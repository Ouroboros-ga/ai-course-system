## 5. 常见问题 FAQ
----------------------------------------------------------------------

Q: 为什么我的 API Key 无法使用?
A: API Key 只是身份凭证，还需要单独开通模型服务权限

Q: Endpoint ID 和 Model ID 有什么区别?
A: Endpoint ID 是你创建的推理接入点标识(以ep-开头)
   Model ID 是模型本身的名字(如Doubao-1.5-pro-32k)
   两者都可以用，但需要确保有对应权限

Q: 如何查看我有哪些可用的模型?
A: 登录 https://console.volcengine.com/ark/ 查看'已开通模型'

Q: 有免费的试用额度吗?
A: 新用户通常有免费Token额度，可在控制台查看剩余额度
