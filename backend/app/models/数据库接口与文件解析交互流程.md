# 数据库接口与文件解析交互流程文档

## 概述

本文档详细说明了 `models` 文件夹下数据库模型与文件解析、智课生成、音频存储等功能的交互流程。

---

## 一、数据库模型概览

### 1.1 核心数据表

| 表名 | 用途 | 关联功能 |
|------|------|----------|
| `courses` | 课程主表 | 存储课程基本信息、文件路径 |
| `course_scripts` | 智课脚本表 | 存储AI生成的结构化脚本、音频URL |
| `script_nodes` | 脚本节点表 | 存储每个节点的详细内容 |
| `docling_documents` | 文档解析主表 | 存储文件解析结果、JSON数据 |
| `docling_groups` | 文档分组表 | 存储解析后的分组信息 |
| `docling_tables` | 表格数据表 | 存储解析出的表格 |
| `docling_table_cells` | 表格单元格表 | 扁平化存储表格单元格 |
| `docling_texts` | 文本内容表 | 存储解析出的文本内容 |
| `docling_pictures` | 图片表 | 存储解析出的图片信息 |

### 1.2 辅助数据表

| 表名 | 用途 |
|------|------|
| `users` | 用户表 |
| `qa_sessions` | 问答会话表 |
| `qa_messages` | 问答消息表 |
| `qa_contexts` | 问答上下文表 |
| `learning_progress` | 学习进度表 |
| `node_progress` | 节点进度表 |
| `understanding_analysis` | 理解度分析表 |

## 二、文件传输与解析流程

### 2.1 文件上传阶段

```
前端上传文件 → API接口接收 → 存储文件信息到数据库
```

**涉及的数据库字段：**

#### `courses` 表
- `source_file_name`: 原始文件名
- `source_file_path`: 原始文件存储路径
- `source_mimetype`: 原始文件MIME类型
- `total_pages`: 总页数

#### `docling_documents` 表
- `origin_filename`: 原始文件名
- `origin_mimetype`: 原始文件MIME类型
- `origin_binary_hash`: 文件二进制哈希
- `source_file_path`: 原始文件存储路径
- `status`: 解析状态（pending/processing/completed/failed）

### 2.2 文件解析阶段

```
调用解析API → 解析文件内容 → 存储解析结果到数据库
```

**解析状态枚举 (`ParseStatus`)：**
- `PENDING`: 等待解析
- `PROCESSING`: 解析中
- `COMPLETED`: 解析完成
- `FAILED`: 解析失败

**解析结果存储：**

#### `docling_documents` 表
- `raw_json`: 原始解析JSON完整数据
- `total_groups`: 分组数量
- `total_tables`: 表格数量
- `total_texts`: 文本数量
- `total_pictures`: 图片数量
- `error_message`: 解析失败时的错误信息

#### `docling_groups` 表
- `doc_id`: 所属文档ID
- `self_ref`: 自引用路径
- `name`: 分组名称
- `label`: 标签类型

#### `docling_texts` 表
- `doc_id`: 所属文档ID
- `group_id`: 所属分组ID
- `text`: 文本内容
- `page_no`: 所在页码
- `sort_order`: 排序序号

#### `docling_tables` 表
- `doc_id`: 所属文档ID
- `table_data`: 表格数据(JSON)
- `num_rows`: 表格行数
- `num_cols`: 表格列数

#### `docling_pictures` 表
- `doc_id`: 所属文档ID
- `image_url`: 图片URL或存储路径
- `page_no`: 所在页码

## 三、智课生成流程

### 3.1 脚本生成阶段

```
读取解析数据 → 调用AI API → 生成结构化脚本 → 存储到数据库
```

**涉及的数据库字段：**

#### `course_scripts` 表
- `course_id`: 所属课程ID
- `version`: 脚本版本号
- `script_content`: 结构化脚本内容(JSON)
- `summary_text`: AI生成的课程摘要
- `keywords`: 关键词(JSON数组)
- `is_active`: 是否为当前激活版本

### 3.2 节点拆分阶段

```
解析脚本内容 → 拆分为节点 → 存储节点详情
```

**涉及的数据库字段：**

#### `script_nodes` 表
- `script_id`: 所属脚本ID
- `chapter_id`: 关联的知识点ID
- `node_index`: 节点序号
- `node_type`: 节点类型
- `title`: 节点标题
- `content`: 节点内容/讲解文本
- `page_start`: 关联PPT起始页
- `page_end`: 关联PPT结束页
- `duration`: 节点时长(秒)
- `is_key_point`: 是否为重点知识点

**节点类型枚举 (`ScriptNodeType`)：**
- `LECTURE`: 讲解
- `QUESTION`: 问题
- `BREAKPOINT`: 断点
- `SUMMARY`: 总结
- `VIDEO`: 视频
- `INTERACTIVE`: 交互

## 四、音频存储流程

### 4.1 音频生成阶段

```
读取脚本内容 → 调用TTS API → 生成音频文件 → 存储URL到数据库
```

**涉及的数据库字段：**

#### `course_scripts` 表
- `audio_url`: 合成音频URL
- `audio_duration`: 音频时长(秒)

#### `script_nodes` 表
- `timestamp_start`: 音频起始时间(秒)
- `timestamp_end`: 音频结束时间(秒)

## 六、API接口与数据库交互

### 6.1 文件上传接口

**接口路径**: `POST /api/somark/parse`

**交互流程**:
1. 接收前端上传的文件
2. 调用外部解析API
3. 返回解析结果给前端

**数据库操作**:
- 创建 `courses` 记录
- 创建 `docling_documents` 记录
- 存储解析结果到相关表

### 6.2 智课生成接口

**接口路径**: `POST /api/course/generate` (示例)

**交互流程**:
1. 读取 `docling_documents` 中的解析数据
2. 调用AI API生成脚本
3. 存储到 `course_scripts` 和 `script_nodes`

### 6.3 音频生成接口

**接口路径**: `POST /api/audio/generate` (示例)

**交互流程**:
1. 读取 `script_nodes` 中的内容
2. 调用TTS API生成音频
3. 存储音频URL到 `course_scripts`

### 6.4 智课播放接口

**接口路径**: `GET /api/course/{course_id}` (示例)

**交互流程**:
1. 查询 `courses` 表获取课程信息
2. 查询 `course_scripts` 表获取脚本和音频URL
3. 查询 `script_nodes` 表获取节点详情
4. 返回完整数据给前端

## 八、关键字段说明

### 8.1 JSON存储字段

| 表名 | 字段名 | 存储内容 |
|------|--------|----------|
| `course_scripts` | `script_content` | 结构化脚本内容 |
| `course_scripts` | `keywords` | 关键词数组 |
| `docling_documents` | `raw_json` | 原始解析JSON |
| `docling_tables` | `table_data` | 表格数据 |
| `script_nodes` | `extra_data` | 扩展元数据 |

### 8.2 URL存储字段

| 表名 | 字段名 | 用途 |
|------|--------|------|
| `courses` | `cover_image` | 封面图片URL |
| `course_scripts` | `audio_url` | 合成音频URL |
| `docling_pictures` | `image_url` | 图片URL |

### 8.3 状态枚举字段

| 枚举类型 | 可选值 | 用途 |
|----------|--------|------|
| `CourseStatus` | DRAFT, PUBLISHED, ARCHIVED | 课程状态 |
| `ParseStatus` | PENDING, PROCESSING, COMPLETED, FAILED | 解析状态 |
| `ScriptNodeType` | LECTURE, QUESTION, BREAKPOINT, SUMMARY, VIDEO, INTERACTIVE | 节点类型 |

## 九、注意事项

1. **文件存储**: 文件本身存储在文件系统中，数据库只存储路径
2. **JSON字段**: 使用 SQLite 的 JSON 列类型存储复杂数据结构
3. **版本控制**: `course_scripts` 支持多版本，通过 `is_active` 标记当前版本
4. **时间戳**: 所有表都有 `created_at` 字段，部分表有 `updated_at` 字段
5. **外键关联**: 使用外键确保数据完整性
