# 学科数据基础模块：复用与废弃边界

> 2026-09-08：用户取消全量 LLM 概念/关系抽取。现行任务为[CS 语料向量化与 RAG 上线实施计划](../../../../docs/phase1/2026-09-08_CS语料向量化与RAG上线实施计划.md)（CR0–CR6）。本轮只更新文档，以下代码尚未按新路线改造。

## 现有文件的处理

| 文件/原任务 | 状态 | 后续使用 |
|---|---|---|
| `identity.py`、`ingest.py`（DK1） | 修改后复用 | 保留身份/哈希/幂等思路；CR1补持久正文读取、元数据、按token重分块和五来源适配 |
| `builds.py`、`work_items.py`（DK4） | 修改后复用 | 保留任务/租约/取消/重试框架；CR2/CR3补批次读取、心跳、事务提交检查和索引发布依赖 |
| `resolution.py`、`validation.py`、`adjudication.py`、`decisions.py`（DK3） | **废弃于当前语料 RAG 路线，仅历史保留** | 不用于索引准入、原文真实性或回答正确性认证；不作为待接线的 B/C/D 模型任务 |
| DK2 extractor/grounding | 未找到已完成实现，任务取消 | 不补建抽取器；原文引用定位由 CR1 的文档/片段记录承担 |

旧 Worker 只分发 resolve/verify/adjudicate，不能以其工作项完成数表示“已完成向量化”。旧规则测试通过也不等于语义蕴含或真实模型核验通过。

## 改造边界

- 保留旧概念数据、模型和 `dk20260908v1` / `dk20260908v2` 迁移历史；本轮没有删表、清库或改变运行行为。
- 新 `corpus_rag` pipeline 与旧任务区分；产物为可回读原文、文本块、向量、全文索引及不可变发布版本，不生成概念/关系/知识卡。
- CR1–CR3 拟新增的 corpus 服务、向量缓存和索引成员模型尚不存在；开发不得把本文规划当作已实现能力。
- 课程 GraphSnapshot、LearningEvidence 不消费这些资料为正式事实/掌握度；TeachingAgent/Nexus 仅消费标有出处的补充参考。
- 本轮现有 `backend/tests/discipline` 复验65项通过（独立测试SQLite、合成配置）；PG并发、真实embedding和部署仍待新任务验证。

详细文件清单、接口、风险、测试和回退见现行实施计划 §2、§6、§7。
