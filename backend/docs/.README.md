  **后端项目目录** 

```
backend/
├── app/
│   ├── __init__.py
│   ├── main.py              # 项目入口，FastAPI实例创建、路由注册
│   ├── core/                # 全局核心配置
│   │   ├── __init__.py
│   │   ├── config.py        # 全局配置（大模型密钥、数据库、端口等）
│   │   ├── security.py      # 简易权限校验（适配泛雅平台）
│   │   └── exceptions.py    # 全局异常处理，统一接口返回格式
│   ├── common/              # 通用工具类（全项目复用，AI辅助开发核心区）
│   │   ├── __init__.py
│   │   ├── llm_client.py    # 大模型API统一封装（兼容多厂商）
│   │   ├── tts_client.py    # 语音合成API封装
│   │   ├── asr_client.py    # 语音识别API封装
│   │   ├── ppt_parser.py    # PPT课件解析工具（智课生成核心）
│   │   ├── pdf_parser.py    # PDF课件解析工具（智课生成核心）
│   │   └── utils.py         # 通用工具函数（时间、格式处理等）
│   ├── models/              # 数据库ORM模型（SQLModel，FastAPI官方推荐）
│   │   ├── __init__.py
│   │   ├── database.py      # 数据库连接初始化（sqlite/mysql一键切换）
│   │   ├── user_model.py    # 用户模型（教师/学生双角色）
│   │   ├── course_model.py  # 课件、智课脚本模型
│   │   ├── qa_model.py      # 问答记录、上下文关联模型
│   │   └── progress_model.py# 学习进度、理解度分析模型
│   ├── schemas/             # 接口请求/响应数据校验模型（Pydantic）
│   │   ├── __init__.py
│   │   ├── smart_course_schema.py
│   │   ├── qa_schema.py
│   │   ├── progress_schema.py
│   │   └── user_schema.py
│   ├── services/            # 核心业务逻辑层（与接口解耦，分工开发核心）
│   │   ├── __init__.py
│   │   ├── smart_course_service.py  # 智课生成业务（课件解析、脚本生成）
│   │   ├── qa_service.py              # 实时问答业务（上下文关联、多轮对话）
│   │   ├── progress_service.py        # 进度续接、理解度分析业务
│   │   └── user_service.py            # 用户基础业务
│   ├── api/                 # 接口路由层（完全对应赛题三大核心模块）
│   │   ├── __init__.py
│   │   ├── v1/
│   │   │   ├── __init__.py
│   │   │   ├── smart_course_api.py  # 智课生成模块接口
│   │   │   ├── qa_api.py              # 实时问答模块接口
│   │   │   ├── progress_api.py        # 进度续接模块接口
│   │   │   ├── user_api.py            # 用户相关接口
│   │   │   └── common_api.py          # 通用接口（文件上传等）
├── requirements.txt         # 后端依赖包，一键pip安装
├── .env.example             # 环境变量示例（密钥、配置，复制即可用）
└── run.py                   # 后端一键启动脚本
```
