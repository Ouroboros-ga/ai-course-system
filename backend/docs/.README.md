**后端项目目录**
本项目使用uv作为包管理器; 兼容Windows, Linux; Python版本: 3.12;
目前优先确保使用cpu运行文档处理模型.

ai apikey配置
现在仅支持火山引擎 apikey获取：
https://console.volcengine.com/ark/

在.env文件中配置ai apikey, 例如：
DOUBAO_API_KEY= 你的apikey
DOUBAO_ENDPOINT_ID= 你的模型   如 DOUBAO_ENDPOINT_ID=doubao-seed-1-8-251228

## 核心模块说明

### 1. 大模型客户端 (`common/llm_client.py`)
统一封装多厂商LLM API调用：
- **豆包（Doubao）** - 火山引擎，当前主要使用
- **通义千问（Qwen）** - 阿里云
- **文心一言（Wenxin）** - 百度
- **OpenAI** - GPT系列

### 2. 文档处理 (`api/v1/endpoints/document.py`)
- 文件上传与解析
- 调用豆包AI直接解析文档内容
- 返回结构化解析结果（`analysis`字段）

### 3. 签名验证 (`core/signature_middleware.py`)
- 请求签名校验（MD5）
- 时间戳防重放攻击
- 白名单路径配置

### 4. 统一响应格式 (`schemas/common_schema.py`)
```python
{
    "code": 200,        # 状态码
    "message": "成功",   # 提示信息
    "data": { ... }     # 业务数据
}
```

### 5. RAG 检索增强生成 (`common/rag_utils.py` + 相关模块)

完整的 Docling 结构感知 RAG 流水线，逻辑链条：

```
Docling 结构化感知 → 公式占位替换 → 表格展平 → IK 分词索引 → 树状 RAG 检索 → 商业 API
```

| 模块 | 文件 | 核心功能 |
|------|------|----------|
| 公式占位替换 | `formula_placeholder.py` | 将 LaTeX 公式替换为语义化占位符，避免符号干扰分词 |
| 表格展平 | `table_flattener.py` | 将 Markdown 表格转为自然语言描述，提升检索召回率 |
| IK 分词器 | `ik_tokenizer.py` | 双向最大匹配 + 教育专有词典（306词），专有名词识别优先 |
| 树状 RAG | `tree_rag.py` | 按标题层级构建知识树，支持关键词/路径/混合检索 |
| 流水线集成 | `rag_utils.py` | 5步流水线编排，对接商业 LLM API 生成最终回答 |

使用示例：
```python
from app.common import rag_pipeline

# 处理文档
result = rag_pipeline.process_document(markdown_text, doc_name="高等数学")

# 检索
results = rag_pipeline.retrieve("什么是傅里叶变换")

# 生成回答（结合检索结果 + 商业 LLM API）
answer = await rag_pipeline.generate_answer("什么是傅里叶变换", top_k=3)
```

### 6. 三大核心模块
| 模块 | 说明 | 对应接口 |
|------|------|----------|
| 智课生成 | 课件解析、脚本生成 | smart_course_api.py |
| 实时问答 | 上下文关联、多轮对话 | qa_api.py |
| 进度续接 | 学习进度、理解度分析 | progress_api.py |

## 快速启动

```bash
# 1. 进入后端目录
cd backend

# 2. 安装依赖
uv sync

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 填入API密钥

# 4. 启动服务
uv run python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
