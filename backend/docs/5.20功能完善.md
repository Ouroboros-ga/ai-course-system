# AI互动智课系统 — 功能总结

---

## 一句话概括

**老师提供素材和大纲 → AI生成PPT和讲课视频 → 学生看视频学习 → 错了自动重讲**

---

## 完整流程

```
┌──────────── 老师端 ────────────┐    ┌──────────── 学生端 ────────────┐
│                                │    │                                │
│  ① 上传人脸视频+参考音频        │    │  ⑥ 播放分屏讲课视频             │
│       ↓                        │    │     左数字人 右PPT              │
│  ② 输入课程大纲/知识点          │    │     按知识点跳转 / 断点续播      │
│       ↓                        │    │       ↓                        │
│  ③ AI生成PPT课件               │    │  ⑦ 做错题                      │
│       ↓                        │    │       ↓                        │
│  ④ 编辑视频脚本+翻页标记        │    │  ⑧ AI针对性重讲 → 弹出视频      │
│       ↓                        │    │                                │
│  ⑤ AI生成讲课视频              │    └────────────────────────────────┘
│     (TTS语音+数字人+PPT→合成)   │
│                                │
└────────────────────────────────┘
```

---

## 七个功能模块

| 模块 | 做什么 | 核心产出 |
|------|--------|---------|
| **F1 素材管理** | 老师上传人脸视频、参考音频 | 可复用的数字人素材库 |
| **F2 AI生成PPT** | 输入大纲/知识点 → LLM扩展 → 生成.pptx | 完整课件文件 |
| **F3 脚本编辑** | 编辑讲解文本，插入PPT翻页标记 | 带翻页时间轴的结构化脚本 |
| **F4 视频生成** | 脚本→TTS语音→数字人视频+PPT视频→合成 | 每个知识点一段分屏讲课视频 |
| **F5 知识点映射** | 建立知识点与PPT页面的对应关系 | 知识点↔页面双向映射表 |
| **F6 视频播放** | 播放合成视频，按知识点跳转，断点续播 | 学生学习入口 |
| **F7 错题重讲** | 做错题→AI分析→生成针对性重讲视频→弹出播放 | 自适应学习闭环 |

---

## 模块依赖

```
F1 素材 ─────────────────────┐
                              ↓
F2 生成PPT ──→ F5 映射 ──→ F4 视频生成 ──→ F6 播放
                              ↑              ↑
F3 脚本编辑 ─────────────────┘              │
                                             │
                       F7 错题重讲 ──────────┘
```

**实施顺序**：F1 → F3 → F2 → F5 → F4 → F6 → F7
