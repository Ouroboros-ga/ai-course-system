# AI互动智课系统 — 功能总结

---

## 一句话概括

**老师提供素材和大纲 → AI生成PPT和讲课视频 → 学生看视频学习 → 错了自动重讲**

---

## 完整流程

```
┌──────────── 老师端 ────────────┐    ┌──────────── 学生端 ────────────┐
│                                │    │                                │
│  ① 上传人脸视频+参考音频        │    │  ⑥ 播放分屏讲课视频             │
│       ↓                        │    │     左数字人 右PPT              │
│  ② 输入课程大纲/知识点          │    │     按知识点跳转 / 断点续播      │
│       ↓                        │    │       ↓                        │
│  ③ AI生成PPT课件               │    │  ⑦ 做错题                      │
│       ↓                        │    │       ↓                        │
│  ④ 编辑视频脚本+翻页标记        │    │  ⑧ AI针对性重讲 → 弹出视频      │
│       ↓                        │    │                                │
│  ⑤ AI生成讲课视频              │    └────────────────────────────────┘
│     (TTS语音+数字人+PPT→合成)   │
│                                │
└────────────────────────────────┘
```

---

## 七个功能模块

| 模块 | 做什么 | 核心产出 |
|------|--------|---------|
| **F1 素材管理** | 老师上传人脸视频、参考音频 | 可复用的数字人素材库 |
| **F2 AI生成PPT** | 输入大纲/知识点 → LLM扩展 → 生成.pptx | 完整课件文件 |
| **F3 脚本编辑** | 编辑讲解文本，插入PPT翻页标记 | 带翻页时间轴的结构化脚本 |
| **F4 视频生成** | 脚本→TTS语音→数字人视频+PPT视频→合成 | 每个知识点一段分屏讲课视频 |
| **F5 知识点映射** | 建立知识点与PPT页面的对应关系 | 知识点↔页面双向映射表 |
| **F6 视频播放** | 播放合成视频，按知识点跳转，断点续播 | 学生学习入口 |
| **F7 错题重讲** | 做错题→AI分析→生成针对性重讲视频→弹出播放 | 自适应学习闭环 |

---

## 模块依赖

```
F1 素材 ─────────────────────┐
                              ↓
F2 生成PPT ──→ F5 映射 ──→ F4 视频生成 ──→ F6 播放
                              ↑              ↑
F3 脚本编辑 ─────────────────┘              │
                                             │
                       F7 错题重讲 ──────────┘
```

**实施顺序**：F1 → F3 → F2 → F5 → F4 → F6 → F7





# AI互动智课系统 — 功能概要

---

## 核心定位

**老师输入课件 → AI生成讲课视频 → 学生自适应学习**

---

## 七大功能模块

### F1 · 老师素材管理
> 上传人脸视频 + 参考音频，绑定账号，多课复用

```
上传mp4人脸视频 / mp3参考音频 → 存储并绑定老师账号 → 创建课程时自动选用默认素材
```

---

### F2 · AI生成PPT课件
> 老师输入大纲和知识点，AI生成完整PPT

```
老师输入(大纲/主题/知识点列表)
    → LLM扩展为结构化教学脚本
    → 按模板生成.pptx课件
    → 自动进入解析管线，产出知识点映射
```

---

### F3 · 视频脚本编辑
> 老师后台编辑讲解文本，插入PPT翻页标记

```
查看脚本知识点树 → 编辑讲解文本 → 插入翻页标记(哪句话翻到哪页PPT) → 选择音色/数字人素材 → 预览单节点效果 → 版本管理
```

---

### F4 · 视频生成（核心管线）
> 每个知识点生成一段"左数字人 + 右PPT"的分屏讲课视频

```
知识点脚本
   ├→ TTS合成语音
   │     ├→ 语音 + 老师人脸素材 → 数字人API → 左侧讲课视频
   │     └→ 翻页标记 + PPT页面渲染 → 右侧幻灯片视频
   │
   └→ 左右视频合成 → 最终分屏视频.mp4
```

---

### F5 · 知识点↔PPT映射引擎
> 建立知识点与PPT页面的双向对应关系

```
老师上传PPT → 逐页提取文本 → 与知识点语义匹配 → 建立映射表
AI生成PPT  → 生成时自动建立映射
老师可手动调整映射关系
```

---

### F6 · 分屏视频播放器
> 学生端：左数字人讲课，右PPT同步翻页

```
┌────────────┬──────────────┐
│  数字人讲课  │   PPT幻灯片   │
│  (左40%)   │   (右60%)    │
└────────────┴──────────────┘
  知识点导航条：[知识点1] [知识点2] [知识点3]...
  支持：断点续播 / 倍速 / 按知识点跳转
```

---

### F7 · 错题重讲闭环
> 做错题 → AI针对性重讲 → 弹出视频

```
学生做错题
  → AI分析错误原因 + 定位薄弱知识点
  → 生成针对性重讲脚本(换类比/换例子，2-3分钟)
  → 生成重讲视频(数字人+PPT)
  → 弹出播放
  → 观看完毕 → 更新理解度
```

---
