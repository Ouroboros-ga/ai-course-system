# AI互动智课系统 — 功能概要

---

## 核心定位

**老师输入课件 → AI生成讲课视频 → 学生自适应学习**

---

## 七大功能模块

### F1 · 老师素材管理（已完成）
> 上传人脸视频 + 参考音频，绑定账号，多课复用

```
上传mp4人脸视频 / mp3参考音频 → 存储并绑定老师账号 → 创建课程时自动选用默认素材
```

---

### F2 · 知识点↔PPT映射引擎（已完成）
> 建立知识点与PPT页面的双向对应关系

```
老师上传PPT → 逐页提取文本 → 与知识点语义匹配 → 建立映射表
AI生成PPT  → 生成时自动建立映射

老师可在课程管理界面，根据实际教学情况，调整知识点与PPT页面的对应关系。前端需要有这个更改调整界面。
更新关系后，需要在视频生成前，根据调整后的映射关系，重新解析脚本。

```

---

### F3 · AI生成PPT课件
> 老师输入大纲和知识点，AI生成完整PPT

```
老师输入(大纲/主题/知识点列表)
    → LLM扩展为结构化教学脚本
    → 脚本输入科大讯飞ppt生成API，接收生成.pptx课件
    → 自动进入解析管线，产出知识点映射表（f2知识点↔PPT映射引擎）
```

---

### F4 · 视频脚本编辑
> 老师后台编辑讲解文本，插入PPT翻页标记

```
查看脚本知识点树 → 编辑讲解文本 → 插入翻页标记(哪句话翻到哪页PPT) → 选择音色/数字人素材 → 预览单节点效果 → 版本管理
```

---

### F5 · 视频生成（核心管线）✅ 已实现
> 每个知识点生成一段"左数字人 + 右PPT"的分屏讲课视频

```
知识点脚本
   ├→ TTS合成语音（支持预置音色和克隆音色S_xxx）
   │     ├→ 语音 + 老师人脸素材 → 数字人API → 左侧讲课视频 ✅
   │     └→ 翻页标记 + PPT页面渲染 → 右侧幻灯片视频（待实现）
   │
   └→ 左右视频合成 → 最终分屏视频.mp4（待实现）
```

已实现：
- TTS合成语音 → 保存音频文件
- 音频 + 人脸视频 → 数字人Gradio API → 数字人讲课视频
- VideoGenerationTask记录生成状态
- 单节点/批量生成API
- 数字人服务健康检查

---


### F6 · 分屏视频播放器
> 学生端：左数字人讲课，右PPT同步翻页

```
┌────────────┬──────────────┐
│  数字人讲课  │   PPT幻灯片   │
│  (左40%)   │   (右60%)    │
└────────────┴──────────────┘
  知识点导航条：[知识点1] [知识点2] [知识点3]...
  支持：断点续播 / 倍速 / 按知识点跳转
```

---

### F7 · 错题重讲闭环
> 做错题 → AI针对性重讲 → 弹出视频

```
学生做错题
  → AI分析错误原因 + 定位薄弱知识点
  → 生成针对性重讲脚本(换类比/换例子，2-3分钟)
  → 生成重讲视频(数字人+PPT)
  → 弹出播放
  → 观看完毕 → 更新理解度
```
