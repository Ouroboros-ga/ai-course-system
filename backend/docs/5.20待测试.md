## 测试步骤

### 1. 确保测试账号存在

```powershell
cd e:\smartcarb\ai-course-system\backend
C:\Users\LIU\.local\bin\uv run python scripts\create_test_users.py
```

### 2. 打开 Swagger UI

浏览器访问：**http://localhost:8000/docs**

找到 **素材管理** 分组，你会看到 5 个接口。

### 3. 获取Token并授权

1. 先调用 `POST /api/v1/user/login`，用 `TTT / 123456` 登录
2. 复制返回的 `token`
3. 点击页面右上角 🔓 **Authorize** 按钮，输入 `Bearer <你的token>`

### 4. 按顺序测试接口

| 顺序 | 接口 | 操作 | 预期结果 |
|------|------|------|---------|
| ① | `POST /assets/upload` | 上传一个mp4文件，asset_type选`face_video` | 返回200，is_default=true（第一个自动默认） |
| ② | `POST /assets/upload` | 再上传一个mp4，asset_type选`face_video` | 返回200，is_default=false |
| ③ | `GET /assets/` | 不传参数 | 返回2个素材 |
| ④ | `GET /assets/?asset_type=face_video` | 筛选类型 | 只返回face_video类型 |
| ⑤ | `PUT /assets/{id}/default` | 把第二个设为默认 | 第二个变默认，第一个取消默认 |
| ⑥ | `GET /assets/{id}/preview` | 预览视频 | 浏览器直接播放视频流 |
| ⑦ | `DELETE /assets/{id}` | 删除一个 | 删除成功，如果是默认的会自动切换 |

### 5. 验证文件存储


## 方式二：用 curl 命令快速测试

```powershell
# 1. 登录获取token
$loginRes = Invoke-RestMethod -Uri "http://localhost:8000/api/v1/user/login" -Method POST -ContentType "application/json" -Body '{"username":"TTT","password":"123456"}'
$token = $loginRes.data.token
Write-Host "Token: $token"

# 2. 上传人脸视频（需要一个mp4文件）
# 先创建一个测试mp4文件
$form = @{
    file = Get-Item -Path "你的视频文件路径.mp4"
    asset_type = "face_video"
    time = (Get-Date -Format "yyyy-MM-dd HH:mm:ss")
}
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/assets/upload" -Method POST -Headers @{Authorization="Bearer $token"} -Form $form

# 3. 查看素材列表
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/assets/" -Headers @{Authorization="Bearer $token"}
```
