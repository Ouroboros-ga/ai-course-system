## F1 · 素材管理

### 功能概述

老师上传人脸视频、参考音频，绑定账号，多课复用。用于后续数字人视频生成（F4/F5）。

### 数据流

```
上传mp4人脸视频 / mp3参考音频
  → 流式写入服务端（1MB chunk，避免全量读内存）
  → ffprobe提取时长 / ffmpeg生成缩略图
  → 存储到 teacher_assets/ 目录
  → 绑定老师账号
  → 创建课程时自动选用默认素材
```

### 后端实现

#### 数据模型

| 文件 | 说明 |
|------|------|
| `backend/app/models/asset_model.py` | TeacherAsset 表 + AssetType 枚举 + CloneStatus 枚举 |

**TeacherAsset 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| teacher_id | int | 所属老师ID（外键） |
| asset_type | AssetType | 素材类型：face_video / ref_audio / other |
| file_name | str | 原始文件名 |
| file_path | str | 文件存储路径 |
| file_size | int | 文件大小(字节) |
| mime_type | str | 文件MIME类型 |
| duration | float | 音视频时长(秒)，ffprobe提取 |
| thumbnail_url | str | 缩略图路径(视频封面)，ffmpeg生成 |
| is_default | bool | 是否为该类型的默认素材 |
| clone_voice_id | str | 声音复刻后的speaker_id（如S_xxxxxxxxx），仅ref_audio使用 |
| clone_status | CloneStatus | 声音复刻状态：none / pending / success / failed |
| metadata_ | JSON | 扩展元数据 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

#### API接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/assets/upload` | 上传素材（流式写入，200MB视频/50MB音频限制） | teacher |
| GET | `/api/v1/assets/` | 获取素材列表（支持 asset_type 筛选，含clone_status） | teacher |
| PUT | `/api/v1/assets/{id}/default` | 设为默认素材（同类型互斥） | teacher |
| GET | `/api/v1/assets/{id}/preview` | 预览素材（支持Range请求，token可通过query传递） | 登录用户 |
| DELETE | `/api/v1/assets/{id}` | 删除素材（引用检查：若脚本节点引用则拒绝409） | teacher |
| POST | `/api/v1/assets/{id}/clone-voice` | 声音复刻（上传参考音频到火山引擎训练克隆音色） | teacher |
| GET | `/api/v1/assets/{id}/clone-status` | 查询声音复刻状态 | 登录用户 |

#### 关键设计决策

| 问题 | 解决方案 |
|------|---------|
| 文件全量读内存 | 流式写入，每次读取1MB chunk边读边写 |
| 硬编码后端地址 | 前端预览URL从 `VITE_API_BASE_URL` 环境变量读取 |
| 缺少引用检查 | 删除前检查 ScriptNode.extra_data 中的 asset_id 引用 |
| 前端上传大小限制不一致 | 前端200MB/后端200MB统一 |
| duration/thumbnail未填充 | ffprobe提取时长，ffmpeg生成视频缩略图 |
| 命名不一致 | 组件统一为 TeacherAssetManager.vue |
| 声音复刻 | 参考音频上传后可一键复刻，clone_voice_id存入TeacherAsset，TTS合成时自动识别S_前缀使用volcano_icl集群 |

### 前端实现

| 文件 | 说明 |
|------|------|
| `frontend/src/api/asset.js` | API封装：uploadAsset, getAssetList, setDefaultAsset, deleteAsset, getAssetPreviewUrl, cloneVoice, getCloneStatus |
| `frontend/src/components/profile/LoginIn/menu/TeacherAssetManager.vue` | 素材管理弹窗组件（含声音复刻按钮和状态标签） |

#### 声音复刻交互

- 参考音频列表项显示复刻状态标签：已克隆(绿) / 复刻中(黄) / 复刻失败(红)
- "声音复刻"按钮：调用后端clone-voice接口，训练中显示loading
- 复刻失败时显示"重新复刻"按钮
- 复刻成功后，克隆音色自动出现在F4脚本编辑器的音色选择器中

## F2 · 知识点↔PPT映射引擎

### 功能概述

建立知识点与PPT页面的双向对应关系。支持自动映射、AI语义匹配、手动调整。映射关系应用到脚本后，视频生成管线将按映射关系同步翻页。

### 数据流

```
老师上传PPT / AI生成PPT
  → Docling解析 → 逐页提取文本（含页码）
  → PPTX特殊处理：从Markdown标题提取页码，避免多页映射到第1页
  → 自动映射：基于ScriptNode的page_start/page_end + 标题匹配 + 均匀分配
  → AI语义匹配：LLM分析知识点与PPT页面语义相似度
  → 手动调整：老师在前端拖拽/输入页码范围
  → 应用映射：更新ScriptNode的page_start/page_end
```

### 后端实现

#### 数据模型

| 文件 | 说明 |
|------|------|
| `backend/app/models/mapping_model.py` | KnowledgePageMap 表，字段：course_id, script_id, node_id, page_start, page_end, confidence, is_manual |

#### 服务层

| 文件 | 核心方法 | 说明 |
|------|---------|------|
| `backend/app/services/mapping_service.py` | `auto_map_from_nodes()` | 自动映射：标题匹配 + 均匀分配 |
| | `ai_match_mapping()` | AI语义匹配：LLM分析知识点与PPT页面 |
| | `update_node_mapping()` | 手动调整单个映射 |
| | `batch_update_mappings()` | 批量更新映射 |
| | `apply_mappings_to_script()` | 应用映射到脚本节点 |
| | `get_page_texts()` | 获取PPT逐页文本（含PPTX重新提取逻辑） |
| | `get_mapping_detail()` | 获取完整映射详情 |

#### API接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/mapping/{course_id}` | 获取映射详情（知识点列表+PPT页面+映射关系） | 登录用户 |
| GET | `/api/v1/mapping/{course_id}/pages` | 获取PPT逐页文本 | 登录用户 |
| POST | `/api/v1/mapping/{course_id}/auto` | 自动生成映射 | teacher |
| POST | `/api/v1/mapping/{course_id}/ai-match` | AI语义匹配 | teacher |
| PUT | `/api/v1/mapping/{course_id}/nodes/{node_id}` | 手动调整映射（含结束页>=起始页校验） | teacher |
| PUT | `/api/v1/mapping/{course_id}/batch` | 批量更新映射 | teacher |
| POST | `/api/v1/mapping/{course_id}/apply` | 应用映射到脚本 | teacher |

#### 关键设计决策

| 问题 | 解决方案 |
|------|---------|
| 多页PPTX内容都映射到第1页 | StructureParser从Markdown标题提取页码；auto_map采用"每页对应多个节点"策略 |
| 点击知识点无法选中/手动编辑无效 | watch(selectedNode)同步编辑值；isPageInSelectedRange使用编辑中的值 |
| 结束页小于起始页 | 前端校验+后端校验，输入框红色提示 |
| 点击右侧PPT页码无法更改映射 | 支持点击PPT页面设置映射关系 |

### 前端实现

| 文件 | 说明 |
|------|------|
| `frontend/src/api/mapping.js` | API封装 |
| `frontend/src/components/profile/LoginIn/courses/MappingEditor.vue` | 映射编辑器弹窗（左知识点列表 + 右PPT页面预览） |

#### MappingEditor交互

- 左侧知识点列表：点击选中，高亮当前映射的PPT页码范围
- 右侧PPT页面：点击页面可更改选中知识点的映射
- 编辑区：起始页/结束页输入框，保存按钮
- 工具栏：自动映射、AI智能匹配、应用到脚本

## F3 · AI生成PPT课件

### 功能概述

老师输入大纲/主题/知识点列表，LLM扩展为结构化教学脚本，调用科大讯飞PPT生成API产出.pptx课件，自动进入解析管线生成知识点映射表。

### 数据流

```
老师输入(大纲/主题/知识点列表)
  → LLM扩展为结构化教学脚本（Markdown格式）
  → 脚本输入科大讯飞PPT生成API
      → 创建任务 → 轮询进度 → 下载.pptx
  → 自动进入解析管线
      → Docling解析 → 脚本生成 → 知识点映射（F2）
  → 前端展示课程，可进入映射编辑器调整
```

### 后端实现

#### 鉴权机制

科大讯飞PPT API鉴权：`MD5(appId + timestamp) → HMAC-SHA1(md5_result, secret) → Base64`

请求头：`appId`, `timestamp`, `signature`

#### 服务层

| 文件 | 核心类/方法 | 说明 |
|------|-----------|------|
| `backend/app/services/ppt_generation_service.py` | `XfyunPPTClient` | 讯飞API客户端：鉴权、模板查询、PPT创建、进度轮询、文件下载 |
| | `PPTGenerationService.expand_to_teaching_script()` | LLM扩展教学脚本 |
| | `PPTGenerationService.generate_ppt()` | 完整生成流程（LLM→讯飞API→轮询→下载） |
| | `PPTGenerationService.get_themes()` | 获取模板列表 |

#### API接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/ppt-generation/themes` | 获取PPT模板列表（支持风格/行业筛选） | 登录用户 |
| GET | `/api/v1/ppt-generation/task/{sid}` | 查询PPT生成任务进度 | 登录用户 |
| POST | `/api/v1/ppt-generation/generate` | 异步生成PPT（后台任务，立即返回） | teacher |
| POST | `/api/v1/ppt-generation/generate-sync` | 同步生成PPT（等待完成，1-5分钟） | teacher |

#### 请求参数（generate/generate-sync）

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| topic | string | Y | 课程主题（1-500字） |
| outline | string | N | 课程大纲 |
| knowledge_points | string[] | N | 知识点列表 |
| template_id | string | N | PPT模板ID（不填用默认） |
| author | string | N | PPT作者名（默认"AI智课"） |
| search | bool | N | 是否联网搜索补充内容 |
| auto_parse | bool | N | 生成后是否自动解析（默认true） |

#### 自动解析管线

PPT生成完成后，自动执行：
1. 创建 Course 记录（is_ai_generated=True）
2. 创建 DoclingDocument 记录
3. 调用 document_service.process_document() 解析PPTX
4. 存储 DoclingGroup、DoclingText 等结构化数据
5. 生成 CourseScript 和 ScriptNode
6. 更新课程统计信息

### 前端实现

| 文件 | 说明 |
|------|------|
| `frontend/src/api/ppt_generation.js` | API封装：getPPTThemes, generatePPT, generatePPTSync, getPPTTaskStatus |
| `frontend/src/components/profile/LoginIn/courses/PPTGenerationDialog.vue` | PPT生成对话框（三步交互） |

#### PPTGenerationDialog交互

- **步骤1**：输入课程主题、大纲、知识点列表；选择PPT模板；可选联网搜索
- **步骤2**：生成中，显示进度条和状态信息（LLM扩展→讯飞API生成→解析管线）
- **步骤3**：完成，显示课程ID和知识点数量，可跳转到课程页面
- 失败时显示错误信息，可重新尝试

#### TeacherDashboard集成

左侧边栏新增"AI生成PPT课件"按钮（紫色虚线边框），点击打开PPTGenerationDialog。

## F4 · 视频脚本编辑

### 功能概述

老师后台编辑讲解文本，插入PPT翻页标记，选择音色/数字人素材，预览单节点TTS效果，管理脚本版本。

### 数据流

```
查看脚本知识点树
  → 编辑讲解文本（Markdown格式）
  → 插入翻页标记（通过F2映射引擎设置page_start/page_end）
  → 选择音色/数字人素材（节点级别，存储在extra_data）
  → 预览单节点TTS效果（调用TTS API合成语音）
  → 保存到后端（持久化content + extra_data）
  → 版本管理（创建快照/回滚）
```

### 后端实现

#### 数据模型

使用现有 ScriptNode 的 `extra_data` JSON字段存储素材选择：

```json
{
  "face_video_asset_id": 1,
  "ref_audio_asset_id": 2,
  "voice": "zh_female_shuangkuaisisi_moon_bigtts"
}
```

#### API接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/document/course/{course_id}/save` | 保存节点修改（含content、page_start/end、extra_data） | teacher |
| POST | `/api/v1/document/tts/synthesize` | TTS语音合成（支持长文本自动分段，支持voice参数） | 登录用户 |
| POST | `/api/v1/document/course/{course_id}/script/snapshot` | 创建脚本版本快照 | teacher |
| GET | `/api/v1/document/course/{course_id}/script/versions` | 获取脚本版本列表 | teacher |
| POST | `/api/v1/document/course/{course_id}/script/rollback/{script_id}` | 回滚到指定版本 | teacher |

#### TTS长文本分段合成

- 短文本（≤2000字）：直接合成
- 长文本（>2000字）：按句号/问号/感叹号自动分段，逐段合成后拼接
- 支持voice参数：节点级别选择音色

#### 版本管理机制

- **创建快照**：深拷贝当前激活脚本的script_content和所有ScriptNode，创建新版本
- **版本列表**：按版本号降序返回所有版本（含节点数量、创建时间）
- **回滚**：将指定版本设为激活，当前激活版本设为非激活，页面重新加载

### 前端实现

| 文件 | 说明 |
|------|------|
| `frontend/src/api/script_editor.js` | API封装：createScriptSnapshot, getScriptVersions, rollbackScriptVersion, saveCourseNodes |
| `frontend/src/views/TeacherDashboard.vue` | 集成F4所有功能 |

#### 音频预览

- 恢复音频播放器UI（播放/暂停、进度条、时间显示）
- "预览语音"按钮调用TTS API，支持全文本合成
- 音色选择：使用节点级别选择的voice参数
- 克隆音色自动识别：voice以`S_`开头时使用volcano_icl集群

#### 声音复刻

- 老师上传参考音频后，点击"声音复刻"按钮
- 后端调用火山引擎声音复刻API（`/api/v1/mega_tts/audio/upload`）
- 训练完成后返回speaker_id（如`S_xxxxxxxxx`），存入TeacherAsset.clone_voice_id
- TTS合成时自动判断：voice以`S_`开头 → 使用`volcano_icl`集群 + `x-api-key`认证
- 复刻状态：none → pending → success/failed，前端显示对应标签

#### 声音复刻后端实现

| 文件 | 核心类/方法 | 说明 |
|------|-----------|------|
| `backend/app/common/tts_client.py` | `VoiceCloneClient` | 声音复刻客户端（单例） |
| | `VoiceCloneClient.upload_and_train()` | 上传音频并训练，返回speaker_id |
| | `VoiceCloneClient.query_status()` | 查询训练状态 |
| `backend/app/api/v1/endpoints/asset.py` | `clone_voice()` | API接口：读取音频→调用训练→更新DB |
| | `get_clone_status()` | API接口：查询复刻状态 |

**声音复刻API调用流程**：

```
POST /api/v1/assets/{id}/clone-voice
  → 校验：仅ref_audio类型 + 归属当前老师 + 文件≤10MB
  → 更新clone_status=pending
  → 读取音频二进制 → base64编码
  → 生成speaker_id: teacher_{user_id}_asset_{asset_id}
  → 调用 VoiceCloneClient.upload_and_train()
      → POST https://openspeech.bytedance.com/api/v1/mega_tts/audio/upload
      → Headers: Authorization=Bearer;{token}, Resource-Id=seed-icl-2.0
      → Body: {appid, speaker_id, audios:[{audio_bytes, audio_format}], source=2, model_type=4}
  → 成功：更新clone_voice_id + clone_status=success
  → 失败：更新clone_status=failed
```

**TTS克隆音色合成流程**：

```
VolcengineTTSClient.synthesize(voice="S_xxx")
  → _is_clone_voice() 判断S_前缀
  → _synthesize_clone()
      → cluster="volcano_icl"
      → Headers: x-api-key={VOLCENGINE_VOICE_CLONE_API_KEY}
      → Body: {app:{cluster:"volcano_icl"}, audio:{voice_type:"S_xxx"}, ...}
  → 预置音色走 _synthesize_preset()
      → cluster="volcano_tts"
      → Headers: Authorization=Bearer;{token}
```

#### 素材选择器

- 三列网格布局：人脸视频、参考音频、语音音色
- 下拉选择器，选项从F1素材管理API动态加载
- 选择"使用默认"时使用老师默认素材
- 素材选择存储在ScriptNode.extra_data中
- 语音音色下拉分组：克隆音色（我的声音）+ 预置音色

#### 版本管理面板

- "版本管理"按钮打开/关闭面板
- 创建快照：输入版本名称（可选），点击创建
- 版本列表：显示版本号、名称、节点数、创建时间
- 当前版本高亮显示（绿色"当前"标签）
- 回滚操作：确认后回滚，页面重新加载

#### 保存持久化

- "保存当前修改"：保存单个节点的content + extra_data到后端
- "保存全部修改"：批量保存所有节点的content + page_start/end + extra_data到后端

### .env 必须配置项

```env
# 科大讯飞PPT生成API（F3必须）

VOLCENGINE_TTS_ACCESS_TOKEN=your-volcengine-tts-access-token
VOLCENGINE_TTS_SECRET_KEY=your-volcengine-tts-secret-key

# 声音复刻（F4克隆音色必须）
VOLCENGINE_VOICE_CLONE_API_KEY=your-clone-api-key
VOLCENGINE_VOICE_CLONE_MODEL_TYPE=4
```

### 前端环境变量

```env
# frontend/.env
VITE_API_BASE_URL=http://localhost:8000/api/v1
```

## 数据库迁移

项目使用 SQLite + `SQLModel.metadata.create_all()`，启动时自动创建新表但不会给已有表添加新列。

若数据库已存在，需手动运行迁移脚本：

```powershell
cd e:\smartcarb\ai-course-system\backend
C:\Users\LIU\.local\bin\uv run python migrate_clone_fields.py
```

该脚本为 `teacher_assets` 表添加：
- `clone_voice_id` VARCHAR DEFAULT NULL — 声音复刻后的speaker_id
- `clone_status` VARCHAR DEFAULT 'none' — 复刻状态（none/pending/success/failed）
