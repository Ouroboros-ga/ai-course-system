## 二、外部工具依赖（需手动安装）

### 2.1 LibreOffice（PPTX/PPT转PDF 必需）

**用途**：将 Office 文档（PPTX/PPT/DOCX/DOC/XLS/XLSX）转换为 PDF，再由 PyMuPDF 渲染为高清图片。

**影响**：未安装时，PPTX/PPT 文件的幻灯片显示将降级为文本绘制模式（质量较低），PDF 文件不受影响。

| 平台 | 安装方式 |
|------|---------|
| **Windows** | 1. 下载安装：https://www.libreoffice.org/download/ <br> 2. 或使用 winget：`winget install TheDocumentFoundation.LibreOffice` |
| **Ubuntu/Debian** | `sudo apt install libreoffice` |
| **CentOS/RHEL** | `sudo yum install libreoffice` |
| **macOS** | `brew install --cask libreoffice` |

**验证安装**：
```bash
# Windows
"C:\Program Files\LibreOffice\program\soffice.exe" --version

# Linux/macOS
libreoffice --version
```

**环境变量**（可选）：如果 LibreOffice 安装在非默认路径，可设置环境变量：
```bash
export LIBREOFFICE_PATH=/path/to/soffice
```

**默认搜索路径**：
- Windows: `C:\Program Files\LibreOffice\program\soffice.exe`
- Linux: `/usr/bin/libreoffice`, `/usr/bin/soffice`, `/usr/local/bin/libreoffice`
- macOS: `/Applications/LibreOffice.app/Contents/MacOS/soffice`

### 2.2 FFmpeg/FFprobe（音频时长精确计算 可选）

**用途**：精确计算 TTS 生成音频的时长。未安装时使用估算值（`字节数 / 采样率 / 2`），精度较低。

| 平台 | 安装方式 |
|------|---------|
| **Windows** | 1. 下载安装：https://ffmpeg.org/download.html <br> 2. 或使用 winget：`winget install Gyan.FFmpeg` |
| **Ubuntu/Debian** | `sudo apt install ffmpeg` |
| **CentOS/RHEL** | `sudo yum install ffmpeg` |
| **macOS** | `brew install ffmpeg` |

**验证安装**：
```bash
ffprobe -version
```

## 四、快速启动指南

### 4.1 后端

```bash

# 方式1：使用 uv（推荐）
uv sync

# 方式2：使用 pip
pip install -e .

# 启动服务（启动时自动检查依赖）
python run.py
```

```bash
cd frontend
```

## 五、依赖架构关系图

```
FastAPI (Web框架)
  ├── sqlmodel (ORM) → SQLite数据库
  ├── pydantic / pydantic-settings (数据校验/配置)
  ├── python-jose + bcrypt (JWT认证/密码哈希)
  └── httpx (异步HTTP客户端)
        ├── llm_client → 豆包/通义千问/文心一言/OpenAI
        ├── tts_client → 阿里云/腾讯云/火山引擎TTS
        ├── digital_human_client → Gradio数字人服务
        └── ppt_generation_service → 科大讯飞PPT API

文档解析管线:
  docling (主力解析) → pdfplumber (PDF备用) → python-docx (Word) → python-pptx (PPT)
  PyMuPDF/fitz (PDF渲染为图片) + LibreOffice (Office转PDF)
  Pillow (文本降级模式幻灯片渲染)

音频管线:
  httpx → 火山引擎TTS API → mp3音频
  ffprobe (可选，精确时长计算)

RAG流水线:
  纯Python标准库实现（无第三方依赖）
```
