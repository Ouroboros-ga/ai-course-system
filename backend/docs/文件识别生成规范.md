## 一、什么是知识点树？
知识点树是将课件内容按照**层级关系**拆解成的树状结构，每个节点代表一个独立的知识点，包含该知识点的属性信息（如是否重点、页码位置、父子关系等）。
---

## 三、知识点树的核心字段解析
| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `chapterId` | String | 唯一标识符 | "chap001_02_03" |
| `chapterName` | String | 知识点名称 | "典型环节的传递函数" |
| `level` | Integer | 层级深度（1=章，2=节，3=知识点） | 3 |
| `isKeyPoint` | Boolean | 是否为重点 | true |
| `pageRange` | String | 对应页码范围 | "27-40" |
| `subChapters` | Array | 子知识点数组 | [...] |
| `description` | String | 知识点简要描述 | "比例、惯性、积分等环节" |
---
## 四、这种结构的优势（对比 Markdown）
| 特性 | Markdown 文件 | 结构化知识点树 |
|------|---------------|----------------|
| **可检索性** | ❌ 需全文扫描 | ✅ 直接按 ID 查询 |
| **层级关系** | ❌ 隐式（通过标题级别） | ✅ 显式（父子节点） |
| **精准定位** | ❌ 无法跳转到具体知识点 | ✅ 通过 pageRange 跳转 |
| **重点标注** | ❌ 需人工识别 | ✅ `isKeyPoint` 字段 |
| **数据库存储** | ❌ 需解析文本 | ✅ 直接存储为 JSON |
| **动态调整** | ❌ 难以重组 | ✅ 轻松添加/删除节点 |

## 五、在"智课系统"中的应用场景
### 1. **脚本生成时**  
系统遍历知识点树，为每个 `chapterId` 生成对应的讲授脚本段落：
```json
{
  "sectionId": "sec002",
  "relatedChapterId": "chap001_02_03",  // 关联知识点ID
  "content": "现在我们来学习典型环节的传递函数...",
  "keyPoints": ["比例环节", "惯性环节", "振荡环节"]
}
```
### 2. **问答交互时**  
学生提问"什么是传递函数？" → 系统通过 NLP 匹配到 `chapterId: "chap001_02_01"` → 返回该知识点的上下文内容。
### 3. **进度追踪时**  
记录学生当前学习的 `chapterId`，实现断点续学：
```json
{
  "currentSectionId": "chap001_03_02",  // 学生学到"结构图简化"
  "progressPercent": 65.5
}
```

这种结构化知识点树正是您之前提到的"云端数据库存储"的核心形式，它让课件从**静态文档**变成了**可计算、可检索、可交互的智能数据**。
