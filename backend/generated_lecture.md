# 第二章 控制系统的数学模型教学讲解

## 引言
同学们，今天我们要开启第二章“控制系统的数学模型”的学习之旅。这一章在整个控制理论体系中占据着至关重要的地位，它是我们进行控制系统分析和综合设计的基础。通过学习这一章，大家要掌握控制系统不同域的数学模型，包括时域、复数域的数学模型，学会运用结构图和信号流图来描述系统，并且能够求解系统的传递函数等。这些知识将为后续深入分析系统性能、进行系统设计和校正等内容奠定坚实的基础。

## 第一节 控制系统的时域数学模型
### 为什么要建立系统的数学模型
同学们，我们为什么要建立系统的数学模型呢？这是因为数学模型是进行控制系统分析和综合设计的基础。系统的状态，也就是各种物理量，会随着时间的推移而不断变化。我们要研究系统的动态特性，就需要用数学表达式来描述它，这就是动态数学模型。

### 动态数学模型的定义
动态数学模型是描述系统（或元件）动态特性的数学表达式。由于系统状态随时间变化，所以最基本的动态数学模型就是微分方程。比如RL串联电路，描述电流随时间变化的微分方程就是一个典型的动态数学模型。控制理论主要研究的就是动态系统。

### 建立数学模型的方法
建立系统数学模型有两种常见的方法：
1. **分析法**：通过对系统各部分的运动机理进行分析，建立系统的数学模型。就像我们分析电路中电流、电压的关系，机械系统中力和运动的关系等。
2. **实验法（系统辨识）**：人为施加某种测试信号，记录基本输出响应，然后根据输入——输出关系拟合系统的数学模型。比如给一个系统输入一个特定的信号，观察它的输出，然后通过数据处理来确定系统的数学模型。

### 建立微分方程的步骤
建立微分方程一般有以下步骤：
1. 按照系统构成和要求确定系统的输入量和输出量。比如在一个电路中，输入量可能是电压，输出量可能是电流。
2. 将系统划分为若干环节，从输入端开始，按信号传递的顺序，前一部分的输出作为后一部分的输入，依据各变量所遵循的物理机制，列出各环节的原始方程。
3. 消去中间变量，写出仅包含输入、输出变量的微分方程式。

### 常见环节和系统微分方程的建立
#### RLC串联电路
我们来看一个RLC串联电路的例子。以$U_i(t)$为输入量，$U_o(t)$为输出量，根据基尔霍夫定律可写出回路方程。这里$i(t)$和$U_o(t)$是被控量，选择$U_o(t)$为输出，$i(t)$就成为中间变量。最后得到的RLC串联电路的数学模型是一个二阶线性微分方程。

#### 弹簧—质量—阻尼器机械位移系统
再看弹簧—质量—阻尼器机械位移系统。质量为$m$的物体在外力$F(t)$作用下，根据牛顿运动定律进行受力分析。$F(t)$为输入量，$x(t)$和$F_1(t)$、$F_2(t)$为被控量，选择$x(t)$为输出，$F_1(t)$、$F_2(t)$成为中间变量。其数学模型同样是一个二阶线性微分方程。

### 系统极点与运动模态
由于传递函数的极点就是微分方程的特征根，所以系统的极点决定了所描述系统自由运动的运动模态。比如给定一个系统的传递函数，我们就可以通过极点来分析系统自由运动的特性。

### 线性微分方程式的求解
在工程实践中，常采用拉氏变换法求解线性常微分方程。其基本思路是：将线性微分方程从时域$t$通过拉氏变换转换为复数域$s$的代数方程，求解代数方程后，再通过拉氏反变换得到微分方程的解。

#### 拉氏变换的定义
如果有一函数$f(t)$满足：$t < 0$时，$f(t)=0$；$t\geq0$时，$f(t)$是分段连续的。那么$f(t)$的拉氏变换为：$F(s)=L[f(t)]$，拉氏反变换为：$f(t)=L^{-1} [F(s)]$。

#### 常用函数的拉氏变换
常见的函数拉氏变换有：
- 单位阶跃函数$I(t)$ 的拉氏变换为$1$。
- 单位脉冲函数$\delta(t)$ 的拉氏变换为$1$。
- 单位斜坡函数$t$ 的拉氏变换为$\frac{1}{s^2}$。
- 正弦函数$\sin\omega t$ 的拉氏变换为$\frac{\omega}{s^2 + \omega^2}$。
- 余弦函数$\cos\omega t$ 的拉氏变换为$\frac{s}{s^2 + \omega^2}$。
- 指数函数$e^{at}$ 的拉氏变换为$\frac{1}{s - a}$。

#### 拉氏变换的定理
- **线性定理**：$L[af_1(t)+bf_2(t)] = aF_1(s)+bF_2(s)$。例如求正弦函数$f(t)=\sin\omega t$的拉氏变换，就可以利用这个定理。
- **微分定理**：$L[f^\prime(t)] = sF(s)-f(0)$，$L[f^{\prime\prime}(t)] = s^2F(s)-sf(0)-f^\prime(0)$。比如求阶跃函数$f(t)=I(t)$的拉氏变换就会用到微分定理。

#### 拉氏反变换
象函数的一般表达式可以分解为零点和极点的形式，然后通过部分分式法求拉氏反变换，实际上就是求待定系数$A_1, A_2, \cdots, A_n$。极点的形式不同，待定系数的求解方法也不同。

## 第二节 控制系统的复数域数学模型
### 传递函数的定义和性质
时域数学模型（微分方程）不能直接反映出系统结构和参数对系统运动特征的影响，当系统的结构和参数变化时，系统分析会比较麻烦。而复数域数学模型——传递函数方法直观，借助计算机可以迅速、准确地获得结果。

传递函数的定义是：在零初始条件下，系统输出量拉氏变换与系统输入量拉氏变换之比，用$G(S)$表示，即$G(S)=\frac{C(S)}{R(S)}$。将微分方程进行拉氏变换就可以求得传递函数。比如求RLC电路的传递函数，我们先根据基尔霍夫定律列出方程，然后进行拉氏变换，最后得到传递函数。

### 传递函数的零点和极点及其对输出的影响
系统微分方程的一般表达式为：$(a_0 s^n + a_1 s^{n - 1} + \cdots + a_{n - 1} s + a_n )C(s) = (b_0 s^m + b_1 s^{m - 1} + \cdots + b_{m - 1} s + b_m )R(s)$。系统传递函数的一般表达式为$G(s)=\frac{b_0 s^m + b_1 s^{m - 1} + \cdots + b_{m - 1} s + b_m}{a_0 s^n + a_1 s^{n - 1} + \cdots + a_{n - 1} s + a_n}$。将传递函数的分子与分母多项式分别用因式连乘的形式表示，其中根就是传递函数的零点和极点。把传递函数的零、极点表示在复平面上的图形就是系统的零、极点图，零点用“O”表示，极点用“×”表示。

### 典型环节的传递函数
不同的物理系统，从数学模型来看，一般可看作由若干个典型环节组成。研究这些典型环节的特性有助于了解系统性能。比如比例环节，其微分方程为$c(t)=Kr(t)$，取拉氏变换得$C(s)=KR(s)$，传递函数为$G(s)=K$。单位阶跃响应为$c(t)=K$。常见振荡环节的实例有机械位移系统、他激直流电动机、RLC电路等。

## 第三节 控制系统的结构图和信号流图
### 结构图的组成
#### 方框（Block Diagram）和信号线（Single Line）
方框表示输入到输出单向传输间的函数关系。
#### 比较点（合成点、综合点）Summing Point
对指向该点的信号进行加减运算，“+”表示相加，“-”表示相减，“+”号可省略不写。要注意进行相加减的量必须具有相同的量纲。
#### 分支点（引出点、测量点）Branch Point

### 结构图的绘制
绘制结构图的步骤如下：
1. 列写系统的微分方程组，并求出其对应的拉氏变换方程组。
2. 从输出量开始写，以系统输出量作为第一个方程左边的量。
3. 每个方程左边只有一个量。从第二个方程开始，每个方程左边的量是前面方程右边的中间变量。列写方程时尽量用已出现过的量。
4. 输入量至少要在一个方程的右边出现；除输入量外，在方程右边出现过的中间变量一定要在某个方程的左边出现。
5. 按照上述整理后拉氏变换方程组的顺序，从输出端开始绘制系统的结构图。

### 闭环系统的结构图
一个闭环负反馈系统通常用特定的结构图表示。输出量$C(s)$反馈到相加点，与参考输入量$R(s)$进行比较。图中各信号之间的关系为$C(s)=G(s)E(s)$，$E(s)=R(s)-B(s)$，$B(s)=H(s)C(s)$。其中$E(s)$和$B(s)$分别为偏差信号和反馈信号的拉氏变换，$H(s)$为闭环系统中的反馈传递函数。反馈信号$B(s)$与偏差信号$E(s)$之比叫做开环传递函数，输出量$C(s)$和偏差信号$E(s)$之比叫做前向传递函数。如果反馈传递函数等于$1$，那么开环传递函数和前向传递函数相同，这时的闭环反馈系统为单位反馈系统。通过推导可以得到系统输出量$C(s)$和输入量$R(s)$之间的闭环传递函数。

### 扰动作用下的闭环系统
实际系统经常会受到外界扰动的干扰。对于扰动作用下的闭环系统，根据线性系统满足叠加性原理的性质，可以先对每一个输入量单独处理，然后将每个输入量单独作用时相应的输出量进行叠加，得到系统的总输出量。分别求出系统对扰动的传递函数和对参考输入的传递函数，进而得到总响应。

### 结构图的简化和变换规则
对结构图进行简化和变换的基本原则是等效原则，即变换前后该部分的输入量、输出量及其相互之间的数学关系应保持不变。具体规则如下：
1. **串联环节的简化**：几个环节首尾连接，前一个环节的输出是后一个环节的输入，这种结构为串联环节。其等效传递函数为各环节传递函数的乘积。
2. **并联环节的简化**：两个或多个环节具有同一个输入信号，以各自环节输出信号的代数和作为总的输出信号，这种结构为并联环节。其等效传递函数为各环节传递函数之和。
3. **反馈回路的简化**：根据闭环传递函数的形式可以对基本反馈回路进行简化。
4. **相加点和分支点的移动**：包括相加点前移、相加点后移、分支点前移和分支点后移四种基本情况，以及相邻相加点和相邻分支点之间的移动。

### 信号流图
#### 信号流图中的术语
- **输入节点（源）**：仅具有输出支路的节点。
- **输出节点（阱）**：仅有输入支路的节点。若信号流图中没有这样的节点，可定义任一变量为输出变量，引出一条增益为$1$的支路形成输出节点。
- **混合节点**：既有输入支路又有输出支路的节点。
- **通道**：沿支路箭头方向穿过各相连支路的途径。开通道与任一节点相交不多于一次；闭通道的终点就是起点，且与任何其他节点相交不多于一次。
- **前向通道**：从输入节点到输出节点的通道上，通过任何节点不多于一次的通道。前向通道增益为前向通道上各支路增益之乘积。
- **回路**：起点和终点在同一节点，并与其它节点相遇仅一次的通路。回路增益为回路中所有支路的乘积。不接触回路是指回路之间没有公共节点的回路。

#### 信号流图的性质
- 信号流图适用于线性系统。
- 支路表示一个信号对另一个信号的函数关系，信号只能沿支路上的箭头指向传递。
- 在节点上可以把所有输入支路的信号叠加，并把相加后的信号送到所有的输出支路。
- 具有输入和输出支路的混合节点，通过增加一个具有单位增益的支路可以把它作为输出节点来处理。
- 对于一个给定的系统，信号流图不是唯一的。

#### 梅逊公式
用梅逊公式可以直接求信号流图从输入节点到输出节点的增益，表达式为$P=\frac{\sum_{k = 1}^{n}P_k\Delta_k}{\Delta}$。其中$P$为系统总增益（对于控制系统的结构图而言，就是输入到输出的传递函数），$k$为前向通道数目，$P_k$为第$k$条前向通道的增益，$\Delta$为信号流图的特征式，$\Delta_k$为第$k$条前向通道$P_k$的余因式。

## 总结
同学们，这一章我们学习了控制系统的数学模型，包括时域数学模型（微分方程）、复数域数学模型（传递函数），还学习了控制系统的结构图和信号流图。我们掌握了建立微分方程的方法、拉氏变换和反变换的知识，学会了利用结构图和信号流图来分析系统，以及运用梅逊公式求解系统的传递函数。这些知识是后续分析系统性能、进行系统设计和校正的基础，大家一定要好好掌握。在后续的学习中，我们将运用这些数学模型来分析系统的时域性能、根轨迹和频率特性等内容。希望大家课后多做练习，加深对这些知识的理解和掌握。
