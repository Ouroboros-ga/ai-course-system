## 一、作品阐述

**作品名称**：CodeNexus 智码交响
**一句话定位**：以 DeepSeek 为基座、以可追溯学科知识图谱为核心的计算机学科垂类大模型与智能体应用。
产品收敛为两个智能体入口——课程内 **TeachingAgent**（教学问答、对话式代码挑战）与课程外 **Nexus AI**
（复杂问题拆解、论文研究、快速复现），由领域微调 7B 模型 + CS 学科知识库 RAG + 多智能体协作承载，
让"AI 深度赋能、人机高效协同"在计算机一流学科建设中可运行、可追溯、可复制。

**解决的现实问题**：
1. 教学端：教师备课/出题/学情分析耗时高，内容质量与来源难保障；
2. 学习端：学生知识问答易得"幻觉答案"，学习路径无个性化，代码纠错缺可信执行环境；
3. 科研端：论文调研与复现门槛高，研究过程难以沉淀与追溯——需要把"从论文到可运行复现"
   的复杂任务交给可信智能体持续执行。

**学科选择**：计算机科学与技术（CS）——课程标准化程度高、知识图谱结构清晰、代码实验可沙箱验证，
最能体现"学科垂类模型 + 智能体 + 可追溯"的组合优势。

## 三、技术方案

### 3.1 总体架构（五层）

平台接入与应用交互层（Vue 3 shadow 前端 `/app/**`）→ 课程业务与发布层（草稿/版本/发布回滚）
→ 智能体协作层（双入口：课程内 TeachingAgent + 课程外 Nexus AI 独立 Runtime；内部实现物理分离 +
Port/Provider/治理）→ 课程知识与证据层（DocumentIR/证据/图谱/知识包/索引）
→ 基础设施（PostgreSQL 16 + pgvector、LanceDB、Judge0、LLM Provider）。

### 3.2 学科垂类大模型（三层）

1. **基座**：DeepSeek（`LLM_PROVIDER=deepseek`，OpenAI 兼容 `https://api.deepseek.com/v1`，
   `deepseek-chat`，2026-08-20 决策并完成 10 用例实测 9/9；Provider 可插拔，
   豆包/通义等亦可切换）；
2. **领域增强**：CS 学科知识库（112 节点/106 关系，数据结构/算法/操作系统/计算机网络/数据库/软件工程/机器学习/编译原理/计算机组成原理/离散数学/计算机图形学 11 门课，权威教材来源）→ 只读检索服务
   （BM25 风格 + CJK 二元组、中英双语、可追溯）+ 课程级 RAG（BM25 + BGE + RRF + Citation 闭包约束）；
3. **领域微调**：Qwen2.5-7B-Instruct + LoRA v2.2（2026-09-09 云端 RTX 4090 实测训练：2212 条指令集/50 评测，
   3 epochs = 417 步，train_loss 0.667/0.669，可训练参数 40.37M；评测基准 10 问只进 eval 集防污染；
   评测如实记录"基座 4/8 vs 微调 3/8"，不宣称提升）。详见
   [微调交付记录](../../docs/phase1/2026-09-09_XH202620微调交付记录.md)。

### 3.3 智能体（双入口）

- **TeachingAgent（课程内）**：22 节点 LangGraph 工作流，课程/学生/能力三重校验，六维认知个性化，
  高风险动作需确认；对话式代码挑战经 Judge0 服务端验证，不猜测运行结果；
- **Nexus AI（课程外全局入口）**：Deep Agents + LangGraph 独立 Runtime（独立 Python 环境/进程，与
  课程业务隔离），复杂问题拆解、论文研究、快速复现；一次确认后自主执行，内部修复不逐步审批；
- 内部实现层：Prep Agent 备课提案（`evidence_refs` 硬门 + 教师审核双门控）；旧 ResearchAgent 科研
  工作台转 Legacy，由 Nexus 替代下线。

### 3.4 可信与安全

证据锚定双门控、版本快照不可变可回滚、Course Access v1 最小权限、四域数据分离、
AI 生成内容标识、密钥不入前端/日志/仓库、沙箱隔离执行。

## 六、创新之处

1. **学科垂类三件套**：DeepSeek 基座 + 学科知识库 RAG + 可复现微调管线，形成"模型可替换、
   知识可追溯、微调可复现"的完整闭环；
2. **以证据而非流畅度评价生成内容**：Citation 闭包三重约束 + 双门控审核，杜绝幻觉答案进入正式课程；
3. **四智能体协作、状态独立**：LangGraph 显式工作流（节点边界即权限边界）+ Port 契约，
   不共享跨课程可变状态；
4. **教学-科研一体化**：同一课程上下文贯通助教/助学/助研，研究结果可回流为教学素材（经教师审核）；
5. **诚实可验证**：全部能力有代码/测试/文档证据，未实现项明确标注，不做伪实现。
