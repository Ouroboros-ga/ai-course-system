## 1. 批量评测（自动判定，10 分钟）

```bash
cd backend
python finetune/evaluate.py \
  --base-url https://spark-api-open.xf-yun.com/v1 \
  --api-key $XFYUN_SPARK_API_KEY \
  --model 4.0Ultra \
  --output finetune/results_4.0Ultra.json
```

- 输出：`results_4.0Ultra.json`，每用例含 `output` 与 `passed`（C3 为 `judge0_manual`，需人工补沙箱执行）
- 判定规则：`contains`（输出须含全部 markers）；C8 数值用例注意容差（0.8/0.667/0.727）

## 5. 常见问题

- **端点 401**：`XFYUN_SPARK_API_KEY` 配置错误或额度不足；密钥只在命令行传入，不写入任何文件
- **部分 markers 未命中**：模型表达方式不同（如"0.80"而非"0.8"）——先人工判断正确性，再微调 markers 或记录人工判定
- **C3 无法自动判定**：属设计行为（`judge0_manual`），必须沙箱执行后人工确认，不得跳过
