## 当前可信事实

- 已注册的主流程路由集中在 `backend/app/main.py`：课件上传、脚本/映射、PPT、TTS、数字人、课程学习、进度、问答和前置知识跳转均有实际入口。
- M4B/M7 使用受控 fake 覆盖教师建课到学生学习的关键接口流程；它们证明契约和控制流，不证明真实模型、TTS、PPT、数字人质量。
- 真实 Duix 部署仍是 `WAITING_FOR_HARDWARE`；比赛现场应按 M7 文档准备预生成视频和降级链路。
- 计算机垂类代码执行、GraphRAG、BKT/HMM/LSTM、复杂多智能体不是当前功能，不能用于对外完成度表述。

| 任务 | 首选资料/命令 |
|---|---|
| 启动服务 | [RUN.md](RUN.md)；实际环境与依赖以代码和本机配置为准 |
| 查 API 事实 | `backend/app/main.py`、endpoint 源码、[路由契约基线](phase1/路由契约基线.md)，不要以 [api接口文档.md](api接口文档.md) 为准 |
| 改主流程前 | [API-Service-Model-外部依赖矩阵](phase1/API-Service-Model-外部依赖矩阵.md)、[关键业务回归矩阵](phase1/关键业务回归矩阵.md) |

| 看重构状态 | [文档状态审查清单](文档状态审查清单.md) 与 `docs/refactor/` 相应阶段报告 |
