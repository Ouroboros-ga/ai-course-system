### F1 · 老师素材管理（已完成）
> 上传人脸视频 + 参考音频，绑定账号，多课复用

```
上传mp4人脸视频 / mp3参考音频 → 存储并绑定老师账号 → 创建课程时自动选用默认素材
```

---

### F2 · 知识点↔PPT映射引擎（已完成）
> 建立知识点与PPT页面的双向对应关系

```
老师上传PPT → 逐页提取文本 → 与知识点语义匹配 → 建立映射表
AI生成PPT  → 生成时自动建立映射

老师可在课程管理界面，根据实际教学情况，调整知识点与PPT页面的对应关系。前端需要有这个更改调整界面。
更新关系后，需要在视频生成前，根据调整后的映射关系，重新解析脚本。

```

---

### F3 · AI生成PPT课件
> 老师输入大纲和知识点，AI生成完整PPT

```
老师输入(大纲/主题/知识点列表)
    → LLM扩展为结构化教学脚本
    → 脚本输入科大讯飞ppt生成API，接收生成.pptx课件
    → 自动进入解析管线，产出知识点映射表（f2知识点↔PPT映射引擎）
```

---

### F4 · 视频脚本编辑
> 老师后台编辑讲解文本，插入PPT翻页标记

```
查看脚本知识点树 → 编辑讲解文本 → 插入翻页标记(哪句话翻到哪页PPT) → 选择音色/数字人素材 → 预览单节点效果 → 版本管理
```

#### 🔧 核心算法

**1. 视频-PPT同步机制（二分查找优化）**

```python
def find_node_by_time(timestamp, nodes):
    """根据时间戳查找当前节点 - O(log n)复杂度"""
    left, right = 0, len(nodes) - 1
    while left <= right:
        mid = (left + right) // 2
        node = nodes[mid]
        if node.timestamp_start <= timestamp <= node.timestamp_end:
            return node
        elif timestamp < node.timestamp_start:
            right = mid - 1
        else:
            left = mid + 1
    return None
```

**2. 断点续播策略**

- 自动保存频率：每10秒 + 暂停时 + 页面卸载时
- 保存内容：当前时间戳、节点索引、PPT页码、已完成节点列表
- 恢复时机：进入播放器页面时自动调用进度API

**3. 知识点跳转逻辑**

```javascript
function jumpToKnowledgePoint(point) {
  // 1. 跳转到对应时间戳
  video.currentTime = point.timestamp_start

  // 2. 更新UI状态
  currentNodeIndex = point.node_index
  currentPage = point.page_start

  // 3. 自动播放
  if (!isPlaying) togglePlay()
}
```

 v#### 🔧 F5映射引擎关键修复（2026-05-26）

**问题背景：**
F6分屏视频播放器依赖F5映射引擎提供两类关键数据：
1. **时间戳数据** (`timestamp_start/end`) - 用于视频-PPT时间同步
2. **页码映射** (`page_start/end`) - 用于PPT页面切换

**发现的问题：**
- ❌ 时间戳数据完全缺失（整个代码库无生成逻辑）
- ⚠️ 页码数据需手动触发"应用到脚本"操作

**修复方案（已实施）：**

| 步骤 | 修改文件 | 内容 |
|------|----------|------|
| 1️⃣ | `document_service.py` | 扩展ScriptNode临时类，添加timestamp字段 |
| 2️⃣ | `document_service.py` | 新增`_estimate_timestamps()`方法，脚本生成时预估时间戳 |
| 3️⃣ | `document.py` | 数据库写入时包含timestamp字段 |
| 4️⃣ | `mapping_service.py` | 新增`calculate_timestamps_from_audio()`方法，TTS后更新精确值 |
| 5️⃣ | `video_generation_service.py` | 集成时间戳更新调用（批量生成完成后自动执行） |
| 6️⃣ | `player.py` (F6 API) | 优先使用KnowledgePageMap表读取页码数据 |

**数据流完整性验证：**

```
✅ 脚本生成阶段 → 自动预估时间戳（基于duration按比例分配）
✅ 数据库写入   → timestamp字段完整存储到ScriptNode表
✅ TTS合成完成 → 基于实际音频时长重新计算精确时间戳
✅ F6播放器读取 → 时间戳非零 + 页码使用映射表精确数据
```

**测试覆盖：**
- ✅ 编写完整单元测试：`backend/tests/test_f5_mapping_fix.py`
- 覆盖场景：字段定义、时间戳预估、TTS精确计算、播放器API优先级

**修复效果：**
- F6播放器依赖满足度：50% → **100%** 🎉
- 视频-PPT同步功能：从完全失效 → **正常可用**
