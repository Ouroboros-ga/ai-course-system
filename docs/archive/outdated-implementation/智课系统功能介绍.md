# AI互动智课系统 — 功能介绍

---

## 系统定位

**老师输入课件 → AI生成数字人讲课视频 → 学生自适应学习**

一句话：老师提供素材和大纲，AI自动生成PPT课件和数字人讲课视频，学生观看视频学习，做错题时AI针对性重讲。

---

│       ↓                              │     │  ⑦ AI互动问答检验理解度        │
│  ③ AI生成PPT课件                     │     │       ↓                      │
│       ↓                              │     │  ⑧ 做错题 → AI针对性重讲       │
│  ④ 编辑视频脚本 + 翻页标记            │     │     → 弹出重讲视频             │

## F1 · 老师素材管理 ✅

**上传人脸视频和参考音频，绑定账号，多课复用**

### 核心功能
- 上传mp4人脸视频 / mp3参考音频 → 绑定老师账号
- 设置默认素材，创建课程时自动选用
- **声音复刻**：上传参考音频 → AI克隆音色 → TTS使用克隆声音讲课
- 素材管理：上传、删除、设为默认

### 技术实现
- 后端：`/api/v1/assets/` 素材CRUD + 声音复刻接口
- 存储：本地文件系统 `teacher_assets/` 目录
- 声音复刻：火山引擎豆包语音API（ICL2.0）
- 支持格式：视频(mp4)、音频(mp3/wav)

---

## F2 · 知识点↔PPT映射引擎 ✅

**建立知识点与PPT页面的双向对应关系**

### 核心功能
- **自动映射**：上传PPT后自动建立知识点→页面映射
- **AI智能匹配**：LLM语义分析，精准匹配知识点与PPT页面
- **手动调整**：老师在前端拖拽/输入页码范围
- **应用映射**：更新脚本节点的page_start/page_end

### 技术实现
- 后端：`/api/v1/mapping/` 映射管理接口
- Docling解析：逐页提取PPT文本
- AI匹配：豆包大模型语义分析
- 前端：MappingEditor组件，可视化编辑映射

---

## F3 · AI生成PPT课件 ✅

**老师输入大纲和知识点，AI生成完整PPT课件**

### 核心功能
- 输入：课程主题 + 大纲 + 知识点列表
- LLM扩展为结构化教学脚本
- 科大讯飞PPT API生成.pptx课件
- **自动进入解析管线**：生成后自动解析→脚本→映射

### 技术实现
- 后端：`/api/v1/ppt-generation/` PPT生成接口
- LLM：豆包大模型扩展教学脚本
- PPT生成：科大讯飞智能PPT API
- 异步生成：支持同步/异步两种模式

---

## F4 · 视频脚本编辑 ✅

**老师编辑讲解文本，选择音色和数字人素材，预览效果**

### 核心功能
- **知识点树**：可视化展示课程结构
- **编辑讲解文本**：每个知识点独立编辑，AI自动生成TTS友好讲解稿
- **素材与音色设置**：选择人脸视频、参考音频、语音音色
- **预览语音**：点击按钮试听TTS合成效果
- **版本管理**：创建快照、回滚到历史版本
- **翻页标记**：标记PPT翻页位置（待前端完善）

### 技术实现
- 后端：`/api/v1/document/` 脚本编辑 + TTS预览 + 版本管理
- TTS：火山引擎语音合成（支持预置音色和克隆音色S_xxx）
- 版本管理：快照创建/回滚/列表查询
- AI讲解稿：自动将课件内容转为口语化TTS讲解文本

## F5 · 视频生成管线 🔧

**脚本 → TTS语音 → 数字人视频 → 分屏合成**

### 已实现 ✅
- **TTS合成语音**：支持预置音色和克隆音色，输出wav格式
- **数字人视频生成**：音频 + 人脸视频 → Gradio API → 数字人讲课视频
- **任务管理**：VideoGenerationTask记录生成状态（pending→tts→dh→completed）
- **批量生成**：课程级批量生成（异步后台任务）
- **单节点生成**：同步生成单个知识点视频
- **健康检查**：数字人服务可用性检测

## F6 · 学生学习界面 🔧

**学生观看数字人讲课视频，AI互动问答**

### 已实现 ✅

- **断点续播**：记录学习进度，下次继续

## F7 · 错题重讲闭环 📋

**做错题 → AI针对性重讲 → 弹出视频**

### 规划流程
```
学生做错题
  → AI分析错误原因 + 定位薄弱知识点
  → 生成针对性重讲脚本（换类比/换例子，2-3分钟）
  → 生成重讲视频（数字人+PPT）
  → 弹出播放
  → 观看完毕 → 更新理解度
```

### 核心价值
- 个性化：针对每个学生的薄弱点定制重讲内容
- 即时性：做错后立即重讲，趁热打铁
- 多角度：换类比、换例子，避免重复无效讲解

## 技术架构

### 后端
| 组件 | 技术 |
|------|------|
| 框架 | FastAPI + Uvicorn |
| 数据库 | SQLite + SQLModel |
| LLM | 豆包（火山引擎） |
| TTS | 火山引擎语音合成 |
| 声音复刻 | 豆包语音ICL2.0 |
| PPT生成 | 科大讯飞智能PPT API |
| 文档解析 | Docling |
| 数字人 | Gradio API |

### 前端
| 组件 | 技术 |
|------|------|
| 框架 | Vue 3 + Vite |
| 状态管理 | Pinia |
| 路由 | Vue Router |
| HTTP | Axios |
| 图表 | Chart.js + vue-chartjs |
| Markdown渲染 | marked + highlight.js + KaTeX |

### API设计
- RESTful风格，统一响应格式
- JWT身份认证（老师/学生/管理员角色）
- 泛雅平台签名验证中间件
- CORS跨域支持
