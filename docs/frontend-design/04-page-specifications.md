> 证据口径沿用 [01-project-audit.md](./01-project-audit.md)：`已实现` 表示已存在可执行代码或接口，`规划中` 表示项目文档明确提出但当前未形成稳定产品能力，`推导项` 仅用于连接已有流程，`待确认` 表示证据不足。原型中的规划项一律显示为 Mock 或禁用状态，不伪装成已上线能力。

## P0-A 学生课程学习空间

### 页面任务

- **页面目标**：让学生在同一学习上下文中完成观看、定位知识点、课程问答、查看依据、前置补学与返回，尽量不打断主学习线。
- **主要用户**：已登录且已选课的学生。
- **用户进入时想完成什么**：从上次位置继续；理解当前知识点；在不离开课程的情况下提问；完成必要补学后准确回到原位置。
- **现状依据**：`StudentDashboard.vue`、`StudentPlayer.vue`、`useStudentLearning.js` 已覆盖课程、播放、进度、问答、测验与前置分析，但这些能力分散；稳定引用与低置信度协议尚未形成。
- **优先级**：P0；独立Mock原型已完成，下一步按07-implementation-plan.md的M2渐进接入正式学生页面。

### 入口、出口与上下文保存

| 类型 | 位置 | 行为 |
|---|---|---|
| 正式入口（现状） | `/student/course/:courseId`、`/player/course/:courseId` | 进入现有学习页或播放器 |
| 原型入口 | `/prototype/student-learning/:courseId?` | 学生角色可进入，页面顶部明确标注 `设计原型 · Mock 数据` |
| 正常出口 | 返回我的课程 | 回到 `/student`；正式接入时先保存播放进度 |
| 补学出口 | 前置知识抽屉/补学模式 | 不创建多层路由；保留 `courseId/nodeId/time/questionId` 返回锚点 |
| 恢复出口 | 返回原讲解位置 | 恢复播放时间、知识点选中、智能体会话上下文和展开的引用 |

### 页面区域

1. **课程上下文顶栏（56px）**：返回、课程名、章/知识点、进度、播放状态、保存状态、专注模式、全屏。
2. **目录轨（桌面 264px）**：搜索、章节折叠、知识点状态、当前高亮、前置知识入口；小屏转抽屉。
3. **学习主舞台（弹性宽度）**：不同时平铺所有媒介，而是在同一时间轴上提供两个任务模式；模式切换保留当前页、播放时间、知识点和问答上下文。
   - `跟随讲解`：数字人/课程视频承担连续讲解主画面；当前 PPT 页作为常驻但可折叠、可放大的辅助画面，不能因模式切换完全消失；当前讲解只显示一段精简字幕/摘要。
   - `课件研习`：PPT 成为主画面，右/下方是学生自己的笔记；讲解全文折叠为按需参考，不占据持续视觉空间。
4. **智能体协作轨（桌面 352px，可折叠）**：建议问题、问题输入、回答、引用、反馈、置信度提示、补学建议；小屏转底部全高抽屉。
5. **学习锚点条**：进入补学后常驻，显示原知识点、原时间和“返回原位置”。

### 数据字段

| 对象 | 字段 | 依据与处理 |
|---|---|---|
| 课程 | `courseId/name/progress/currentNode` | 已实现；原型用独立 Mock |
| 目录节点 | `id/title/status/duration/prerequisites` | 目录、进度已实现；前置关系由现有 prerequisite 路由支持 |
| 播放状态 | `time/duration/playing/rate/subtitles/savedAt` | 播放和进度已实现；保存状态是现有同步行为的可视化推导 |
| 学习模式 | `stageMode: guided\|study`、`noteDraft` | 模式切换与笔记区为推导项；首轮原型本地 Mock，不宣称已有笔记接口 |
| 讲解内容 | `slide/page/transcript/evidenceAnchor` | slide/script 已实现；稳定 evidence anchor 属规划中 |
| 问答 | `question/answer/conversationId/streaming` | 问答已实现；前端现有流式为模拟，需明确状态 |
| 引用 | `sourceTitle/page/blockId/quote/locatable` | Evidence/DocumentIR 规划中；正式接入前不得声称可稳定定位 |
| 置信度 | `level/reason/fallback` | 规划中；当前原型只演示交互语义 |
| 返回锚点 | `nodeId/time/questionId/expandedCitationIds` | 推导项；用于保证学习不中断 |

### 操作与核心交互

- **继续学习**：初始化后定位上次节点和时间；无进度则从课程首个可学节点开始。
- **选择知识点**：先写入当前进度，再切换课件、讲解与智能体上下文；加载期间保持目录可用。
- **切换学习模式**：使用主舞台顶部的分段切换器；`跟随讲解` 与 `课件研习` 共享同一时间轴和 PPT 页，不重新加载课程，也不清空笔记或智能体对话。键盘可用方向键切换，语义采用 `role=tablist`。
- **调换主次画面**：跟随讲解中可将当前 PPT 临时放大为主画面，视频缩为画中画；再次操作恢复。该动作不等于切换到课件研习，不改变笔记布局和播放上下文。
- **折叠目录/智能体**：桌面释放主舞台空间；折叠按钮具有 `aria-expanded`。
- **提问**：提交后展示明确的生成中状态；回答结束后允许追问、复制、反馈。
- **查看引用**：默认只显示来源摘要；展开后显示页码与短摘录；“定位”只在 `locatable=true` 时可用。
- **低置信度回答**：不以红色报错处理，使用琥珀提示并给出核验、换问法、反馈三个下一步。
- **前置补学**：打开同层补学视图并创建恢复锚点；返回后恢复原状态，避免浏览器后退链迷失。
- **全屏/专注模式**：全屏使用浏览器 API；不支持时进入页面级专注模式，按钮文本和状态同步更新。

### 状态规格

| 状态 | 表现 | 恢复动作 |
|---|---|---|
| 首次加载 | 目录骨架、舞台占位、智能体输入禁用；不整页白屏 | 自动完成或显示重试 |
| 切换知识点 | 舞台局部加载，保留目录与问答历史 | 可选择其他节点 |
| 空课程 | 说明课程尚未发布内容 | 返回课程列表 |
| 无问答历史 | 推荐问题 + 输入说明 | 提交第一个问题 |
| 回答生成中 | 流式占位、停止按钮、`aria-live=polite` | 停止后保留已生成部分 |
| 引用不可定位 | 来源可读但定位按钮禁用，并说明协议未接入 | 返回回答 |
| 进度保存失败 | 顶栏显示“未保存”，不阻断播放 | 立即重试/稍后自动重试 |
| 媒体错误 | 主舞台显示错误原因和重载；课件文本仍可访问 | 重载媒体/切换纯课件 |
| 无权限/未选课 | 不展示课程内容 | 返回课程大厅或发起选课 |
| 成功 | 保存状态、完成节点和返回恢复使用克制的绿色反馈 | 无弹窗 |

### 响应式与可访问性

- `>= 1280px`：三轨布局；目录 264px、智能体 352px，主舞台最小 560px。
- `1024–1279px`：目录压缩至 232px；智能体默认折叠，由按钮展开覆盖面板。
- `768–1023px`：目录、智能体均为抽屉；主舞台单列；控制栏允许两行。
- `< 768px`：顶部只保留返回、上下文、目录和智能体入口；课件比例自适应；底部控制固定但不遮挡字幕。
- 任意断点只呈现当前学习模式的核心内容，不把视频、PPT、全文讲解和笔记纵向连续堆叠；小屏模式切换固定在主舞台顶部。
- 所有图标按钮有可读名称；触控目标不小于 44px；焦点环不被 `overflow` 裁切；颜色不是唯一状态信号；视频提供字幕入口；讲解文本、公式、代码与引用具备足够行高和横向滚动容器；尊重 `prefers-reduced-motion`。

### 所需接口、缺口与组件

| 能力 | 当前接口/代码 | 缺口 |
|---|---|---|
| 课程初始化/目录/幻灯片 | player、document、progress 路由与现有 composable | 前端返回结构需统一适配层 |
| 保存/恢复进度 | player/progress resume/save/sync | 保存冲突和离线重试语义待确认 |
| 问答/历史/测验 | chat routes | 当前引用、置信度、停止生成协议不足 |
| 前置补学/返回栈 | prerequisite routes | 返回锚点需要前端统一状态模型 |
| 引用定位 | Evidence Viewer 与 DocumentIR 规划 | 尚不是学生正式接口，原型必须 Mock |

复用组件：`CourseOutlineTree`、`LearningStage`、`PlaybackControls`、`TranscriptViewer`、`QuestionComposer`、`AgentAnswer`、`CitationList`、`EvidencePreview`、`PrerequisitePath`、`LearningAnchorBar`、`StatusBadge`。

## P0-B 教师课程生产工作台

### 页面任务

- **页面目标**：把现有上传、解析、结构、脚本、映射、音频/PPT/数字人生成、预览与发布组织成一条可检查、可回退、可局部重试的生产流水线。
- **主要用户**：课程创建者和拥有课程编辑权限的教师。
- **用户进入时想完成什么**：知道课程处于哪一步、当前阻塞原因、需要自己确认什么；完成本步骤并安全推进到发布。
- **现状依据**：`TeacherDashboard.vue` 已承载多数生产能力，document/mapping/ppt/video/asset 路由提供实际能力；统一长任务与 DocumentIR 质量队列仍在规划。
- **优先级**：P0；独立Mock原型已完成，下一步按07-implementation-plan.md的M3为现有TeacherDashboard增加兼容工作台壳，再逐步迁移内部工具。

### 入口、出口与导航

| 类型 | 位置 | 行为 |
|---|---|---|
| 正式入口（现状） | `/teacher/create`、`/teacher/course/:courseId` | 新建或编辑现有课程 |
| 原型入口 | `/prototype/teacher-pipeline/:courseId?` | 教师角色可进入，明确 Mock 标识 |
| 出口 | 返回课程列表 | `/teacher/history`；长任务继续执行的语义必须可见 |
| 预览 | 课程预览模式 | 保留当前步骤与滚动位置，关闭后返回 |
| 发布 | 发布检查通过后执行 | 未满足门禁时禁用并显示原因，不打开连续弹窗 |

### 页面区域

1. **课程顶栏（56px）**：返回、课程名、版本、保存状态、预览、发布、更多。
2. **生产流程轨（248px）**：步骤序号、状态、警告/失败数；支持折叠，小屏转抽屉。
3. **中心工作区**：随步骤显示上传器、解析结果、章节树、知识点/脚本编辑、映射、生成任务或预览。
4. **检查轨（336px）**：质量检查、AI 建议、任务日志三个标签；当前步骤说明、缺失项、错误原因、重试与人工确认。
5. **长任务停靠条**：显示跨步骤任务进度、预计状态、离开页面提示和任务中心入口。

### 流程状态模型

| 状态 | 含义 | 可进入下一步 |
|---|---|---|
| `not_started` | 尚无输入或未触发 | 否 |
| `processing` | 系统/AI 长任务执行中 | 可浏览，不能确认完成 |
| `generated` | 机器产物已生成，尚未教师检查 | 否；显示 `AI 生成` |
| `review_required` | 存在待检查项 | 否 |
| `confirmed` | 教师已确认当前版本 | 是 |
| `warning` | 可继续但需记录风险 | 视质量门禁配置 |
| `failed` | 当前步骤失败 | 否；允许步骤级重试 |
| `stale`（规划语义） | 上游修改后下游产物可能过期 | 否；需局部重新生成或重新确认 |

“生成成功”不得自动变成“已完成”；版本变化后应重新评估下游状态。当前后端没有统一状态机，本页先定义前端表现和集成契约，不改后端协议。

### 数据字段

| 对象 | 字段 |
|---|---|
| 课程 | `courseId/name/version/status/updatedAt/saveState/owner` |
| 流程步骤 | `key/title/status/progress/warnings/blockers/reviewedAt` |
| 资料 | `assetId/name/type/size/uploadState/parseTaskId` |
| 解析质量 | `pageCount/blockCount/warnings/quality/evidenceCoverage`（后两项属规划） |
| 结构节点 | `chapterId/nodeId/title/order/sourceRefs/reviewState` |
| 脚本块 | `blockId/text/duration/generated/sourceRefs/slidePage/dirty` |
| 生成任务 | `taskId/type/status/progress/createdAt/error/retryable` |
| 发布门禁 | `id/title/status/severity/actionTarget` |

### 操作与核心交互

- **切换步骤**：任何步骤可回看；离开有未保存更改时在页面内提示保存，而非连续弹窗。
- **人工确认**：只有具备编辑权限且无阻断项时可确认；记录确认人、时间和版本。
- **局部重新生成**：选中脚本块/节点执行，明确将受影响的映射、音频、数字人产物标记为待复核。
- **长任务**：触发后停靠条持续显示；允许离开页面；失败卡片展示错误摘要、日志入口和重试。
- **失败重试**：仅重试失败步骤/节点；按钮执行后进入 processing，避免重复提交。
- **发布检查**：列表内直接跳转到问题步骤；全部阻断项通过后才启用发布。
- **版本处理**：现有快照/回滚能力保留；规划中的内容版本体系只做信息架构占位，不新增接口。

### 状态规格

| 状态 | 表现 | 恢复动作 |
|---|---|---|
| 页面加载 | 顶栏和三轨骨架，发布按钮禁用 | 自动/重试 |
| 新课程空态 | 流程定位“基本信息”，解释下一步 | 填写基本信息 |
| 无资料 | 上传区域说明支持的真实格式，不承诺未验证格式 | 上传资料 |
| 处理中 | 步骤和停靠条双处显示一致进度 | 可离开/查看日志 |
| 待人工检查 | 琥珀状态 + 清单，AI 产物标识克制 | 修改/确认 |
| 失败 | 红色仅用于阻断项，显示错误原因 | 重试/查看日志 |
| 保存冲突 | 保留本地编辑并说明版本冲突 | 对比后重试，正式接口待确认 |
| 成功确认 | 步骤变为绿色已确认，不弹出庆祝动画 | 进入下一步 |
| 无权限 | 只读预览，隐藏修改/生成/发布 | 返回列表 |
| 发布成功 | 版本状态更新并提供学生端预览入口 | 返回列表/继续维护 |

### 响应式与可访问性

- `>= 1360px`：流程轨 248px、检查轨 336px，中心最小 640px。
- `1100–1359px`：检查轨可折叠；流程轨 220px。
- `768–1099px`：流程轨和检查轨均转抽屉；中心编辑区优先；长任务条允许两行。
- `< 768px`：提供审核、任务查看和轻量文本修改；复杂 PPT 映射明确提示建议桌面端完成，而不是挤压成不可用布局。
- 编辑器支持键盘遍历与清晰焦点；拖拽排序必须提供键盘替代；状态不只靠颜色；进度使用 `role=progressbar`；日志可复制；错误摘要与字段错误建立 `aria-describedby`；生成状态通过 `aria-live` 克制播报。

### 所需接口、缺口与组件

| 能力 | 当前依据 | 缺口 |
|---|---|---|
| 课程/脚本/版本/发布 | document routes | 多种返回结构需要统一前端 adapter |
| 资料上传/预览 | asset/document routes | 解析质量指标与稳定 Evidence 契约在规划中 |
| PPT 映射 | mapping routes | 上游变化导致映射过期的统一语义缺失 |
| TTS/PPT/数字人任务 | document/ppt/video-gen routes | 状态、进度、错误、重试未统一；部分任务进程内存化 |
| 质量门禁 | 现有字段校验 + DocumentIR/R2 规划 | 缺少统一质量检查与人工确认接口 |

复用组件：`CoursePipeline`、`PipelineStep`、`MaterialUploader`、`ParsingResultViewer`、`ChapterTreeEditor`、`KnowledgePointEditor`、`ScriptEditor`、`SlideScriptMapper`、`GenerationTaskCard`、`QualityGatePanel`、`PublishChecklist`、`VersionHistory`、`LongTaskDock`。
