# 学生端完整前端设计

> 目标：形成以课程学习现场为中心、以可信课程智能体为协作者、以学习不中断为约束的学生产品。规划中的认知、推荐和Memory只在证据、权限、删除与晋级门禁完成后进入正式导航。

## 1. 学生端设计原则

1. 学习内容始终是视觉主角，AI面板是协作者，不接管整个页面。
2. 视频、数字人、PPT、脚本和笔记共享一个PlaybackContext，不成为互相割裂的页面。
3. 补学、错题重讲和引用定位使用同层视图与恢复锚点，学生随时知道从哪里来、如何回去。
4. 建议必须解释原因和依据，不显示来源不明的“掌握度72%”。
5. 无证据、证据失效或无权限时明确停止或降级，不生成看似可信的引用。
6. Memory由学生可见、可关闭、可修改、可删除；跨课程默认不共享。
7. 移动端首先保证观看、PPT、问答、笔记和返回，复杂多栏内容改为互斥抽屉。

## 4. S01 学生首页

### 页面目标

用最少信息回答三个问题：我上次学到哪里、今天最应该做什么、哪些课程需要继续。

### 页面区域

1. 继续学习：一条主要课程，显示章节、知识点、最近时间、保存状态和继续按钮。
2. 今日任务：未完成练习、补学返回、教师指定任务；没有真实任务接口时不显示。
3. 我的课程：最多六门，进入完整课程页。
4. 学习建议：只有Recommendation带非空LearningEvidence引用并通过产品门禁时显示。
5. 最近问答：快速返回原课程、原知识点和原回答。

不展示课程总数、学习时长增长等无行动意义的大数字。首次进入时突出选择课程；加载失败按区域恢复，不整页阻断。

## 5. S02 我的课程

Tab为在学、已完成、可选课程。筛选只保留课程名、教师和状态；默认按最近学习排序。

课程项字段：封面、名称、教师、学习状态、最近知识点、进度、更新时间、主要动作。未选课程显示课程介绍和选课；已选课程显示继续学习；课程未发布或无权访问时不可进入内容。

选课成功后保持当前筛选并更新按钮；重复点击期间按钮禁用。退课属于高风险动作，必须说明学习记录是否保留；接口语义未确认前不设计一键退课。

## 6. S03 课程学习空间

基础状态和接口见04-page-specifications.md。本文件冻结双模式布局决策。

### 6.1 共享框架

顶部课程栏、左侧目录、中央学习舞台、右侧智能体、补学恢复条。所有模式共享以下状态：

~~~text
courseId
nodeId
playbackTime
slideNumber
scriptBlockId
conversationId
expandedCitationIds
noteAnchor
prerequisiteReturnAnchor
~~~

模式切换不得重新请求整门课程，不清空问答和笔记，不丢失播放位置。

### 6.2 跟随讲解

桌面主舞台采用70/30主辅布局：

- 主画面：数字人或课程视频；无视频时使用音频加课程视觉占位。
- 辅助画面：当前PPT页，始终可见，可折叠、放大或与视频调换主次。
- 底部：统一时间轴、播放、倍速、字幕、音量、当前知识点。
- 当前讲解：只显示正在讲的一段，完整脚本按需展开。

学生听公式、图表、代码或题目时不需要切换模式即可阅读当前课件。PPT辅助画面加载失败不阻断视频，但显示文本替代和重试。

### 6.3 课件研习

- 主画面：完整PPT，可翻页、缩放、搜索和定位知识点。
- 右/下区域：自己的笔记，默认绑定当前页、知识点和时间。
- 视频缩为可选迷你播放器；脚本与字幕放入可展开参考区。
- 翻页时可选择跟随播放或自由浏览。自由浏览结束提供“返回当前讲解页”。

### 6.4 智能体区域

消息结构为问题、回答正文、回答状态、引用摘要、下一步操作。推荐问题与当前知识点绑定但不自动发送。

Citation状态映射：

| 状态 | 学生文案 | 操作 |
|---|---|---|
| verified | 已核对课程资料 | 定位原文 |
| partial | 依据可读，定位可能有偏差 | 打开所在页 |
| stale | 来源已更新 | 查看新版/重新提问 |
| mismatch | 引用与原文不一致 | 不作为可靠依据、反馈 |
| no_evidence | 课程资料不足 | 查看相关章节/向教师反馈 |
| unavailable | 来源暂不可打开 | 重试 |
| forbidden | 当前无权查看来源 | 返回回答 |

低置信度不能只显示一个模型数字。页面说明是“证据不足、引用不一致、检索范围不足或服务降级”中的哪一种，并给出可行动选项。

### 6.5 补学和返回

进入补学前保存恢复锚点。补学内容在同一学习空间切换课程节点，顶部常驻“正在补学：X，为了理解Y”。返回恢复时间、PPT页、目录选中、问题上下文和已展开引用。刷新后是否可恢复由后端持久化契约决定；未接入时明确“仅本次会话保留”。

## 7. S04 练习与复习

### 页面区域

- 待完成：课程、知识点、来源任务、截止时间。
- 错题回看：题目、首次/最近作答、错误类型、关联讲解和Evidence。
- 推荐复习：建议、原因、证据、不确定性、预计时长。
- 复习会话：单题或单知识点，不形成多层导航。

错题重讲使用课程内容和知识锚点；没有可验证依据时只能给一般性提示，不生成精确课程引用。完成复习后返回原学习锚点或复习列表，并写入真实LearningEvent。

## 8. S05 历史问答

筛选：课程、知识点、时间、是否有依据、反馈状态。列表默认显示问题和短回答，不展示整段对话。

详情包含完整上下文、当时的课程版本、引用状态、反馈和“回到当时位置”。课程已更新时显示“这是基于旧版本的回答”，重新提问创建新会话，不覆盖历史。

学生可以删除自己的对话显示记录；是否删除审计和安全记录由隐私政策决定，前端必须说明范围。

## 9. S06 学习记录

按时间线展示可验证事件：开始/完成节点、作答、重试、问答、补学和建议完成。默认不显示内部埋点和模型特征。

页面提供课程、时间和事件类型筛选。事件可展开查看来源对象；异常数据标记延迟、重复或未同步。学习记录是事实，不等于认知结论。

## 10. S07 学习建议

每条建议使用以下结构：

~~~text
建议做什么
为什么现在建议
使用了哪些学习证据
证据时间和课程范围
系统不确定在哪里
预计投入
开始 / 稍后 / 不再建议
~~~

强建议必须有非空evidenceRefs。交互语义可以解释“重复困惑于边界条件”，但不能独立生成MasteryState分数。推荐来源、版本和生成时间可查看；建议失效后保留在历史中但不可继续执行。

## 11. S08 Memory与隐私

### 页面目标

让学生理解智能体记住了什么、为什么记住、在哪里使用，以及如何控制。

### 页面区域

1. 个性化总开关：关闭后不再生成或使用新Memory，已有数据的保留/删除范围需说明。
2. Memory列表：类型、内容、课程范围、来源交互、生成原因、置信/不确定性、创建和失效时间。
3. 条目操作：修改、删除、查看来源、禁止使用。
4. 数据操作：导出、删除全部、查看近期审计。
5. 说明区：Memory不是成绩，不向其他课程默认共享。

删除必须支持单条和全部删除，并显示删除是否可恢复。敏感条目不允许由低置信语义自动创建；来自合成/研究数据的条目不得出现在正式学生账户。

## 12. 状态、响应式与无障碍

- 1440px：学习空间三轨；普通页面最大1280px。
- 1024–1439px：智能体默认折叠；目录保留。
- 768–1023px：目录和智能体均为抽屉，主舞台单列。
- 小于768px：视频/PPT使用同一主舞台切换，目录与智能体互斥全高抽屉，底部控制不遮挡字幕。
- 字幕、倍速、键盘控制、可见焦点和reduced-motion为基础能力。
- 公式、表格、代码和长引用提供横向滚动或适配视图，不缩到不可读。
- 保存失败、网络中断和媒体错误不清空现有内容；恢复动作位于错误附近。
- Memory删除、退出未保存笔记、取消练习等高风险操作提供明确范围和焦点恢复。
