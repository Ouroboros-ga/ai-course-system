## 1. 赛题要求摘要（改造的验收目标）

1. **作品形态**：深度结合**讯飞星火或其他开源大模型**，面向某一特定学科研发**垂类大模型**，
   并基于高校教学研场景开发**智能体等创新应用**，覆盖**助教 / 助学 / 助研**场景。
2. **技术实现建议**：知识库构建、模型微调（LoRA/SFT）、RAG、智能工作流编排、多模态交互、场景化开发。
3. **核心功能点**：基础 1—4（场景贴合、自然交互、知识权威、内容可追溯）；创新 5—8
   （可复制可推广、生成内容多元性、复杂问题求解、个性化自适应）。
4. **评选 7 维度**（100 分）：作品完成度 10、创意实用度 20、技术实现度 20、技术先进性 10、
   内容质量度 20、商业化潜力 10、用户认可度 10（50 人以上规模化使用可额外加分最高 10）。
5. **提交材料 01—07**：参赛信息（报名表）、伦理与安全合规性声明、作品 Demo、作品方案 PPT、
   作品代码（含模型文件或 ServiceID）、效果验证报告（≥2 名真实目标用户）、其他材料（可选）。
6. **平台**：星火学科大模型平台赛事中心 https://ai.fifedu.com/home（答题要求指定入口）。

## 4. 产品定位重塑

### 4.1 作品名称（决策项，暂定）

- **主推**：`智溯 CS —— 面向一流计算机学科建设的垂类大模型与智能体应用`（智溯 = 智能 + 可追溯，呼应"内容可追溯"核心能力）
- 备选：`星火智学 CS`／`CS 学研一体智能平台`／`智课星河（CS 版）`
- 命名规则提醒：压缩包命名格式为 `提报单位(学校全称)—学科垂类大模型与创新应用开发—作品名称—团队负责人姓名—团队负责人联系方式`

### 4.2 一句话定位

> 以**讯飞星火**为基座的**计算机学科垂类大模型**与**智能体应用集**：通过 CS 学科知识库 +
> RAG + 领域微调构建学科模型层，由备课/教学/代码/科研四类智能体承载**助教、助学、助研**
> 三大场景，让"AI 深度赋能、人机高效协同"在计算机一流学科建设中可运行、可追溯、可复制。

### 4.3 "学科垂类大模型"三层方案（诚实口径）

| 层 | 方案 | 状态 |
|---|---|---|
| 基座 | DeepSeek（`LLM_PROVIDER=deepseek`，`deepseek-chat`，2026-08-20 决策并实测）+ 星火/开源（Qwen/豆包）双轨可插拔 | DeepSeek Provider 已接入并完成 10 用例实测（9/9 自动通过） |
| 领域增强 | CS 学科知识库（校本教材 + 权威论文 + ACM/ICPC 题库 + 行业标准）→ RAG（BM25+BGE+RRF+GraphRAG+Citation） | 知识库内容待填充；RAG 已实现 |
| 领域微调 | LoRA/SFT 管线：数据准备（CS 指令集/评测集）→ 训练脚本 → 评测基准；GPU 不足时走星火 MaaS 微调或标注"管线可复现待训练" | 全部待建设，**不虚报已训练** |

### 4.4 智能体应用集（助教/助学/助研 → 现有 Agent 映射）

| 场景 | 赛题举例 | 本项目承接 |
|---|---|---|
| 助教 | 智能备课、作业批改、学情诊断 | Prep Agent 备课提案、AI 出题双门控、六维认知 + 学情诊断（待外化报告） |
| 助学 | 学习路径规划、知识问答讲解、学习陪伴 | 路径规划、TeachingAgent 问答（Citation 可追溯）、CodingEduAgent 代码诊断 + 算法可视化 |
| 助研 | 领域前沿追踪、学术写作、科研数据分析 | ResearchAgent（arXiv 追踪 ✅、写作/分析待完善） |

### 4.5 学科知识体系（知识库填充范围）

与现有 `knowledge_data/` 对齐，首批覆盖 6 门核心课：数据结构与算法、操作系统、计算机网络、
数据库系统、软件工程、机器学习；每门课产出：概念节点、前置/从属/支撑关系、典型例题、
权威来源（教材名/章节、论文、标准）。格式沿用 `algorithms.json / data_structures.json /
relations.json`（扩充为 `courses/*.json` 亦可，需与导入脚本一致）。

### 4.6 目标用户与商业化路径（维度 9/10 素材）

- 目标用户：CS 专业本科生/研究生（助学）、CS 课程教师（助教）、科研团队（助研）
- 推广路径：单校单课程 → 课程/知识库模板复制到全校 CS 课程 → 私有化/SaaS 输出到兄弟院校 CS 院系
  （服务一流学科建设申报）→ 方法论复制到教育学/医学等学科（长线）
- 可量化价值：备课时间、出题效率、问答准确率与可追溯率、文献调研耗时、代码诊断定位时间

## 6. 风险与诚实边界（AGENTS.md 硬边界对齐）

1. **不伪造**：微调结果、用户反馈、准确率、规模化数据必须真实采集；LoRA 未训练不称"已微调"，
   标注为"管线可复现、待 GPU/MaaS 训练"。
2. **付费服务不进自动化测试**：星火 LLM/TTS 只做受控手工验收；测试维持 Fake/Mock（现状 2665 基线）。
3. **密钥不入库**：星火凭据走 `.env` + fail-closed，参照现有 XFYUN_PPT 模式。
4. **数据边界**：用户试用用合成/假名化数据；真实学生数据不复制入库；AI 生成内容加标识
   （材料 02 承诺项）。
5. **GraphRAG 默认关闭**（数据外发授权未批）：Demo 启用需授权或使用合成课件数据，并在方案中如实说明。
6. **时间风险**：9/5 材料截止为硬约束，R1 起每轮交付物必须"可运行、可回退"。
