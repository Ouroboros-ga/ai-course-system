v2NexusLab Console · 专业化重构

沿用项目 Academic Ink 配色体系（design.md 权威，不改色板），改的是执行层： 去掉斜纹底 / 数字圆点 / 闪烁动画 / unicode 符号图标；状态改为「小圆点 + 文字」； 数据一律等宽 + 等宽数字；控件统一 28px 高、4px 圆角、1px 描边；分层靠描边不靠阴影。

v1 · 造成「玩具感」的四处
  • 45° 斜纹底 —— repeating-linear-gradient(45deg)，典型「施工中」观感
  • 17px 数字圆点阶段条 —— ①②③ 式编号球，教程/向导感
  • 闪烁圆点 —— @keyframes blink，呼吸灯玩具感
  • unicode 符号当图标 —— ◷ ▤ ⚑ ▸ ✓，字形随系统变化、粗细失控
v2 · 替换方案
  • 细虚线 + 极淡琥珀底 + 2px 左侧标记，无图案
  • 细线 + 6px 小圆点 + 文字标签，当前点带 3px 柔光环
  • 11px 细环 spinner，0.7s 匀速旋转（GitHub Actions 式）
  • 内联 SVG（lucide 15 组，stroke 1.6–1.75），尺寸/粗细可控

Board B · 状态矩阵

8 种状态，含 Nexus 特有的「待批准」与「未知」。状态一律「小圆点 + 文字」，无大面积彩色块。
01 · 收起态（默认）
运行中 nanogpt-shakespeare 2m13s
默认一行的实验卡。点任意处展开。
02 · 待批准
等待确认 nanogpt-shakespeare 09:41
不显示「执行中」「已开始」。倒计时来自 expires_at；过期转「已过期 · 请让 Nexus 重新提案」。
03 · 成功
已完成 nanogpt-shakespeare 4m02s
指标显示 1.8857 与期望 1.88±0.06；分开表达「进程成功 / 指标 PASS / 清洁验证结论」。
04 · 失败
失败 nanogpt-shakespeare exit 1
展开后自动定位到失败步骤（整行淡红底）并高亮对应日志。显示真实 exit_code 与 detail。
05 · 取消中 → 已取消
取消中 nanogpt-shakespeare 回收中
待后端 NX-E3
cancelling → 回收确认后才转 cancelled。不得用聊天 Stop 冒充 Cancel（v1.3 C4）。
06 · 超时
超时 nanogpt-shakespeare 10m00s
来自 timed_out。与「失败」分开：失败是退出码非 0，超时是被总截止打断。
07 · 未知（断线 / Worker 重启）
未知 nanogpt-shakespeare 可能已过期
Worker 内存 _jobs 丢失时：「服务重启后该作业状态不可恢复」。禁止 fallback 到成功态、禁止自动重跑。
08 · Worker 不可用（异常态）
复现服务当前不可用
错误码 REPRO_WORKER_UNAVAILABLE
历史状态暂时无法读取
重试
保留最后一次已知状态但标注「可能已过期」，不假装在线。
