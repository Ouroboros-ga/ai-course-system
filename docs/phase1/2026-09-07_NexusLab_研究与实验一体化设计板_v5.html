v5 做了什么：补齐三个连接界面

部位设计约束
视图模型同一个 Research 会话 = 研究对话 + 实验工作台 两个视图，顶部常驻切换；工作台显示运行中的数量General 模式不显示任何实验入口；需要实验时引导显式切换到 Research
三个情境入口① 空会话 / composer 附近「准备实验」　② 提案卡「查看方案」　③ 对话引用条「打开工作台」入口常驻，与是否成功触发工具无关；空态提供「准备第一次实验」与「使用已验证示例」
准备态只有三问：验证什么 / 用什么 / 花多久。每项标注 已确认 · 待补充 · 当前不支持；高级配置折叠打开不执行、改动不自动跑；批准走既有服务端硬门（一次性票据 + plan_hash 校验）
提案卡对话内只显示摘要（目标 / 环境 / 预算）+ 查看方案 · 继续讨论审批不放对话里，放在工作台准备态最终确认处
运行态沿用 v4 大工作区；顶部补「← 研究对话」与 run 切换器；「询问 Nexus」开临时抽屉抽屉只传 run ID + 步骤 + 有界日志（末 40 行），不复制全量日志、不混入其他会话；关闭抽屉继续看实验
结果态主动作「分析本次结果」→ 回对话 + 预填未发送；次动作「调整方案再运行」切回对话不取消实验；后台完成只出轻提示，不强制跳转
专有名词「从上一次跑调整」改名为 调整方案再运行：复制冻结配置 → 新提案 → 展示差异 → 重新审批 → 新 run

三处事实更正（动手前核查出来的）

项v4 的错误实况
run 列表GAP-2「无 list API」已作废。GET /runs 与 GET /runs/{run_id} 已上线（某会话我的 runs，含实时态合并），前端 listNexusRuns 已封装并调用 2 次 → 视图切换里的「本次运行 ▾」有真数据源
Verifying画成绿色完成当前 preset 无干净环境 B 验证 → 应为不适用（虚线空心点 + 灰字）。准备态与结果态同步改
预算「不超过 15 分钟」preset 真实值为 estimated_minutes: 5；executable preset 目前只有 1 个（nanogpt）。此前把 15 分钟 / modelsno 上限写进画面属于编造
唯一新缺口　_public_approval 只返回 approval_id / status / preset_id / repo_url / repo_license / plan_hash / budget / expires_at / job_id —— 不含 steps 与 expected_metrics。准备态要展示步骤与判定指标，需要会话侧的 plan 投影或 plan_reproduction 结果供给，不能由前端拼。
其余缺口沿用 v4　全量日志回看（环形缓冲 2000 字符）、指标时序（只给终值，不画假曲线）、config 结构化。
配色与控件　与 v4 同一套令牌，未改动：单一降饱和 accent #2A6FAD，最深 #1A1F28 无纯黑，去卡片化靠 1px 分隔线，控件 28px / 4px / 1px，数字 tabular-nums，终端 #12171F 是唯一深色语境。
