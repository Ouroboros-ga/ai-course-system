改动v5v6
视图切换器只在研究对话顶部；工作台靠左上「← 研究对话」返回同一枚切换器固定右上角，两个视图同位同款；左上角让位给实验名。切换永远发生在同一个位置，不会迷路

审批入口工作台准备态底部两个按钮浮窗挂在研究对话输入框上方：待确认方案摘要 + 批准执行 / 查看完整方案；不同意就直接在下面输入框提要求，改完重新确认。服务端硬门不变（plan 指纹 + 一次性票据）
询问 Nexus右缘贴边抽屉可自由拖动浮窗：按标题栏拖走，不挡日志；继承研究对话上下文——它就是研究对话在工作台里的一个窗口，同一个助手，同样能操作工作台（改方案走审批、取消走 cancel）

层结论
run 表nexus_runs（nexus_run_service.py:38 DDL）没有 title / name 字段：只有 run_id / preset_id / plan_hash / job_id / status / detail / created_at…
会话标题有 —— GET /sessions 返回 session_id + 标题 + 最近活跃（runtime main.py:669）。会话名 ≠ 实验名，一个会话可有多次实验
v1 首版做法前端本地命名：preset 显示名 + run 序号（如 nanogpt 复现 · #2），序号由 listNexusRuns 的 created_at 排序生成。同 preset 同会话重跑自动递增，无后端改动
待立项（不画饼）用户自定义实验名需 nexus_runs 加 title 字段 + 更新端点；preset 的 paper_title 可作默认名的更优来源（需经会话侧投影下发，前端拿不到 REPRO_PRESETS）
实现落点备忘　切换器组件两视图复用（同位：右 18px / 顶对齐 48px 栏）；审批浮窗与 v6 B1 同构， 出现在「存在 pending approval」时；拖动浮窗建议原生 pointer 事件 + position:absolute， 位置持久化 sessionStorage（与 Console 展开态同机制），不做磁吸贴边。
沿用不变　fail-closed 三处标注（Verifying 不适用 / 预算 5 分钟来自 preset / 无全量日志回看）； General 模式无实验入口；配色与控件令牌同 v4/v5。
