# M7 决赛演示操作脚本

## 1. 适用范围

本脚本冻结一条决赛主路径，不增加公开 API、不修改数据库结构、不改变启动方式。自动化验证只使用隔离数据库和 fake；真实 LLM、PPT、TTS、Duix 必须在赛前人工窗口单独验证。

## 2. 演示前准备

在仓库根目录执行：

```powershell
$env:AI_COURSE_DATABASE_URL = "sqlite:///E:/smartcarb/ai-course-system/.m7_demo/m7_demo.db"
backend\.venv\Scripts\python.exe backend\scripts\prepare_m7_demo.py
powershell -ExecutionPolicy Bypass -File backend\scripts\m7_preflight.ps1
```

如已取得真实可播放的预生成 MP4，可安装 Duix 兜底：

```powershell
backend\.venv\Scripts\python.exe backend\scripts\prepare_m7_demo.py --video-path E:\demo-assets\m7_demo.mp4
```

启动后端和前端时必须保持同一个 `AI_COURSE_DATABASE_URL`。后端入口保持现有 `backend/run.py`，前端保持现有 `npm.cmd run dev`。

## 4. 现场节奏

1. 正常路径总时长控制在 8 至 10 分钟。
2. 上传、PPT、TTS、Duix 任一步超过 30 秒无明确进度，立即切换兜底课程。
3. 不在台上修配置、重装依赖或重复调用付费服务。
4. 降级时明确说“当前使用赛前预生成素材继续验证教学闭环”，不得把兜底结果描述成实时生成。

## 5. 演示结束判定

只有学生端完成分屏播放、进度保存、问答或测验，以及一次前置知识跳转/返回，才算主链路演示完成。外部生成状态可以是成功或已解释的降级，但页面不得崩溃，课程与学习记录不得丢失。
