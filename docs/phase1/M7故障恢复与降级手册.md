# M7 故障恢复与降级手册

## 1. 分级原则

- P0：无法登录、后端/前端不可用、课程或播放器打不开、数据丢失，主链路不能继续。
- P1：某个生成或智能功能失败，但可用预生成素材或人工操作继续完成教学闭环。
- 所有恢复动作优先保持现场可控，不改代码、不迁移数据库、不临时安装依赖。

## 2. P0 故障

| 故障 | 识别 | 人工恢复 | 放弃条件 |
| --- | --- | --- | --- |
| 后端不可用 | `/openapi.json` 非 200 | 检查后端进程和 `AI_COURSE_DATABASE_URL`，按原启动方式重启一次 | 60 秒内不能恢复，改为录屏/截图说明，不伪造在线结果 |
| 前端不可用 | 首页无法打开或白屏 | 检查 Vite 进程；使用已构建产物按现有方式启动；刷新一次 | 60 秒内不能恢复，停止实时 UI 演示 |
| 登录失败 | 两个固定账号都失败 | 在同一数据库环境变量下重新执行准备脚本，再重启后端 | 数据库无法打开或密码仍失败 |
| 兜底课程不可见 | 教师/学生列表为空 | 核对数据库 URL；执行准备脚本；教师端确认 published | 课程写入失败或模型异常 |
| 播放器初始化失败 | `/api/v1/player/init/<id>` 非 200 | 重新登录、确认学生已选课、确认课程 published；只重试一次 | 初始化仍失败，不继续问答/跳转演示 |
| 数据库损坏 | 启动报 SQLite 错误 | 停止进程，替换为赛前冻结的数据库副本 | 没有可验证备份 |

## 3. P1 外部服务故障

| 服务 | 失败表现 | 降级路径 | 不允许的说法 |
| --- | --- | --- | --- |
| LLM | 脚本、问答、测验或前置分析超时/业务失败 | 使用已准备课程与脚本；问答改为展示课件中的固定问题；前置跳转改为人工切节点 | 不得称固定文本为实时模型生成 |
| PPT | 生成任务 failed/timeout | 使用上传课件原页和已准备的节点映射 | 不得把旧 PPT 说成本次实时生成 |
| TTS | 状态 failed/partial/timeout | 停止批量重试；使用赛前预生成音频或带声音的预生成视频 | 不得写伪造 `audio_url` 或宣称全部成功 |
| Duix | 任务 failed、video path 为空或硬件不可用 | 使用 `prepare_m7_demo.py --video-path` 安装的真实预生成 MP4 | 不得把预生成视频描述成现场 Duix 生成 |
| 网络 | 外部服务不可达 | 保持本地数据库与前端链路，直接进入兜底课程 | 不得关闭错误提示后宣称外部服务正常 |

## 4. Duix 专项兜底

当前真实 Duix Docker、硬件、路径语义和耗时仍为 `WAITING_FOR_HARDWARE`。赛前必须准备一段与兜底课件一致、可离线播放的 MP4，并使用 `--video-path` 安装。现场只检查任务状态和播放器消费路径，不把硬件未验证状态升级为已完成。

## 5. 人工恢复顺序

1. 记录失败步骤、时间和页面提示。
2. 只重试一次当前动作，防止重复课程、重复任务或付费调用。
3. 生成类失败立即切到兜底数据；核心页面失败才重启对应进程。
4. 切换后从课程发布或学生选课处继续，不回到上传重跑全链路。
5. 演示结束后保留日志和数据库副本，禁止现场直接改生产表。

## 6. 证据边界

- 自动化 fake 覆盖成功、超时、不可用、非法响应和业务失败：`backend/tests/fakes.py`、`test_m4b_fakes.py`。
- TTS 部分成功与错误聚合：`test_r2c_tts_batch_task.py`。
- 视频状态查询：`video_generation.py::get_task_status`。
