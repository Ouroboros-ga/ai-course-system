# M7 演示前检查清单

## 1. 一键检查

仓库根目录执行：

```powershell
$env:AI_COURSE_DATABASE_URL = "sqlite:///E:/smartcarb/ai-course-system/.m7_demo/m7_demo.db"
powershell -ExecutionPolicy Bypass -File backend\scripts\m7_preflight.ps1
```

服务启动后增加本地存活检查：

```powershell
powershell -ExecutionPolicy Bypass -File backend\scripts\m7_preflight.ps1 `
  -SkipTests -SkipBuild -CheckLive
```

预检脚本只允许探测 `localhost`、`127.0.0.1` 或 `::1`，不会访问真实外部服务。

## 2. 环境检查

- [ ] 当前分支和提交号已记录。
- [ ] `git diff --check` 通过，工作区改动已人工确认。
- [ ] 后端虚拟环境存在。
- [ ] `AI_COURSE_DATABASE_URL` 明确指向演示库。
- [ ] 演示库、预生成媒体和日志有只读备份。
- [ ] 前后端启动命令与正式演示一致。
- [ ] 8000/5173 端口没有被无关进程占用。

## 3. 数据检查

- [ ] `DemoTeacher` 和 `DemoStudent` 可登录。
- [ ] 兜底课程存在且为 published。
- [ ] 两个脚本节点、文本和页码映射可见。
- [ ] 学生账号可以看到课程并完成选课。
- [ ] 演示前将学生进度重置到约定位置，或明确从断点续学开始。

## 4. 媒体与外部服务检查

- [ ] 真实课件上传文件可读。
- [ ] PPT 生成凭据只在人工窗口验证，不用于自动化测试。
- [ ] TTS 人工生成一次并确认音频可播放。
- [ ] Duix 如未完成硬件验收，状态仍写 `WAITING_FOR_HARDWARE`。
- [ ] 预生成 MP4 本地可播放，文件路径与任务状态一致。
- [ ] 断网后兜底课程、课件页和预生成媒体仍可打开。

## 5. 页面检查

- [ ] 教师登录、历史、创建、课程页无白屏和阻塞遮罩。
- [ ] 上传后的课程与脚本信息完整。
- [ ] 映射、TTS 状态、数字人状态可读。
- [ ] 学生课程大厅、课程详情和播放器可打开。
- [ ] 分屏播放器中视频、PPT、节点文本互不遮挡。
- [ ] 控制台无新增未处理异常。
- [ ] 进度保存后重新进入可以恢复。
- [ ] 问答、测验、前置跳转各执行一次。

## 6. 现场物料

- [ ] 电源、网络、HDMI/投屏和音频输出已验证。
- [ ] 浏览器缓存策略明确，两个账号的切换方式已排练。
- [ ] 本地数据库备份、预生成视频和课件各有第二份副本。
- [ ] `M7故障恢复与降级手册.md` 可离线打开。
- [ ] 主讲人与操作人员确认 30 秒切换兜底规则。

## 7. 通过标准

一键检查无阻塞失败，所有 P0 页面人工通过，且至少一条离线兜底路径已现场演练。真实外部服务未验证时不得勾选对应项，也不得因此修改自动化测试结果。
