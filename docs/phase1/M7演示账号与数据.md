# M7 演示账号与数据

## 1. 固定账号

| 角色 | 用户名 | 默认密码 | 用途 |
| --- | --- | --- | --- |
| 教师 | `DemoTeacher` | `Demo123456` | 上传、编辑、映射、生成、发布 |
| 学生 | `DemoStudent` | `Demo123456` | 选课、播放、进度、问答、测验、跳转 |

这些账号由 `backend/scripts/prepare_m7_demo.py` 幂等创建，仅用于本地决赛演示数据库。若演示机器可被外网访问，必须通过 `M7_DEMO_PASSWORD` 设置临时强密码，不得沿用默认密码。

## 2. 固定数据

- 上传样例：`docs/phase1/demo/M7演示课件.md`。
- 兜底课程键：`m7-demo-fallback`。
- 兜底课程标题：`M7 决赛演示：二分查找与递归`。
- 兜底脚本：2 个节点，二分查找与递归，每节点 60 秒。
- 兜底映射：两个节点分别映射第 1、2 页。
- 兜底视频：仓库不自带虚构视频；只有传入真实 `.mp4` 后才写入 completed 任务。

## 3. 准备命令

推荐使用与生产库分离的演示数据库：

```powershell
New-Item -ItemType Directory -Force .m7_demo | Out-Null
$env:AI_COURSE_DATABASE_URL = "sqlite:///E:/smartcarb/ai-course-system/.m7_demo/m7_demo.db"
$env:M7_DEMO_PASSWORD = "<现场临时密码>"
backend\.venv\Scripts\python.exe backend\scripts\prepare_m7_demo.py
```

脚本默认拒绝写入 `database/smart_class.db`。确需写默认库时必须人工显式添加 `--allow-default-database`，并在执行前备份数据库。

## 4. 预生成视频安装

```powershell
backend\.venv\Scripts\python.exe backend\scripts\prepare_m7_demo.py --video-path E:\demo-assets\m7_demo.mp4
```

该命令只接受存在的 `.mp4`，复制到当前视频存储目录，并为兜底节点写入真实的 completed 任务及文件路径。它不会生成伪视频，也不会调用 Duix。

## 5. 数据冻结规则

1. 决赛前一天冻结课件、账号、数据库备份和预生成媒体的校验值。
2. 演示当天不修改课程节点顺序、页码映射或账号角色。
3. 每轮彩排使用数据库副本；不要在唯一演示库上反复删课。
4. 准备脚本可重复运行，固定课程和账号不应重复创建。

## 6. 证据

- 用户写入：`prepare_m7_demo.py::_upsert_user`。
- 课程与脚本：`prepare_m7_demo.py::_ensure_course`、`_ensure_script_and_nodes`。
- 映射：`prepare_m7_demo.py::_ensure_script_and_nodes`。
- 视频兜底：`prepare_m7_demo.py::_install_video_fallback`。
- 默认数据库保护：`prepare_m7_demo.py::main`。
