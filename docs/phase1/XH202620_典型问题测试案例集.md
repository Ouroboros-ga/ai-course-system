## C1 助学｜二叉树重建（前序 + 中序 → 唯一二叉树）

- **问题**：已知某二叉树的前序遍历序列为 `A B D E C F`，中序遍历序列为 `D B E A F C`，请重建该二叉树并给出其后序遍历序列。
- **标准答案**：后序遍历为 `D E B F C A`。
  - 推理链：前序首元素 `A` 为根 → 中序中 `A` 左侧 `D B E` 为左子树、右侧 `F C` 为右子树 → 左子树前序 `B D E`、中序 `D B E`，根为 `B`，左孩子 `D`、右孩子 `E` → 右子树前序 `C F`、中序 `F C`，根为 `C`，左孩子 `F`。后序 = 左子树后序 `D E B` + 右子树后序 `F C` + 根 `A` = `D E B F C A`。
- **权威来源**：严蔚敏、吴伟民《数据结构（C语言版）》第 5 章"树和二叉树"——遍历与由遍历序列恢复二叉树。
- **评测方法**：比对模型输出的后序遍历序列是否等于 `D E B F C A`；要求输出给出分步推理（可追溯），不只给结论。

## C2 助学｜算法复杂度分析（快排最坏情况）

- **问题**：对已按升序排好的长度为 n 的数组执行"以首元素为基准"的快速排序，其时间复杂度是多少？请说明原因，并与归并排序对比。
- **标准答案**：最坏情况 O(n²)。已有序数组每次划分产生 n-1 与 0 两个子问题，递推式 T(n)=T(n-1)+O(n) → O(n²)；归并排序无论输入顺序均为 O(n log n)。平均情况下快排为 O(n log n)。
- **权威来源**：Cormen 等《算法导论（原书第 3 版）》第 7 章"快速排序"（最坏情况分析 7.2 节）、第 2 章"归并排序"。
- **评测方法**：断言模型给出"最坏 O(n²)"并解释退化原因；若给出平均 O(n log n) 必须区分口径；可要求其用 Master Theorem 或递推树说明。

## C3 助学｜代码调试（沙箱执行验证）

- **问题**：下面的 C 函数意图把字符串原地反转，但运行结果错误，请定位问题并给出修复后的代码（可在沙箱中执行验证）：

  ```c
  void reverse(char s[]) {
      int n = strlen(s);
      for (int i = 0; i < n; i++) {
          char t = s[i];
          s[i] = s[n - i];
          s[n - i] = t;
      }
  }
  ```

- **标准答案**：三处问题：① 循环应只到 n/2（否则交换两次又还原）；② `s[n-i]` 越界（有效下标 0..n-1，应为 `s[n-1-i]`）；③ 未处理空串/`\0` 位置。修复：

  ```c
  void reverse(char s[]) {
      int n = strlen(s);
      for (int i = 0; i < n / 2; i++) {
          char t = s[i];
          s[i] = s[n - 1 - i];
          s[n - 1 - i] = t;
      }
  }
  ```

- **权威来源**：Kernighan & Ritchie《The C Programming Language》数组/字符串章节；正确性由 Judge0 沙箱实际执行"输入 → 输出反转串"断言。
- **评测方法**：CodingEduAgent 输出诊断（越界 + 边界）→ 修复代码提交 Judge0 执行 `reverse("hello")` 断言输出 `olleh`（服务端验证，非学生自评）。

## C4 助教｜操作系统进程调度（FCFS 平均等待时间）

- **问题**：三个进程 P1、P2、P3 到达时间均为 0，服务时间分别为 24、3、3，采用先来先服务（FCFS，到达顺序 P1→P2→P3）调度，计算各进程等待时间与平均等待时间。
- **标准答案**：P1 等待 0，P2 等待 24，P3 等待 27，平均等待时间 (0+24+27)/3 = 17。若按 SJF（P2、P3 先执行）平均等待 (0+3+6)/3 = 3，可用于对比说明调度策略影响。
- **权威来源**：汤小丹等《计算机操作系统（第 4 版）》进程调度章节（FCFS/SJF 例题口径一致）；Silberschatz《Operating System Concepts》第 6 章。
- **评测方法**：断言输出等待时间表与平均值 17；要求展示甘特图/时间线（可追溯）；对照教材例题数值。

## C5 助教｜计算机网络 TCP 三次握手

- **问题**：解释 TCP 建立连接的三次握手过程，说明为什么需要三次（两次为何不够），并给出关键报文标志位与状态迁移。
- **标准答案**：① 客户端发送 SYN（seq=x）进入 SYN_SENT；② 服务端回复 SYN+ACK（seq=y, ack=x+1）进入 SYN_RCVD；③ 客户端发送 ACK（ack=y+1）进入 ESTABLISHED，服务端收到后也进入 ESTABLISHED。需三次的原因：防止已失效的连接请求报文突然到达服务端造成错误连接（若只有两次握手，服务端无法区分迟到重复的 SYN 与新的连接请求）；核心是让双方确认对方的收发能力并同步初始序号。
- **权威来源**：谢希仁《计算机网络（第 8 版）》TCP 运输连接管理；RFC 793（Transmission Control Protocol）。
- **评测方法**：断言状态机与标志位正确（SYN/SYN+ACK/ACK、seq/ack 语义）；要求引用 RFC 793 或教材章节；检查无"两次握手足够"的常识性错误。

## C6 助研｜数据库 SQL 改写与事务隔离

- **问题**：给定学生成绩表 `score(student_id, course_id, score)`，写出查询"每门课程成绩最高的学生学号与分数"的 SQL；并说明在"读已提交（READ COMMITTED）"隔离级别下，该查询与"可重复读（REPEATABLE READ）"行为差异。
- **标准答案**：
  - 改写（避免"先按课程分组取 max 再关联"易错写法，推荐窗口函数）：

    ```sql
    SELECT course_id, student_id, score
    FROM (
        SELECT course_id, student_id, score,
               ROW_NUMBER() OVER (PARTITION BY course_id ORDER BY score DESC) AS rn
        FROM score
    ) t
    WHERE rn = 1;
    ```

  - 隔离级别差异：READ COMMITTED 下同一事务内两次查询可能读到不同已提交数据（不可重复读）；REPEATABLE READ 下（PostgreSQL 语义）同一事务快照内两次查询结果一致（快照隔离，不产生不可重复读；MySQL InnoDB 亦通过 MVCC 实现）。若存在并列最高分，上述写法只取一条，需说明可用 `RANK()` 保留并列。
- **权威来源**：王珊、萨师煊《数据库系统概论（第 6 版）》关系查询与事务章节；PostgreSQL 文档 "Transaction Isolation"（READ COMMITTED / REPEATABLE READ）。
- **评测方法**：在本地 PostgreSQL/SQLite 构造样例数据实际执行 SQL 验证结果集（服务端执行，截图留存）；隔离级别差异以权威文档为准核验表述。

## C7 助教｜软件工程测试用例设计（等价类 + 边界值）

- **问题**：为"成绩录入"功能设计测试用例。输入规则：成绩为整数，合法范围 0–100（含端点）。请给出等价类划分与边界值用例。
- **标准答案**：
  - 有效等价类：0 ≤ 成绩 ≤ 100 的整数；无效等价类：成绩 < 0、成绩 > 100、非整数。
  - 边界值用例（重点）：0（合法下界）、100（合法上界）、-1（非法下界外）、101（非法上界外）。
- **权威来源**：张海藩《软件工程导论（第 6 版）》第 6 章"软件测试"——等价类划分与边界值分析。
- **评测方法**：断言输出含"等价类"与"边界值"方法名及四组边界（0/100/-1/101）；检查无"边界值=1/99"这类常见漏项。

## C8 助学｜机器学习混淆矩阵与 F1 计算

- **问题**：某二分类模型测试结果：TP=40、FP=10、FN=20、TN=30。计算精确率（Precision）、召回率（Recall）与 F1。
- **标准答案**：精确率 = TP/(TP+FP) = 40/50 = 0.8；召回率 = TP/(TP+FN) = 40/60 ≈ 0.667；F1 = 2·P·R/(P+R) ≈ 0.727。
- **权威来源**：周志华《机器学习》第 2 章"模型评估与选择"——混淆矩阵、P/R/F1 定义。
- **评测方法**：断言数值与公式（容差 ±0.01）；要求给出公式过程，不只给答案；数值错误或 P/R 混淆即判错。

## C9 助学｜0-1 背包动态规划

- **问题**：背包容量 W=5，三件物品（重量,价值）=（2,3）（3,4）（4,5）。用动态规划求最大可装价值。
- **标准答案**：最大价值 = 7（选物品 1（2,3）与物品 2（3,4），总重 2+3=5 ≤ 5，价值 3+4=7；选物品 3 只能单独装（4,5）价值 5 < 7）。状态转移 dp[i][w]=max(dp[i-1][w], dp[i-1][w-wi]+vi)。
- **权威来源**：Cormen 等《算法导论（原书第 3 版）》第 15 章"动态规划"——0-1 背包问题。
- **评测方法**：断言最大价值为 7；要求展示 dp 表或递推说明；错误答案（如 5 或 9）判错。

## C10 助教｜操作系统死锁判定

- **问题**：进程 A 持有锁 L1 并请求锁 L2，进程 B 持有锁 L2 并请求锁 L1，两进程均不释放已持有的锁。判断是否死锁，并说明死锁的四个必要条件。
- **标准答案**：是死锁——满足全部四个必要条件：互斥、占有并等待、不可抢占、循环等待（A→L2、B→L1 构成等待环）。处理方法：预防（破坏条件之一）、避免（银行家算法）、检测与解除。
- **权威来源**：汤小丹等《计算机操作系统（第 4 版）》第 3 章"处理机调度与死锁"——死锁必要条件与处理策略。
- **评测方法**：断言输出"死锁"结论并列出四条件；漏掉"循环等待"或误判"无死锁"即判错；要求给出等待环说明。
