# 二分查找与递归：从问题分解到算法实现

## 1. 二分查找

二分查找适用于有序序列。每一步将目标值与区间中点比较，并把搜索范围缩小为原来的一半。

核心条件：数据必须有序；循环中需要维护左右边界；当左边界超过右边界时，查找失败。

## 2. 递归与基本情况

递归函数通过调用自身处理规模更小的同类问题。完整递归必须包含基本情况，否则调用不会停止。

分析递归时需要明确：当前子问题是什么、规模如何缩小、何时到达基本情况，以及返回值如何组合。

## 3. 二分查找的递归实现

递归二分查找把左半区间或右半区间作为新的子问题。每次调用都会缩小区间，因此最终命中目标或进入空区间。
