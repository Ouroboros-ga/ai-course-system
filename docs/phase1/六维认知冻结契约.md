# 六维认知冻结契约（2026-08-17，M9 收尾）

本文档是六维认知改进计划（M1-M9）的**冻结契约**：六维字段名、语义、生产者、
消费者与冻结边界。任何改动必须同步更新本契约并跑通 `tests/learning/` 与
`tests/agents/` 相关回归。

## 1. 六维字段（冻结）

`CognitiveState` 六维字段（`app/models/cognitive_state_model.py`），
`CognitiveDimension` 枚举顺序即六维顺序：

| 维度 | 字段 | 语义 | 范围 |
|---|---|---|---|
| 表现分 | `observed_performance_score` | 答题正确率（加权） | 0-1 |
| 置信度 | `evidence_confidence` | 证据充分度（样本量/时间/一致性加权） | 0-1 |
| 困惑风险 | `confusion_risk` | 重复错误/困惑（错误率×0.7 + 重复×0.3） | 0-1 |
| 提问深度 | `inquiry_depth` | LLM 标定提问认知深度（越界→None） | 0-1 |
| 提示依赖 | `hint_dependency` | 使用提示的答题占比 | 0-1 |
| 解释需求 | `explanation_need` | 确定性投影：`min(1, confusion×0.5 + (1-perf)×0.3 + hint×0.2)` | 0-1 |

**None 语义**：维度无证据时为 `None`（不是 0.0）。所有消费方必须区分
"未知"与"低分"；提示词注入与出题端口序列化时 None → `"unknown"`（M6）。

## 2. 生产者（冻结）

| 生产者 | 状态 | 说明 |
|---|---|---|
| `cognitive_service.compute_cognitive_state` | 唯一生产者 | 确定性计算，reason code 可审计 |
| `cognitive_decay_service.decayed_confidence` | 读取投影 | 不落库，仅消费时衰减 |
| `progress_service.UnderstandingAnalyzer` | **已停写（M4）** | 不再调用 LLM、不再写 `UnderstandingAnalysis`/NodeProgress 理解度 |
| 客户端 `understandingScore`（`/progress/sync`） | **已封堵（M4）** | 请求字段保留兼容，显式忽略，不写入任何业务字段 |
| 泛雅回调 `understanding_score` | **已冻结（M9）** | 不再更新 `StudentEnrollment.avg_understanding_score`（历史值仅供审计） |

## 3. 消费者（冻结）

| 消费者 | 用途 |
|---|---|
| `recommendation_service.generate_recommendation` | 六维策略分流（低表现/低置信/困惑/前置薄弱） |
| `edu/policy.py::decide_teaching_action` | 教学动作（含 M5 迟滞带） |
| `learning_path_service.plan_next_nodes` | 学习路径（M3 判弱 + 薄弱优先） |
| `learning_adjustment_service` | 学习调整建议（`EXPLANATION_NEED_HIGH` 等 reason code 独立计算） |
| `RESPONSE_SYSTEM` / `build_generation_prompt` | 提示词注入（M6 规则） |

## 4. 冻结边界（不可回退项）

1. **六维字段名与顺序**：`CognitiveDimension` 枚举与 `CognitiveState` 字段名冻结；
   新增维度必须走枚举扩展 + 迁移，不得复用旧字段。
2. **None ≠ 0.0**：任何序列化/注入不得把缺失维度当 0.0（M6 契约测试锁定）。
3. **旧理解度链路冻结**：`UnderstandingAnalysis` 表不再新增写入（历史保留审计）；
   `NodeProgress.understanding_score/level` 不再由客户端/旧 LLM 链路写入；
   `StudentEnrollment.avg_understanding_score` 不再更新。
4. **确定性**：六维计算与教学动作决策必须确定性（无 LLM 直连）；
   LLM 只做表达（RESPONSE_SYSTEM）与提问深度标定（inquiry_depth，越界→None）。
5. **消费方输出契约**：`/recommendation`、`/cognition`、`/player/progress/save`
   的六维相关字段名与结构冻结；`/progress/visualization` 旧理解度展示带
   `understanding_deprecated: true` 标记（M9）。
