## M4-M7 建立测试时的约束

| 约束 | 建议执行方式 | 禁止事项 |
|---|---|---|
| LLM 调用隔离 | `monkeypatch` `llm_client.chat` / `simple_chat`，或 FastAPI dependency override 包装服务层 | 禁止真实调用豆包、通义、文心、OpenAI |
| TTS 调用隔离 | 优先设置 `TTS_PROVIDER=mock` 或 monkeypatch `tts_client.synthesize` | 禁止真实调用阿里云、腾讯云、火山 TTS |
| PPT 调用隔离 | monkeypatch `ppt_generation_service.xfyun_client` 和 `llm_client.chat` | 禁止真实调用讯飞 PPT API |
| 数字人调用隔离 | monkeypatch `digital_human_client.check_health` / `generate_video` | 禁止真实调用 Gradio 数字人服务 |
| 数据库隔离 | dependency override `get_session` 到临时 SQLite 或事务夹具 | 禁止使用 `database/smart_class.db` 执行自动化测试 |
| 启动副作用隔离 | 避免测试导入 `app.main` 时触发真实建表、迁移和依赖检查；必要时最小化行为保持型可测试性改造 | 禁止通过删除启动逻辑换取测试通过 |

## 当前阶段结论

1. 现有系统主流程以教师素材/课件/课程、PPT 解析与生成、知识点映射、学生学习、问答、进度、TTS、视频生成、泛雅对接为核心。
2. 未来规划模块在后端 endpoint 层多为占位代码，前端也存在占位组件，但未接入 `frontend/src/router/index.js` 主路由。
3. 第一阶段不应扩大到 V3.1 新能力实现；应先建立可重复、可 Mock、可回滚的测试基线。

## 回滚方法

本阶段只新增 `docs/phase1/` 下文档。回滚时删除本目录新增的四份审计文档即可，不涉及业务代码、测试配置、数据库或依赖。
