# 路由契约基线

更新时间：2026-07-08

## 目的

本文件记录 M4A 对当前真实路由状态的锁定方式。M4A 不修复重复路由和前后端接口不一致，只把现状变成可验证证据，供 M4B-M7 建立回归测试。

## 契约测试文件

路由契约测试位于：

```text
backend/tests/test_m4a_route_contract.py
```

测试通过 FastAPI `app.routes` 和 `app.openapi()` 记录每条 `APIRoute` 的：

- HTTP method
- 完整 path
- endpoint 函数名
- endpoint module，作为 router 来源线索
- 注册顺序 index
- 是否出现在 OpenAPI

## 已锁定的关键路由事实

| 路由事实 | 测试 | 预期 |
|---|---|---|
| 路由记录字段完整 | `test_route_contract_records_required_fields` | 每行包含 `index/method/path/endpoint/module/in_openapi` |
| catch-all 不进入 OpenAPI | `test_route_contract_locks_known_non_openapi_catch_all` | `/{path:path}` 的 DELETE/GET/PATCH/POST/PUT 均为 `app.main.catch_all` 且 `in_openapi=False` |
| `document.router` 挂载到 `/api/v1/document` | `test_route_contract_locks_document_router_double_mount` | `/api/v1/document/upload` 存在 |
| `document.router` 再次挂载到 `/api/v1/chat/file` | `test_route_contract_locks_document_router_double_mount` | `/api/v1/chat/file/upload` 存在 |
| `document.py` 存在重复 `GET /courses` | `test_route_contract_locks_known_duplicate_document_routes` | `GET /api/v1/document/courses` 数量为 2 |
| `document.py` 存在重复 `POST /course/{course_id}/save` | `test_route_contract_locks_known_duplicate_document_routes` | `POST /api/v1/document/course/{course_id}/save` 数量为 2 |
| 当前视频生成真实前缀 | `test_route_contract_locks_video_gen_and_known_absent_old_routes` | `/api/v1/video-gen/health` 存在 |
| 旧测试路径不是当前真实路径 | `test_route_contract_locks_video_gen_and_known_absent_old_routes` | `/api/v1/video-generation/health` 不存在 |
| 前端 `chat.js` 的 `/chat/${chatId}` 风险 | `test_route_contract_locks_frontend_chat_path_mismatch` | `/api/v1/chat/{chat_id}` 不存在，`/api/v1/chat/messages/{chat_id}` 存在 |

## 运行时路由清单生成方式

测试中的 `_route_rows(app)` 生成如下结构：

```python
{
    "index": index,
    "method": method,
    "path": route.path,
    "endpoint": route.endpoint.__name__,
    "module": route.endpoint.__module__,
    "in_openapi": route.path in openapi_paths,
}
```

M4A 暂不导出运行时快照文件，避免引入额外生成物；如后续需要，可在 M4B/M5 将 `_route_rows(app)` 输出为 JSON/Markdown 快照并纳入评审。

## 代码证据来源

主入口注册依据：`backend/app/main.py`

- `/api/v1/document`：`app.include_router(document.router, prefix="/api/v1/document")`
- `/api/v1/chat/file`：`app.include_router(document.router, prefix="/api/v1/chat/file")`
- `/api/v1/video-gen`：`app.include_router(video_generation.router, prefix="/api/v1/video-gen")`
- `/{path:path}`：`catch_all` 兜底路由，不进入 OpenAPI

重复路由依据：`backend/app/api/v1/endpoints/document.py`

- `@router.get("/courses")` 出现两次
- `@router.post("/course/{course_id}/save")` 出现两次

前端接口不一致依据：

- `frontend/src/api/chat.js` 使用 `/chat/${chatId}`
- `backend/app/api/v1/endpoints/chat.py` 定义 `/messages/{chat_id}`，未见 `/chat/{chat_id}` 对应 endpoint
