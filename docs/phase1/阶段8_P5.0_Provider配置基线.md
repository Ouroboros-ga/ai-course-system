# 阶段 8 P5.0：Provider 配置基线

> 更新日期：2026-08-07。本文记录统一 Provider 配置的代码事实与页面状态契约。

- Stage 8 不读取通用 `TTS_PROVIDER`；该变量只保留给历史 document/video 兼容链。
- 本地 Demo 必须在 `backend/.env` 显式设置 `MEDIA_DEMO_MODE=true`。服务端强制选择 Fake，
  健康接口返回 `effective_provider=fake-demo`、`billable=false`、
  `requires_confirmation=false`，建设页显示 `fake-demo`，不调用付费 TTS。
- 正式模式必须设置 `MEDIA_DEMO_MODE=false` 与 `STAGE8_TTS_PROVIDER=doubao`。缺失、拼写
  错误或豆包凭据不完整时返回 `status=needs_configuration`，禁止静默回退 Fake 或创建任务。
- 正式豆包健康时返回 `effective_provider=doubao`、`billable=true`、
  `requires_confirmation=true`；只有教师明确确认后才允许提交任务。
- `MEDIA_DEMO_MODE=true` 优先级高于任何正式 Provider 配置，避免本地环境残留凭据产生付费调用。

实现证据：`backend/app/services/stage8_provider_runtime.py`、
`backend/app/api/v1/endpoints/media_release.py`、
`frontend/src/app/pages/course/build/BuildMediaPage.vue`。

本次变更未调用真实付费 TTS；课程 87 已冻结的 Fake 媒体版本不被覆盖。
