# 阶段 8 P5.1：音色与角色注册表

> 状态：已实现（2026-08-07）

P5.1 把媒体版本使用的音色与平台 2D 角色从前端硬编码改为服务端注册表，并在批次确认时冻结版本。

## 代码证据

- `backend/app/models/platform_media_preset_model.py`：`PlatformVoicePreset`、`PlatformAvatarPreset`。
- `backend/app/services/platform_media_preset_service.py`：安全 DTO、幂等 seed、角色 manifest 写入与 release 版本签名。
- `backend/alembic/versions/20260807_1700_0042_platform_media_presets.py`：注册表及批次/发布版本字段迁移。
- `GET /api/v1/media/course/{course_id}/platform-presets`：仅返回 preset id/version、显示名、Provider 标识和内容哈希；不返回 speaker、resource ID 或密钥。
- `MediaBuildBatch` 与 `MediaRelease`：冻结 voice/avatar preset id + version。
- 学习端 `mediaPlaybackAdapter` / `useAvatarPlayback`：优先加载发布版本签名 manifest，失败后使用平台内置 manifest，再降级静态头像/无数字人。

## 运行与迁移

先执行 `alembic upgrade head`。seed 是服务层幂等注册，不以启动时 `create_all` 替代迁移。`MEDIA_DEMO_MODE=true` 时只展示 fake-demo 音色；正式模式由服务端配置的 Doubao Provider 决定可见音色。

## 不可变语义

角色/音色发生变化必须新建 MediaRelease。学生播放响应固定返回 `avatar_preset_id`、`avatar_preset_version` 与签名 `avatar_manifest_url`；历史版本不会因注册表新增版本而静默切换。
