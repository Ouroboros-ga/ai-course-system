# 阶段 8 P5.3：一次受控豆包验收

> 更新日期：2026-08-07
> 状态：实现完成；本机本回合的真实外部调用被运行环境审批拦截，不能据此伪造“已重新调用成功”。
> 本文只记录一次短文本 POC，不是正式课程发布或长文本质量验收。

## 1. 验收边界

- 仅允许教师明确授权后执行一次短文本调用。
- 调用入口为 `backend/scripts/volcengine_tts_poc.py`，必须显式传入
  `--allow-billable-call`；默认 dry-run，不联网。
- 文本限制为 60 UTF-8 bytes；本次约定文本为“这是一次豆包语音验收。”。
- 不批量调用、不自动重试、不写入对象存储、不创建或覆盖
  `MediaBuildBatch`、`MediaRelease`、`MediaReleaseItem` 或正式课程发布版本。
- 日志与文档不得保存 API Key、Speaker、原始 Provider 帧或完整音频。

## 2. 配置与调用链

正式调用必须满足：

```text
MEDIA_DEMO_MODE=false
STAGE8_TTS_PROVIDER=doubao
VOLCENGINE_DOUBAO_TTS_WS_URL/API_KEY/RESOURCE_ID/SPEAKER 已配置
```

本地 Demo 的 `MEDIA_DEMO_MODE=true` 始终强制 `fake-demo`，不会因为环境残留密钥而调用付费服务。
真实豆包仅允许由受控 Worker 或本脚本执行，浏览器不接触凭据。

命令（仅在教师授权且运行环境允许外部调用时执行一次）：

```powershell
backend\\.venv\\Scripts\\python.exe backend\\scripts\\volcengine_tts_poc.py `
  --env-file backend\\.env `
  --text "这是一次豆包语音验收。" `
  --allow-billable-call
```

脚本输出脱敏 JSON，包含音频字节数、PCM 推算时长、音频 SHA、`words` 数量、最后字结束时间、
时间误差、`phonemes` 数量、Provider 事件和错误码；不会落盘音频。

## 4. 与正式发布的关系

P5.3 只验证 Provider 能力边界，不改变 Stage 8 的 Fake Demo 主链。正式课程仍须经过：

```text
计划 → 教师一次费用确认 → TTS/缓存 → subtitle-manifest/v1 + avatar-cues/v1
→ ppt-manifest/v1 → audio-playlist/v1 → 激活 MediaRelease → 正式课程发布
```

豆包真实结果不得覆盖已有 Fake 版本；任何进入课程的音频、字幕、Cue、PPT 或角色变更都必须生成新的不可变媒体版本，并固定 `release_id + playlist_content_hash`。
