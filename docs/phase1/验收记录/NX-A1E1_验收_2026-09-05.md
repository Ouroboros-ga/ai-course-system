## NX-A1 附件/视觉：交付内容

- 入口：`POST /api/v1/nexus/attachments`（multipart）、`GET` 列表/详情
  （`include_blocks` 文本预览）、`GET .../download` 鉴权下载、
  `DELETE` 立即撤销、`POST .../bind` 会话绑定；chat `attachment_ids`（≤5）
  发送时验主＋原子绑定后透传。
- 八格式：pdf（fitz 逐页）/docx（段落＋表格定位）/jpg·png（Pillow 校验＋
  尺寸，直传保留字节）/xlsx（openpyxl 只读，sheet 范围，10 万格截断）/
  pptx（slide＋备注＋表）/ppt·doc（LibreOffice，无则如实 failed）。
- 引用：每 block 自带 locator（pN/slideN/paraN/tableN/sheet:X）；模型侧
  `read_attachment` 工具（双模式共用，第 8/第 5 工具）按 locator 精读。
- 视觉：无视觉模型配置 → `vision=unavailable`；OCR 走 PaddleOCR HTTP
 （`ocr_port.get_ocr_port`），无服务 → `ocr=unavailable`，不阻塞 ready，
  不冒充看图。
- 配额/生命周期：单文件 20MiB、用户活跃 50MiB/20 个；未绑定 24h、已绑定 7d
  （惰性过期）；删除立即撤销＋尽力清对象；魔数嗅探＋扩展名交叉验证；
  客户端可判定错误 422（无行），服务端侧失败落 failed 行。
- 内容永不进入课程知识域/LearningEvidence/Course Graph（只进会话上下文）。

## NX-E1 run/恢复：交付内容

- `nexus_runs` 表（run_id=approval_id，幂等键）：执行成功后 Runtime 经内部
  端点登记 linkage；冲突属他人 → 409 拒绝覆盖（upsert 限定 owner）。
- `GET /nexus/runs?session_id=`（恢复查询，只读）＋`GET /nexus/runs/{id}`：
  实时态与 Worker 合并；Worker 无此 job → unknown＋不可恢复说明；
  不可达 → stale 快照；跨用户空列表/404。
- 前端：切会话/初载即恢复（未终态续轮询、孤儿 run 建恢复 turn、成功态抑制
  自动补报告＋手动"补领报告"）；**恢复路径永不重新提交**。
- 可移植 DDL（TEXT/REAL epoch/JSON-as-TEXT）：恢复语义本地全测，
  与 artifacts 的 PG-only 模式不同（代码注释写明理由）。
