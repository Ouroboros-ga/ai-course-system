## 验收中发现并修复的缺陷（均已随部署上线）

1. **归属登记断层**（`1338467b`）：NX-G2 审批执行路径的
   `_record_job_ownership` 依赖聊天请求作用域 ContextVar（审批执行端点未
   设置）→ 静默失败 → M4 归属表 `nexus_repro_jobs` 无记录 → 作业状态查询
   永久 404、进度永不更新。修复：Runtime 显式传 user_id ＋ Backend
   /repro-runs 收口同步写归属表。
2. **轮询 code 键信封冲突**（`1338467b`，M4 起即存在）：作业记录恒含
   `code(null)` 键，`allowFlatResponse` 的"无 code 键才算裸响应"形状探测把
   整个记录误判为业务错误响应并拒绝，tick 静默吞掉。修复：request.js 新增
   `flatEnvelope` 显式声明。
3. **恢复标记误持久化**（`8ce3597f`/`bc8762b0`）：`_runsRestored` 被写进
   localStorage，刷新后 runs 恢复被脏标记永久跳过。修复：页面级 Set＋加载时
   清理残留。
4. **附件清单未注入**（`b9d0ddda`）：Runtime 不向模型暴露附件 id/文件名，
   read_attachment 必然 NOT_IN_SCOPE。修复：Backend 构建元数据清单随 payload
   透传，Runtime 注入消息前缀注记。
