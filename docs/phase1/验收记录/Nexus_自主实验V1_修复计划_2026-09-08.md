## 1. 批次 A：P1 正确性与契约（必须先做）

### A1 · 终态判定只认 execute（P1-1）

**文件**：`nexus/src/nexus/experiment_agent.py`、`nexus/src/nexus/experiment_report.py`。

**改法**：文件工具仍记 attempt（T5-1 对账语义不变），但不再参与终态判定——
- `_execute_under_lock`：`last_exit` 只在 `name == "execute"` 时更新；文件工具分支记 attempt 时 `config_changes={"kind": "file_tool"}`。
- `build_experiment_report`：`execution_succeeded` 的末个退出码只取 `config_changes.kind != "file_tool"` 的 attempt（缺省视为 execute，兼容旧行）。

**验收**：新增用例——脚本化模型 `execute` 失败（exit 1）后 `read_file` 成功，run 必须 `failed`、报告 `execution_succeeded is False`；反向用例（末次 execute 成功）保持 succeeded。

### A2 · 控制面 §2 契约补齐（P1-2）

**文件**：`nexus/src/nexus/experiment_sandbox.py`、`deploy/repro-runtime/service.py`、`deploy/repro-runtime/swerex_adapter.py`。

**改法**：
- `PUT /sandboxes/{run_id}` 请求体带 `scope_hash`：服务端首次落盘、重复 PUT 比对，不同 → 409 `SCOPE_HASH_MISMATCH`；客户端由 `_backend_from_settings` 从 run 行取 `scope_hash` 注入。
- 工作区限定：服务端 `REPRO_WORKSPACE_ROOT`（默认 `/workspace`），路径必须落在根内，否则 422 `PATH_OUTSIDE_WORKSPACE`；客户端同步校验。
- symlink 逃逸：`swerex_adapter.resolve_real_path()` 用 `readlink -f` 解析父目录，解析结果逃出工作区 → 422 `PATH_SYMLINK_ESCAPE`（读/写/上传三路径统一走）。

**验收**：service 侧新增（同 run 同 hash 幂等 / 异 hash 409 / 越界 422 / symlink 逃逸 422）；客户端 ensure 请求体含 scope_hash 断言。

### A3 · 后端独立执行门（P1-3）

**文件**：`backend/app/api/v1/endpoints/nexus_proxy.py`。

**改法**：`POST /repro/execute` 在转发前做与 Runtime 同码的判定——`mode == "research"` 且显式 `research_execution_mode` 非 `auto` → 403 `EXPERIMENT_EXECUTION_DISABLED`，零转发零提交（未显式传值时仍交 Runtime 按会话偏好裁决，不误伤偏好=auto）。

**验收**：`backend/tests/test_nexus_proxy.py` 新增显式 Ask→403 且上游零调用；显式 auto 与缺省透传保持原语义。

### A4 · 资源上限闭环（P1-4）

**文件**：`experiment_sandbox.py`、`service.py`、`swerex_adapter.py`。

**改法**：ensure 请求体带 `resources`（cpu/memory_mb/disk_mb/wall_time_s）；服务端按声明派生容器参数（`--memory/--cpus/--pids-limit/--storage-opt size=`），磁盘参数不被存储驱动支持时**如实降级并记录 note**，不假装生效；`wall_time_s` 作为 run 级截止——超时后新 operation 返回 409 `WALL_TIME_EXCEEDED`，已运行操作结果保留。

**验收**：service 新增（resources→docker_args 派生、超出服务端上限 422、wall_time 到期 409）；缺 resources 时回退现有 env 默认（兼容旧客户端）。

### A5 · T5 恢复接线（P1-5）

**文件**：`nexus/src/nexus/experiment_store.py`、`nexus/src/nexus/main.py`。

**改法**：console 端点对 `status=running` 的 run 调 `adopt_running_operation`（只查不交），把接管结果并入快照（`console_status`/`active_operation`）；查询失败仍 `reconciling`，绝不 submit。

**验收**：新增用例驱动接线函数——运行中 run 经 console 路径只产生 GET 查询、`operation_posts` 不增；终态 run 不碰控制服务。

### A6 · pull=never 与镜像（P1-6）

**改法**：`service.py` 构造 adapter 时传 `pull=os.environ.get("REPRO_TASK_PULL", "never")`；缺镜像时启动失败如实报错，不静默联网拉取。

**验收**：service 用例断言 adapter 收到 `pull="never"`（env 覆盖为 missing 时生效）。

### A7 · 配方镜像 digest 落地（P1-7）

**改法**：adapter `start()` 后 `docker inspect --format {{.Image}}` 采集镜像 ID（失败留空＋note）；service 落 run 记录并随 `GET /sandboxes/{run_id}` 暴露；Nexus 报告端点生成前经 `sandbox_status()` 取值传入 `build_stored_report(image=…, image_digest=…)`。

**验收**：service 用例断言 digest 出现在 lifecycle；报告用例断言传入值进配方；采集失败时为空且不编造。

### A8 · 文档与回执订正（P1-9）

- `docs/phase1/CodeNexus_P2开发计划.md` CURRENT 段按 T7 要求标注受限已验收范围（"CPU 公开仓库的一次确认自主配置与运行 V1"）与未验收项；`docs/DOCUMENTATION_INDEX.md` 同步。

## 3. 不修/降级声明（需产品/契约决策）

- **P2-7 操作级取消**：任务书 §2 只定义 run 级取消；"模型终止自己卡住的命令"需新增 operation 级 API＋模型工具，属契约扩展，不在本轮改。

- **P2-9 自主 run 指标采集**：无指标来源（论文指标未结构化），保持 `not_evaluated` 的诚实口径。
- **P2-12 SR6 转换器**：任务书倾向 Pandoc，实现为标准库手组（零新依赖）；换 Pandoc 需新依赖授权。
- **P2-13 前端行为级测试**：现为源码正则断言；引入组件测试框架属新依赖。
- **T7 真实模型/真容器验收、LaTeX 编译证明**：需线上授权与 TeX 工具链。
