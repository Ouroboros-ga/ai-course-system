## 3. 阻塞与根因（教训）

现象：lifespan 持续 `fallback to memory: permission denied for database ai_course`，
而同串直连成功。逐层二分（同步/异步 × 文件/环境 × 有/无 `User=root`、环境元数据 diff、
`/proc` 进程环境哈希比对）后确认：

- **不是 CONNECT 缺权**（`has_database_privilege(...,'CONNECT')=True`），
  **是 `CREATE SCHEMA` 缺库级 CREATE 权**——PG 对两者报完全相同的
  `permission denied for database` 文本（`CREATE SCHEMA` 需库级 CREATE 权）。
- 修复后 lifespan 一次通过；`main.py` 已加 `step=` 步骤标记，
  下次同类问题可直接区分 `ensure_schema_threads_table` 与 `saver_setup`。

另见异常（未解，不阻塞）：20:13:13 有一次非本会话发起的干净重启（`systemd stop`，
无交互登录记录）；当时另有未提交的前端改动在工作区。如有其他自动化在操作该机，
建议对账一次。
