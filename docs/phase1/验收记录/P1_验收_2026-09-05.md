## 3. 遗留观察（不阻塞 P1，需后续处理）

1. **`nexus_checkpoints` 五表属主迁移**：restore 后属主为 `ai_course_bootstrap`，
   本次 DDL（`ADD COLUMN title`）因 `must be owner` 失败导致 persistence 首次
   降级 memory。已将五表属主统一 `ALTER ... OWNER TO ai_course_app`（该 schema
   本就是 Nexus DSN 用户的数据域）。教训：**迁移 restore 后要核对 schema 属主**
2. **前端服务器构建能力缺失**：`/opt/smartcarb/shared/node_modules` 未随迁移
   就位（`vite` 不可达），本次 release 用本地上传 dist 完成跳过构建分支。
   后续应在新机补一次依赖安装恢复服务器端构建；另补
   `/opt/node-v22-current → /opt/node-v22.23.2-linux-x64` 软链（已完成）
3. **工具面收敛口径失效（既有）**：health `tool_surface` 出现 deepagents 内置
   `write_file/execute/task` 等（main.py M0-B1 注释口径为 read_file+四产品工具），
   为 `cbd89410` StateBackend 接线后的现象。其中 `execute` 为进程内 shell 执行，
   按 AGENTS.md §4.1.10 精神（不可信代码不进 Nexus 进程）应单独评估收敛——
   建议列入 P2 首项
