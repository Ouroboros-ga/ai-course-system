## 3. 关键差异与处置

1. **公网入口必须用域名**：新接入商对未备案裸 IP 的 80/443 做拦截页
   （`http://103.36.223.177/` 运营商提示页）。迁移配置里已含 `zsitai.xyz` +
   证书且 DNS 已指向新机 → **`https://zsitai.xyz/` 实测 200、API 鉴权正常**，
   作为正式入口。（另在 nginx 80 块加了 `listen 18080` 备用监听，当前 301
   到 https，如需 IP 直连备用通道可再调整为独立 server 块。）
2. **repro-worker 镜像不含 torch**：旧机最终 torch 镜像因构建 tag 未落上而
   丢失（考古：rebuild5 自检通过但 latest 未更新，容器也已在迁移中重建）。
   处置：新机重新构建（Dockerfile 自带 tuna 镜像源 + import 自检），构建中；
   完成后 recreate 容器即可。
3. **iptables 出站白名单未迁移**（Docker 网桥 ID 变化，规则失效）：功能不受
   影响，属 hardening 项——worker 定型后在 `/opt/smartcarb/repro-worker/`
   重跑 `refresh-iptables.sh`。
4. compose 插件新机缺失：worker 已临时以等价 `docker run` 参数运行；
   长期修复 `apt install docker-compose-plugin` 或统一用 run 脚本。
