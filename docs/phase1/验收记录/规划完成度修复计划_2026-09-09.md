## 1. 批次 A：Nexus 显式迁移机制（P1-1）

**问题**：任务书 T2 与 P2 计划 §9.7 均明文"显式迁移、**不写启动时DDL**"，实现却在
lifespan/懒加载路径执行 `CREATE TABLE IF NOT EXISTS` ＋ `ADD COLUMN IF NOT EXISTS`
（`main.py:70-100`、`proposals.py:411-432`、`approvals.py:174-199`、`experiment_runs.py:76-96`、
`execution_mode.py:85-88`、`persistence.py:61-92`）。

**范围界定**：仅 Nexus 运行时侧（PG-only）。backend 侧 `nexus_run_service.py`/
`nexus_artifact_service.py` 的 DDL 是**双方言设计**（SQLite 部署与测试直接依赖，`test_nexus_lb1_lb2.py:111`
直接调用 `migrate_nexus_runs`），不属本批偏离，排除。

**改法**：
1. 新增 `nexus/migrations/0001_nexus_baseline.sql`：`{schema}` 占位符，幂等
   （`CREATE SCHEMA/TABLE IF NOT EXISTS` ＋ `ADD COLUMN IF NOT EXISTS`），覆盖
   `nexus_threads/nexus_proposals/nexus_approvals/nexus_experiment_runs/nexus_session_prefs`
   及其索引与全部增量列；文件头写明回退说明。
2. 新增 `nexus/scripts/apply_nexus_migrations.py`：以 `NEXUS_POSTGRES_DSN` 连接，
   ledger 表 `{schema}.nexus_schema_migrations(version, applied_at, checksum)`；
   按版本序应用未执行文件（逐文件事务，失败回滚并 exit 2）；支持 `--status`/`--dry-run`。
3. **移除启动 DDL**：lifespan 改为只读的 schema 检查（缺失时记明确 error，不建表）；
   删除 5 个 `ensure_*_table` 函数及其懒加载调用；DDL 常量迁入迁移文件。
4. 发布脚本：同步 nexus 后、重启 nexus-runtime 前执行 `apply_nexus_migrations.py`，失败即中止。
5. 守卫测试：源码级断言 `nexus/src/nexus/*.py` 不含 `CREATE TABLE`/`ADD COLUMN`/`CREATE SCHEMA`；
   runner 单测（版本序、幂等、checksum、dry-run）。

**验收**：`nexus/.venv/Scripts/python.exe -m pytest nexus/tests/test_nexus_migrations.py -q` 全绿；
nexus 全量套件不回归。
