## 2. 迁移的调用点

1. 数字人视频生成 service
   - 文件：`backend/app/services/video_generation_service.py`
   - 函数：`VideoGenerationService.generate_node_video`
   - 旧调用：`digital_human_client.generate_video`
   - 新调用：`DigitalHumanAdapter(digital_human_client).generate_video`

2. 视频生成中的 TTS 合成
   - 文件：`backend/app/services/video_generation_service.py`
   - 函数：`VideoGenerationService._synthesize_tts`
   - 旧调用：`tts_client.synthesize`
   - 新调用：`TTSAdapter(tts_client).synthesize`

3. PPT 生成 service
   - 文件：`backend/app/services/ppt_generation_service.py`
   - 函数：`PPTGenerationService.generate_ppt`
   - 旧调用：`self.xfyun_client.get_theme_list/create_ppt_task/wait_for_completion/download_ppt`
   - 新调用：`PPTAdapter(self.xfyun_client)` 对应方法

4. 节点音频合成路由
   - 文件：`backend/app/api/v1/endpoints/document.py`
   - 路由：`POST /api/v1/document/course/{course_id}/node/{node_id}/synthesize-audio`
   - 旧调用：`tts_client.synthesize`
   - 新调用：`TTSAdapter(tts_client).synthesize`

5. AI 问答 service 普通问答分支
   - 文件：`backend/app/services/qa_service.py`
   - 函数：`QAService.ask_question_with_rag`
   - 分支：`strict_mode=False`
   - 旧调用：`llm_client.chat(messages, temperature=0.7)`
   - 新调用：`LLMAdapter(llm_client).chat(messages, temperature=0.7)`

## 3. 未迁移的调用点

- `backend/app/services/document_service.py` 多处 LLM 调用：超大文件、跨课件解析和脚本生成主流程，R1 不拆分不重写。
- `backend/app/services/mapping_service.py` LLM 调用：非本轮最小接入路径。
- `backend/app/services/progress_service.py` LLM 调用：非本轮最小接入路径。
- `backend/app/services/prerequisite_service.py` LLM 调用：已有 M4B fake 覆盖，暂不扩大。
- `backend/app/services/smart_course_service.py` LLM 调用：非本轮最小接入路径。
- `backend/app/api/v1/endpoints/document.py` 其他 TTS 调用：只迁移节点音频合成路径。
- `backend/app/api/v1/endpoints/asset.py` 声音复刻业务调用：adapter 已有，缺少本轮业务契约测试，暂不迁移。
- `backend/app/api/v1/endpoints/platform.py` 泛雅 httpx 调用：`ExternalHTTPAdapter` 已有，端点迁移留待平台契约测试。
- `backend/app/api/v1/endpoints/video.py` 远程视频 httpx 调用：`ExternalHTTPAdapter` 已有，端点迁移留待远程视频契约测试。
- `backend/app/api/v1/endpoints/video_generation.py` 数字人健康检查：本轮只迁移 service 生成主路径。

## 9. 已知风险

- adapter 层已覆盖声音复刻和外部 HTTP，但业务调用点暂未迁移，需要后续配套端点契约测试。
- `document.py` 仍有其他 TTS 调用未迁移，后续迁移前需先补对应业务测试。
- `document_service.py` 仍有多处 LLM 调用，文件体量和职责过大，后续应在测试基线更稳后再分批迁移。
- 全量 `backend/tests` 仍存在历史失败，R1 只保证 M4A/M4B 关键回归和新增 adapter 测试通过。
- 前端 build 在沙箱内会因 esbuild 子进程 `spawn EPERM` 失败，需提升权限运行同一命令。

## 10. 回滚方法

未提交时回滚：

```text
git checkout -- backend/app/platform backend/app/services/video_generation_service.py backend/app/services/ppt_generation_service.py backend/app/services/qa_service.py backend/app/api/v1/endpoints/document.py backend/tests/test_r1_adapters.py backend/tests/test_r1_adapter_migration.py docs/refactor/R1外部服务适配层设计.md docs/refactor/R1迁移报告.md
```

已提交后回滚：

```text
git revert <R1提交ID>
```

回滚影响：

- 删除新 adapter 层。
- 恢复四个迁移调用点的旧 client 直连方式。
- 删除 R1 新增测试和文档。
- 不涉及数据库回滚。
