# R2D0 教育知识图谱本体与构建算法

## 1. 本体目标

图谱服务教学解释、先修路径、例题/公式关联与可引用问答。每个自动节点和边必须能追到 `SourceBlock`；“LLM 认为正确”不是证据。Ontology 版本与 GraphSnapshot 绑定。

## 2. 节点类型

| 类型 | 含义与最小属性 |
|---|---|
| Course | 课程；`course_id,title` |
| Chapter | 章；`ordinal,title` |
| Section | 节；`ordinal,title` |
| KnowledgePoint | 可教学/考核的知识单元；`canonical_name,aliases,difficulty` |
| Concept | 术语或抽象概念 |
| Definition | 定义陈述 |
| Formula | 公式；`latex,normalized_latex` |
| Theorem | 定理/性质及条件 |
| Method | 解法、算法、步骤 |
| Skill | 可观察操作能力 |
| Example | 讲解示例 |
| Exercise | 练习/测验；`answer_ref` 可选 |
| Misconception | 常见错误认识 |
| LearningObjective | 学习目标 |
| SourceBlock | DocumentIR block 的图中引用，不复制其全文作为唯一源 |
| PageOrSlide | 页/幻灯片；`index,label` |

节点共有字段：`node_id, snapshot_id, ontology_version, type, canonical_key, name, aliases, properties, status, confidence, created_by_run, valid_from/to`。

## 3. 关系约束

`证据`列中“必需”表示自动 accepted 前至少一条 `GraphEvidence`；人工创建同样记录 reviewer 与理由。

| 关系 | 允许 source -> target | 有向 | 自环 | 证据 | 可审核 | 路径检索 |
|---|---|---:|---:|---:|---:|---:|
| CONTAINS | Course/Chapter/Section -> Chapter/Section/KnowledgePoint/Objective | 是 | 否 | 必需 | 是 | 是 |
| PART_OF | Chapter/Section/KnowledgePoint -> Course/Chapter/Section | 是 | 否 | 必需 | 是 | 是 |
| DEFINES | Definition/SourceBlock -> Concept/KnowledgePoint | 是 | 否 | 必需 | 是 | 是 |
| EXPLAINS | Section/Example/SourceBlock -> KnowledgePoint/Concept/Formula/Method | 是 | 否 | 必需 | 是 | 是 |
| PREREQUISITE_OF | KnowledgePoint/Concept/Skill -> KnowledgePoint/Concept/Skill | 是 | 否 | 必需 | 是 | 是，DAG |
| DERIVES_FROM | Formula/Theorem/Method -> Formula/Theorem/Concept | 是 | 否 | 必需 | 是 | 是 |
| USES | Method/Example/Exercise/Skill -> Concept/KnowledgePoint/Method | 是 | 否 | 必需 | 是 | 是 |
| USES_FORMULA | Method/Example/Exercise/Theorem -> Formula | 是 | 否 | 必需 | 是 | 是 |
| HAS_EXAMPLE | KnowledgePoint/Concept/Method -> Example | 是 | 否 | 必需 | 是 | 是 |
| TESTS | Exercise -> KnowledgePoint/Concept/Skill/Method | 是 | 否 | 必需 | 是 | 是 |
| CONTRASTS_WITH | Concept/Method/Misconception -> 同类兼容类型 | 否 | 否 | 必需 | 是 | 是 |
| CAUSES | Concept/Event-like KnowledgePoint/Misconception -> Concept/Result-like KnowledgePoint | 是 | 否 | 必需 | 是 | 是 |
| RELATED_TO | KnowledgePoint/Concept/Method -> 同类 | 否 | 否 | 必需 | 是 | 受限，低权重 |
| SUPPORTED_BY | 任意语义节点/边声明 -> SourceBlock | 是 | 否 | 本身即证据 | 是 | 否 |
| APPEARS_ON | SourceBlock/语义节点 -> PageOrSlide | 是 | 否 | 必需 | 是 | 否 |

`PART_OF` 可由 `CONTAINS` 反向派生，不重复抽取；`RELATED_TO` 不能用于先修推理。`PREREQUISITE_OF` 必须无环；发现环时边进入 `needs_review`，不能自动删掉高价值证据。

## 4. 构建流水线

1. **确定性结构图**：Course/Chapter/Section/PageOrSlide/SourceBlock 从 DocumentIR 和 EducationalUnit 直接生成。
2. **实体候选**：按 unit/chunk 使用严格 schema 抽取；输出 mention span、type、name、properties 和 evidence block IDs。
3. **关系候选**：仅在已知实体、允许类型矩阵和当前/邻近 chunk 内抽取。
4. **规范化**：Unicode、大小写、空白、符号、公式规范化；生成 `canonical_key`。
5. **别名合并**：exact key -> alias dictionary -> lexical/vector candidate；不确定合并进 review。
6. **关系验证**：endpoint 存在、类型允许、方向、非自环、证据跨度、重复边。
7. **先修环检测**：对 accepted + candidate 高置信先修边运行 SCC/拓扑检测。
8. **证据检查**：block 必须属于同一 artifact/course scope，span/bbox 有效，引用文本哈希匹配。
9. **置信度**：组合 extraction、evidence、canonicalization、constraint、cross-parser 分数；按关系类型校准。
10. **教师审核队列**：冲突、先修边、低置信合并、跨章边优先。
11. **快照发布**：候选 run 冻结；只有 accepted 节点/边进入不可变 snapshot，原 active pointer 原子切换。

禁止单次 prompt 直接写最终图。LLM/VLM 只产 candidate；校验、状态和发布由确定性代码控制。

## 5. 状态机

```text
candidate -> accepted
candidate -> needs_review -> accepted | rejected
candidate -> rejected
accepted  -> superseded（新快照中替代，不原地抹除审计记录）
```

- `candidate`：结构合法但尚未通过全部规则/阈值。
- `accepted`：满足 schema、证据和置信门槛，或经教师批准。
- `rejected`：违反硬约束、无证据或经教师否决。
- `needs_review`：证据冲突、置信度中间区、别名合并不确定、先修环等。

初始拟议阈值：普通边 `>=0.85` 自动 accepted，`0.60-0.85` review；先修边 `>=0.90` 且无环才自动 accepted。阈值必须由标注集校准。

## 7. 混合检索

查询流水线：scope 过滤 -> query classification -> BM25/关键词 + 向量召回 -> entity linking -> graph seeds -> 允许边类型/最大 2 hop/每类 fan-out 的受控扩展 -> evidence blocks 原文召回 -> rerank -> cited context。

| 问题 | 检索策略 |
|---|---|
| 定义 | Concept/Definition 精确实体 + DEFINES/EXPLAINS + 原文 |
| 公式 | Formula 符号/LaTeX 规范匹配 + USES_FORMULA/DERIVES_FROM |
| 例题 | Example/Exercise + HAS_EXAMPLE/TESTS/USES，附题面页 |
| 先修 | PREREQUISITE_OF 反向受控遍历，检测 snapshot DAG |
| 跨章节 | 多实体 seed + CONTAINS/PART_OF 和高置信语义边 |
| 课程概览 | 结构图 + LearningObjective/KnowledgePoint，禁止无界社区总结 |
| 无答案 | 低 evidence coverage 时明确无答案，不让 LLM补全事实 |

最终每个 context item 必带 `course_id, artifact_id, page_or_slide, block_id, evidence_id, bbox/span, snapshot_id`；回答引用不得只给文件名或 preview。
