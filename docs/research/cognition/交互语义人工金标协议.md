# 交互语义人工金标协议

## 适用范围

该协议用于评估规则、未来外部模型或 LLM 的**候选交互标签**，不用于给学生正式掌握度打分。正式数据必须是假名化受保护数据；仓库中的 `interaction_gold_synthetic_v1.json` 仅验证格式、工具和指标。

## 标注单位

每条记录是一个稳定 `source_event_id` 的学生单次输入，并带课程/知识点作用域。一个事件可有多个标签，但同一事件不得被拆成多条独立证据。

| 标签 | 标注为真 | 不标注为真 |
| --- | --- | --- |
| `confusion_risk` | 明确说不理解、无法继续、概念矛盾或持续困惑。 | 单纯请求定义、正常澄清、语气词。 |
| `inquiry_depth` | 提出条件、反例、迁移、跨概念关系或可检验假设。 | 仅把题目复述为“怎么做”。 |
| `hint_dependency` | 明确要求完整答案、下一步提示或反复索取外部步骤。 | 教师主动提供提示，或学生要求解释原理。 |
| `explanation_need` | 表示需要原理、因果链、步骤解释，或解释后仍未解决。 | 只要最终答案、闲聊或资源导航。 |

## 流程与门禁

1. 两名标注者独立标注，互相不可见；保留标注版本与理由。
2. 分歧交由第三方裁决，形成不可覆盖的 adjudication 记录。
3. 按标签报告 precision、recall、F1、覆盖率和混淆案例；不只报告总分。
4. 模型缺失预测、跨课程输入或无法验证来源时，评测整批拒绝，不对剩余样本打分。
5. 只有金标完成、隐私审查通过、课程隔离可验证后，未来候选模型才可进入 Shadow 对照；仍不可直接写入表现分。
