# R1、R2、R3 离线检索消融实验报告

## 范围与结论

本报告只覆盖 `reviewed_silver_v0_2` 上的离线研究实现，不是正式 Human Gold，不构成生产接入或线上效果承诺。所有运行均课程隔离、保留 Evidence/Citation，并且运行阶段不读取 qrels 或答案标签。

结论很直接：在这份 Silver fixture 的最终 test split 上，R2（BM25 + Dense RRF）优于 R0 和 R1；受限一跳 R3 没有超过 R2。因此，当前不应仅因为已构建课程图谱而把图扩展纳入在线问答链路。

## 固定输入与方法

- fixture：`research/product1_graph_retrieval/datasets/reviewed_silver_v0_2`，manifest SHA-256 为 `ea1f660d0c73dff28f1815456a8ab683bde487d85db70f44b6a8c43c41063975`。
- R0：课程独立 BM25，唯一冻结 tokenizer。
- R1：本地 `BAAI/bge-small-zh-v1.5`，revision `7999e1d3359715c523056ef9478215996d62a620`，`model.safetensors` SHA-256 `354763b9b1357bc9c44f62c6be2276321081ed2567773608c0d0785b61d5a026`，CLS pooling、L2 normalization、精确余弦，不使用 FAISS、向量数据库或外部服务。
- R2：冻结 R0/R1 结果上的 RRF（`k=60`，两路权重均为 `1.0`），最终候选数固定 50。
- R3：从 R2 前 10 个 seed 按分数衰减 `0.5` 扩展；仅允许同课程、`accepted`、`slide_block_structure` 的 `PPTSlide -[MAPPED_TO]-> ScriptNode` 一跳结构边；每个 seed 最多 5 条关系，最多 10 个图候选，最终候选仍固定 50。没有使用或生成任何语义边。

## 验证集调参

R1 只在 validation 比较 query instruction：无 instruction 的 `MRR=0.7206`、`nDCG@10=0.5225`，优于带 instruction 的 `MRR=0.6394`、`nDCG@10=0.4563`，因此固定为空字符串后才运行一次 test。

R3 只在 validation 比较图分数衰减：

|衰减|MRR|Recall@5|nDCG@10|判断|
|---:|---:|---:|---:|---|
|0.25|0.6997|0.5000|0.5520|与 R2 相同|
|0.50|0.6997|0.5000|0.5520|选定的保守配置|
|1.00|0.5503|0.4286|0.4164|明显退化|

R3 未使用 test 标签选择参数；选定配置仅运行一次 test。

## 最终 test 结果

|方法|Recall@5|MRR|nDCG@10|跨课程污染|Evidence 完整性|Citation Key 有效性|无答案误答率|
|---|---:|---:|---:|---:|---:|---:|---:|
|R0 BM25|0.4000|0.5034|0.4222|0.0000|1.0000|1.0000|1.0000|
|R1 Dense|0.4222|0.4744|0.4043|0.0000|1.0000|1.0000|1.0000|
|R2 BM25 + Dense + RRF|0.4889|0.5148|0.4702|0.0000|1.0000|1.0000|1.0000|
|R3 R2 + 一跳结构图扩展|0.4889|0.5148|0.4702|0.0000|1.0000|1.0000|1.0000|

R3 的 test 输出包含 154 个由图结构扩展得到的命中，覆盖全部 20 个 test 查询（共 1000 个最终命中）。这说明图确实改变了候选集合，而非空操作；但它没有改变上述评价指标，也没有修复无答案误答。因此在当前数据与预算下，图扩展只增加了结构候选，未证明有检索增益。

## 已知限制与下一步

1. 无答案查询仍全部误答；这不是生成层问题，而是目前 BM25/Dense/RRF/R3 都没有足够的拒答阈值或校准器。
2. Reviewed Silver 有人工修改与 LLM 协作整理，但不等价于正式双人独立标注的 Human Gold；不能据此宣称泛化提升。
3. 若继续研究，应先建立独立 Human Gold 或保留测试集，再研究拒答校准、跨语言别名和更有信息量但仍受审核的图边；不应直接接入生产链路。
