# Human Gold 冻结报告模板

## 标识

candidate_id / protocol_version / source_manifest_sha256 / 冻结时间 / 冻结责任人：

## 输入与契约

课程 ID（3–5 门）、文件 hash、授权引用、隐私复核引用、DocumentIR/Evidence/Citation/Education Graph 契约版本：

## 标注与仲裁

A/B/仲裁员 member_id（身份只引用外部受控记录）、身份记录引用、独立性声明 hash、各 bundle hash、retrieval/mapping 两份仲裁文件 hash、分任务原始标签分歧数、不确定性升级数、需仲裁总数与解决数、校准记录引用：

## 数据统计

## 完整性
