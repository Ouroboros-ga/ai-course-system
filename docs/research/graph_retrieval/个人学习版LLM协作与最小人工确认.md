# 个人学习版：LLM 整理与最小人工确认

适用对象：个人开发者，用老师提供的课程 PPT/PDF 学习 RAG、知识图谱和可信检索。

这个版本不要求企业式授权表、身份核验、双人标注或仲裁。你已经说明课程材料来自授课老师、仅个人学习、不商业化；本说明按此边界工作。

## 一句话原则

LLM 负责“读懂、整理、生成草案”；人只负责“这是不是你要学的、老师是不是这样讲的”。

因此，LLM 可以先做：

- PPT/PDF/OCR 文本整理；
- 知识点、别名、章节和页码的草案；
- 学习问题、问题类别、答案草案；
- 检索候选、引用草案、知识图谱边和 LLM 参考 qrels；
- 对疑似图表、公式或图片页给出解释和不确定性提示。

下面这些决定仍值得人来点一下或改一下，因为它们取决于你的学习目标和老师的课程语境：

| 你要确认的事 | 为什么 LLM 不能替你最终决定 | 怎么填 |
|---|---|---|
| 课程是否纳入 | 只有你知道这门课是否是当前 RAG 学习范围 | 在“课程范围”选“保留”或“暂不使用” |
| 问题是否有学习价值 | 同一个问题可能语义正确，但对你当前学习无用、太简单或超纲 | 在“问题清单”选“保留 / 改写 / 不需要”；只有改写时填写新问题 |
| 知识点名称是否符合老师讲法 | 教师常用术语、课程重点和你的记忆习惯无法仅从文本可靠推出 | 在“知识点清单”选“保留 / 改名 / 合并 / 不需要”；只有改名或合并时写原因 |
| 少数图片、公式、流程图是否明显错读 | LLM 视觉理解已经很强，但你能最快发现“这张图不是这个意思” | 只在“疑难页面”发现关键错误时选“需要补充”，写一句说明；其余可不填 |
| 章节边界是否明显错误 | 大多数可直接用 LLM 草案；只有目录或页码明显不对才需要改 | “章节核对”默认不填；发现明显错位才填“改”及正确页码 |

## 不需要你人工填写的内容

- 每道题的标准答案；
- answerability、relevance 0/1/2、qrels；
- 每个 Evidence 的精确字符区间和 Citation；
- OCR 置信度、bbox、模型参数；
- 课程内所有页面的一一映射；
- 身份、授权、仲裁、审批等企业治理字段。

这些内容由 LLM 生成“学习参考草案”。后续你可以抽样检查，也可以用它跑本地 RAG 实验；但报告里应称为“LLM 辅助参考集”，不要称为“双人人工 Gold”或“人工准确率”。

## 最省事填写顺序

1. 先在“课程范围”把要学习的课程标为“保留”。
2. 在“问题清单”快速扫一遍：有用就“保留”，表述别扭就“改写”，不想学就“不需要”。
3. 在“知识点清单”只处理名称明显不对、重复或不需要的项。
4. 仅当关键图、公式或流程图明显被误读时填写“疑难页面”。
5. “章节核对”无明显错误时不需要填写。

完成后，LLM 可以把这些人工确认合并到学习版 DocumentIR、Evidence、RAG 查询集和知识图谱草案中；仍不自动宣布为正式人工 Gold 或放行生产算法。
