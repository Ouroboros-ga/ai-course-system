# 知识图谱定位决议：展示与认知推荐，暂不接入在线检索

> **状态**：已决议（2026-07-23）
> **配套文档**：[`生产检索基线决议_R2_RRF.md`](./生产检索基线决议_R2_RRF.md)（检索排序用 R2 RRF，不用图扩展）
> **适用范围**：知识图谱在产品中的角色定位，覆盖 graph_shadow（G3E1）、`product1_cognition` 图结构、前端图谱浏览器、教学智能体 KnowledgeGraphPort。

---

## 1. 决议

知识图谱在当前阶段**仅承担两类用途**：

1. **展示**：作为可视化、治理和离线研究工件呈现给用户/教师/评委，不参与在线检索排序。
2. **学习认知推荐算法**：在 `product1_cognition`（KG-MEST）中作为只读输入，提供知识点锚定（Q-Matrix）、先修 DAG（弱先修识别）、资源索引，支撑掌握度诊断与学习路径推荐。

**图 RAG（图谱扩展接入在线检索排序）暂时搁置**，不作为生产候选路径。

## 2. 依据

- **图 RAG 效果在未调试优化下一般**：在 `reviewed_silver_v0_2` 离线评测中，R3（受限一跳结构图扩展）的 Recall@5 与 MRR 相对 R2（BM25 + BGE Dense + RRF）均未提升（详见 `R1_R2_R3_离线检索消融实验报告.md`、`生产检索基线决议_R2_RRF.md`）。
- 在缺乏针对图检索的检索增强/重排/查询路径调优前，接入图扩展不带来收益，反而增加在线链路复杂度与不确定性。
- 因此**不以"已有图谱"为由把图扩展接入检索链路**；待图 RAG 经独立调试优化并在离线评测中相对 R2 取得可验证提升后，再重新评估。

## 3. 运行时常量

- `GRAPH_EXPANSION_PRODUCTION_CANDIDATE_ENABLED = false`
- R2 sidecar provider（`backend/app/platform/retrieval_demo/course_provider.py` `graph_snapshot`）不导入、不调用图扩展；其 `graph_snapshot` 返回 `{"nodes": [], "edges": [], "graph_kind": "disabled_not_a_production_retrieval_candidate"}`，显式标注禁用，不伪造图谱数据。

## 4. 各模块的图谱用途对照

| 模块 | 图谱用途 | 是否参与在线检索排序 |
|---|---|---|
| graph_shadow（G3E1，`platform/shadow/graph_shadow.py`） | 影子生成 EducationalUnit/GraphNode/GraphRelation 候选，写入隔离 shadow store，PROPOSED 状态待治理 | 否（影子，默认 off，不碰 V1 表） |
| `product1_cognition`（KG-MEST） | 真实图结构：`GraphSnapshot`（先修 DAG、Q-Matrix、资源索引）+ 环检测 + 治理门禁；作为**只读输入**支撑掌握度/推荐，不存储状态、不参与推理 | 否（研究基线，离线产报告） |
| 前端 graph-browser | 仅渲染真实接口可证数据（mapping course->知识点->evidence），检索轨迹层显式空态不伪造 | 否（展示） |
| teaching-agent `KnowledgeGraphPort`（`RetrievalDemoKnowledgeGraphPort`） | 消费 R2 sidecar 的 `graph_snapshot`（当前空）做概念解析/上下文 | 否（消费方，当前空数据） |

## 5. 与检索基线的关系

本决议与 [`生产检索基线决议_R2_RRF.md`](./生产检索基线决议_R2_RRF.md) 互补、不冲突：
- **检索决议**回答"在线检索排序用什么" -> R2 RRF（BM25 + 本地 BGE Dense + RRF），不用图扩展。
- **本决议**回答"图谱本身用来干啥" -> 展示 + 认知推荐算法，暂不接入在线检索。

两者共同结论：**在线检索 = R2 RRF 是唯一候选基线；图谱不参与在线检索排序。**

## 6. 解除搁置的前置条件

重新评估图 RAG 接入在线检索，需同时满足：
1. 针对图检索的检索增强/重排/查询路径调优已完成；
2. 在与 R2 相同的离线评测集（或更严格的已审核数据集）上，图增强检索相对 R2 RRF 取得**可验证的 Recall@5 / MRR 提升**；
3. 经 P1-00 + P1-10 评审通过，更新本决议与 `生产检索基线决议_R2_RRF.md`。

在此之前，`GRAPH_EXPANSION_PRODUCTION_CANDIDATE_ENABLED` 保持 `false`，任何模块不得将图扩展接入在线检索排序或伪造图谱检索结果。
