# 产品一功能文档

## 1. 产品概述

**产品名称：基于泛雅平台的 AI 互动智课生成与实时问答系统**

产品面向高校教师与学生，将 PPT、PDF、Word、教案等教学资料转化为可编辑、可发布、可播放、可互动的 AI 互动智课。教师可以完成从资料上传到课程发布的制作流程；学生可以在课程中观看、提问、测验、补学并持续保存学习进度。

产品的核心闭环为：

```text
教学资料
-> 课程解析与脚本
-> 页面映射与音视频表达
-> 课程发布
-> 学生分屏学习
-> 问答、测验与前置补学
-> 学习进度沉淀
```

## 2. 用户角色与功能范围

| 角色 | 使用目标 | 核心功能 |
| --- | --- | --- |
| 教师 | 将已有资料快速建设为可教学课程 | 上传资料、编辑脚本、配置页面映射、生成音视频、预览、发布、管理课程与学生。 |
| 学生 | 在课程上下文中完成学习、复习与补学 | 选课、分屏播放、保存进度、课程问答、测验、前置知识跳转与返回。 |
| 管理员 | 管理账号、课程与受限技术功能 | 账号与权限管理、查看受限的证据/质量验证页面、控制演示环境。 |
| 演示人员 | 保持比赛或答辩现场的教学闭环稳定 | 准备演示账号和课程，使用预生成音视频，在外部服务故障时按预案降级。 |

## 3. 教师互动智课生产功能

### 3.1 资料与素材管理

教师可上传课程所需的教学资料，包括课件、教材、讲义及课程相关素材。上传后，系统创建课程资料记录，并进入后续解析和建课流程。

教师可管理与课程相关的图片、音频等素材。这些素材可用于课程页面、音频生成、数字人视频或演示兜底，不要求教师重新制作全部内容。

功能要点：

1. 上传资料后创建课程与解析记录。
2. 显示资料解析或处理状态，便于教师判断是否可继续建课。
3. 解析异常时保留失败信息，教师可改用已准备课程或重新处理资料。
4. 演示环境可使用固定课件和预置课程，避免现场重复调用外部服务。

### 3.2 课程结构与教学脚本

系统根据资料内容生成课程结构、章节和教学脚本。脚本由多个教学节点组成，每个节点可包含标题、讲稿、顺序、预计时长、知识点和课件页信息。

教师可以：

1. 查看和编辑课程脚本。
2. 调整节点顺序、讲解内容和时长。
3. 保存脚本版本和快照。
4. 在需要时回滚到历史脚本版本。
5. 使用已准备的固定节点完成演示，不依赖现场生成质量。

### 3.3 PPT 页面与知识节点映射

课程脚本中的教学节点需要与课件页面建立对应关系。映射后，播放器可在讲解节点切换时展示相应 PPT 页面。

映射支持自动候选与人工调整。教师可以检查每个节点的页码范围，补充缺失映射，或修改不准确的映射结果。

映射功能的目标不是替代教师审核，而是降低逐页配置成本。对于演示课程，教师可直接使用已经确认的映射结果。

### 3.4 音频、数字人与 AI PPT

系统提供多种课程表达方式：

| 功能 | 教师可获得的结果 | 使用说明 |
| --- | --- | --- |
| TTS 音频生成 | 为单个脚本节点或整门课程生成讲解音频。 | 成功节点保存音频地址与时长；批量任务可显示进行中、完成、部分成功或失败。 |
| 数字人视频生成 | 将讲解音频和形象素材组织为可播放视频任务。 | 任务会展示生成状态；失败时不伪造视频地址。 |
| AI PPT 生成 | 根据教学主题或大纲创建 PPT 生成任务。 | 可作为建课素材来源，仍需教师检查内容和页面映射。 |
| 预生成媒体兜底 | 使用赛前生成的音频或视频继续课程演示。 | 外部服务不可用时保持教学闭环，并明确向观众说明使用了预生成素材。 |

### 3.5 课程预览、发布与管理

教师可在发布前查看课程内容、脚本节点、页面映射和媒体状态。课程发布后，学生才能选课并进入学习流程。

教师可以进行以下课程管理操作：

1. 发布课程。
2. 下架课程。
3. 查看历史课程和课程状态。
4. 删除不再使用的课程。
5. 查看选课学生与课程统计信息。

## 4. 学生学习与互动功能

### 4.1 选课与课程入口

学生登录后可查看已发布课程，完成选课或退课，并在“我的课程”中继续学习。首次选课时，系统为学生建立该课程的学习记录。

### 4.2 分屏互动播放器

学生进入课程后使用分屏播放器学习。播放器围绕当前教学节点组织以下内容：

1. 视频或音频讲解。
2. 对应 PPT 页面或课件内容。
3. 课程节点与章节导航。
4. 当前学习位置和播放进度。
5. 与当前课程相关的问答和测验入口。

播放器的价值在于将“讲解内容、课件页面和学习行为”放在同一学习场景中，而不是让学生在多个独立页面间反复切换。

### 4.3 学习进度与断点续学

系统保存学生在课程中的当前节点、播放位置和学习完成情况。学生离开课程后再次进入，可从最近学习位置继续。

进度功能用于支持：

1. 课程学习过程记录。
2. 学生个人续学。
3. 教师对课程参与情况的基础查看。
4. 后续学习证据和学情分析能力的输入。

### 4.4 课程内 AI 问答

学生可以在学习过程中提出问题，例如“为什么二分查找必须在有序序列中使用”。系统结合当前课程和学习上下文返回解释性回答。

问答功能面向理解与学习辅助，不应被描述为自动完成作业或保证所有问题都正确。外部大模型不可用时，演示可切换到预置问题、课件内容或人工讲解继续说明教学流程。

### 4.5 测验与学习反馈

课程支持生成或展示测验，学生可提交答案并获得学习反馈。测验与课程节点结合，用于帮助学生确认当前内容是否理解，也为后续补学提供依据。

### 4.6 前置知识补学

当学生当前学习内容依赖尚未掌握的前置知识时，系统可给出补学入口。例如学习递归时，可以跳转复习二分查找等前置内容。

学生可以：

1. 查看前置知识缺口提示。
2. 跳转到建议复习的课程节点。
3. 在补学后返回原来的学习节点。
4. 保留跳转历史，避免丢失原学习任务。

## 5. 平台协同与运行保障

### 5.1 账号、角色与泛雅协同

平台支持教师、学生和管理员的角色入口。系统保留与泛雅相关的 SSO、用户/课程/选课同步和学习进度回调能力，用于后续接入学校既有教学平台。

泛雅真实环境联调需要单独验收。自动化回归不会访问真实泛雅环境，也不会把接口存在表述为已完成真实平台端到端上线。

### 5.2 外部服务任务保障

LLM、TTS、AI PPT、数字人、声音复刻和远程 HTTP 调用均可能出现超时、服务不可用、格式异常或“请求已完成但业务失败”。系统针对这些情况保留任务状态和错误信息，避免把失败伪装成成功。

自动化测试使用可控 Fake 覆盖成功、超时、服务不可用、格式错误和业务失败，不调用真实付费服务或生产数据库。

### 5.3 决赛演示降级

为保证现场稳定，演示运行采用以下原则：

1. 关键课程、脚本、映射和账号在赛前准备。
2. 音频、视频和课件可使用预生成素材兜底。
3. 上传、PPT、TTS 或数字人任务超过可接受等待时间时，切换到准备课程继续展示。
4. 降级时明确说明素材为赛前生成，不把兜底说成实时生成。
5. 不在现场重装依赖、修改配置或重复调用付费服务。

## 6. 可信教学增强功能

以下能力已形成契约、组件、旁路验证或受限演示入口，但尚未成为学生默认学习流程。它们的作用是为产品后续提供可追溯、可解释和可治理的教学能力。

### 6.1 文档证据与原文查看

未来的可追溯问答需要将回答关联到具体教材页、文本块和坐标区域。当前已经准备了 Evidence Viewer、Citation 卡片、坐标高亮、失效证据提示等界面与接口契约。

当前状态：页面和 API 已可用于管理员技术验证；真实教材页面渲染、真实证据数据和面向学生的点击原文体验尚未作为默认功能发布。

### 6.2 教育知识结构与图谱

系统已具备将课程、章节、知识点、课件页面和证据关系组织为图结构的基础能力。当前图谱只在旁路中生成候选或冻结快照，用于验证知识结构和证据绑定。

当前状态：不自动修改正式课程，不自动给学生生成学习路径，不应表述为已上线的 GraphRAG 或自动知识图谱教学。

### 6.3 学习事件、记忆与学情

系统正在建立学习事件、学习证据、掌握状态和学生记忆的基础结构。它们未来可用于解释学生的薄弱点、推荐前置补学和支持教师了解班级学习情况。

当前状态：旁路能力仅生成候选事件、候选记忆和审计记录；不会写入正式长期记忆，不会影响正式回答，也不会直接给学生贴“掌握/不掌握”的标签。

### 6.4 教师安全治理

系统为课程级安全策略、禁答规则、必须引用、来源范围和审计记录预留了能力。当前安全能力以 dry-run 方式评估“若启用会怎样”，不阻断学生的 V1 请求。

未来进入正式流程前，需要完成教师配置、误拦截评估、审计和灰度发布。

## 7. Shadow 与实验功能说明

### 7.1 Product 1 V2 Shadow

Product 1 V2 Shadow 用于验证文档解析、证据引用、学习事件、学生记忆、安全治理和知识图谱等新能力。它具有三项硬约束：

1. 默认关闭。
2. 旁路运行时不改变 V1 响应、正式课程数据、学生页面和正式问答提示词。
3. 运行失败时保留 V1 主链并记录原因。

因此，V2 Shadow 是“安全验证新能力”的机制，不是对学生自动开放的功能开关。

### 7.2 Shadow-1 检索演示

Shadow-1 是管理员在开发、测试或演示环境中使用的本地检索展示页面。它运行冻结的课程范围检索方案：`BM25 + 本地 BGE Dense + RRF`，展示命中证据、citation、PPT 页码和冻结图谱快照。

该页面具有以下边界：

1. 仅管理员可访问，默认关闭。
2. 不调用 V1 聊天、课程播放器、学生进度、记忆或学习路径。
3. 不调用远程向量服务或真实付费 LLM。
4. 展示的是实验性 Evidence 文本摘录，不是经质量校准的正式问答。
5. 当前研究素材不是 Human Gold，拒答校准尚未完成，因此不能宣传准确率或优于 V1。
6. 页面可以一键回退为 `v1_only`，不会改动 V1 代码、课程数据或数据库。

## 8. 当前可对外展示的功能边界

可以对外展示：

1. 教师从资料上传、脚本编辑、页面映射、媒体任务到课程发布的完整流程。
2. 学生从选课、分屏学习、进度保存、问答/测验到前置补学的完整流程。
3. 外部服务出现故障时，使用预生成音视频和准备课程继续演示教学闭环。
4. 平台已为可追溯证据、知识结构、学习事件、记忆和安全治理提供可控的旁路验证基础。

当前不应对外表述为已完成：

1. 真实外部 LLM、TTS、PPT、数字人或泛雅环境的稳定性和效果验收。
2. 每门课程都支持教材原文点击、高亮和坐标定位。
3. 自动教育知识图谱、GraphRAG、学生长期记忆或自动学情推荐已默认上线。
4. BKT、HMM、LSTM、深度知识追踪或复杂多智能体教学系统。
5. Shadow-1 检索实验的准确率、拒答能力或优于 V1 的结论。
