## 🔧 问题1：教师界面"学生状态"数字修复

### 问题描述
教师管理界面（TeacherHistory.vue）中，每门课程的"👥 学生状态 (N)"按钮显示的数字始终为0，与实际选课人数不符。

### 根本原因
- 后端 `GET /api/v1/document/courses` 接口返回的课程数据中**缺少 `student_count` 字段**
- 前端使用 `course.student_count || 0` 显示，由于字段不存在导致始终显示为0

### 解决方案
**文件**: [backend/app/api/v1/endpoints/document.py](../backend/app/api/v1/endpoints/document.py#L515-L523)

```python
# 在 get_courses_list 接口中增加查询逻辑
student_count = session.exec(
    select(func.count()).select_from(StudentEnrollment).where(
        StudentEnrollment.course_id == course.id,
        StudentEnrollment.is_active == True
    )
).one()

courses_data.append({
    # ... 其他字段
    "student_count": student_count,  # 新增字段
})
```

### 验证方法
1. 教师登录系统
2. 进入"课程管理"页面（/teacher/history）
3. 确认每个课程卡片上的"👥 学生状态 (N)"显示正确的选课人数

## 💾 问题3：学习进度数据持久化

### 问题描述
学生学习后切换账号或退出再进入，学习进度清零，教师端也无法看到学生的学习数据。

### 根本原因分析

#### 3.1 数据模型字段不一致 ❌→✅

**问题代码** ([document.py#L1647-L1666](../backend/app/api/v1/endpoints/document.py#L1647-L1666)):
```python
# 错误：使用了不存在的字段名
LearningProgress.student_id == student_id  # ❌ 应该是 user_id
learning_progress = LearningProgress(
    student_id=student_id,           # ❌ 应该是 user_id
    overall_progress=0.0,            # ❌ 应该是 completion_rate
    total_study_time=0,              # ❌ 应该是 total_learning_time
    last_access_time=datetime.utcnow(), # ❌ 应该是 last_accessed_at
)
```

**修正后**:
```python
# 正确：使用 progress_model 中定义的字段
LearningProgress.user_id == student_id   # ✅
learning_progress = LearningProgress(
    user_id=student_id,                  # ✅
    completion_rate=0.0,                 # ✅
    total_learning_time=0,               # ✅
    last_accessed_at=datetime.utcnow(),  # ✅
    total_nodes=total_nodes,             # ✅ 新增
    completed_nodes=0,                   # ✅ 新增
    status="not_started",                # ✅ 新增
)
```

**影响范围**:
- `_init_learning_progress_for_student()` 函数
- `_ensure_learning_progress()` 函数

#### 3.2 进度保存时机不足 ❌→✅

**之前**: 只在问答交互时调用 `saveProgressToServer()`
**现在**: 
- ✅ 节点首次访问时自动保存（`markNodeVisited` → `saveNodeAccessToServer`）
- ✅ 问答交互时保存理解度数据
- ✅ 节点完成时标记并保存

**文件**: [useStudentLearning.js#L362-L384](../frontend/src/composables/useStudentLearning.js#L362-L384)

```javascript
function markNodeVisited(index) {
  // 初始化节点进度...
  
  // 新增：立即保存到服务器
  saveNodeAccessToServer(index)
}

async function saveNodeAccessToServer(index) {
  await request({
    url: '/progress/sync',
    method: 'post',
    data: {
      courseId: selectedCourse.value.id,
      nodeId: node.id,
      isCompleted: false,
      timeSpent: 0,
    }
  })
}
```

- 所有节点的详细进度（完成状态、理解度、提问次数）

## 📊 数据流图示

### 选课流程
```
学生点击"选择此课程"
    ↓
POST /document/course/{id}/enroll
    ↓
后端验证 + 创建 StudentEnrollment 记录
    ↓
调用 _init_learning_progress_for_student()
    ↓
创建 LearningProgress 记录（user_id, course_id）
创建 NodeProgress 记录（每个节点）
    ↓
返回成功响应
    ↓
前端刷新"我的课程"列表
```

### 学习进度保存流程
```
学生访问知识点
    ↓
markNodeVisited(index)
    ↓
saveNodeAccessToServer(index)  [新增]
    ↓
POST /progress/sync
{
  courseId, nodeId,
  isCompleted: false,
  timestamp: 0
}
    ↓
后端更新 LearningProgress.last_accessed_at
创建/更新 NodeProgress 记录
    ↓
返回 { completionRate, status }
```

### 进度加载流程（断点续接）
```
学生重新进入课程
    ↓
loadCourseContent(courseId)
    ↓
loadProgressFromServer(courseId)  [新增]
    ↓
GET /progress/detail/{course_id}
    ↓
查询 LearningProgress + NodeProgress
    ↓
返回完整进度数据
{
  overall: { completion_rate, status... },
  nodes_progress: [{ is_completed, understanding_score... }]
}
    ↓
前端更新 nodeProgressMap
显示"已恢复学习进度: XX%"
    ↓
学生从上次位置继续学习
```
