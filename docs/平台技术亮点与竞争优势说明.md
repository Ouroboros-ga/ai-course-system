# 平台技术亮点与竞争优势说明

本平台立足于泛雅平台生态，采用可治理的多智能体架构（教学问答、备课、代码诊断三智能体物理分离），在开放 API 标准契约之上自建了"智能体工程实现层"。围绕安全、嵌入、图检索与可插拔四大维度，平台形成了一套既贴合教育场景合规要求、又具备强扩展性的技术体系，整体竞争力体现在以下方面。

## 一、安全性：数据保护、访问控制与运行环境隔离三重保障

平台将数据安全视为教育系统的底线，从数据、权限、运行三个层面构筑防护：

- **数据保护（最小化与隔离）**：平台将运行审计、师生对话、学习分析划分为三个相互独立的数据域，彼此不共享原始上下文；审计记录中的用户内容片段被强制截断至 100 字符以内，元数据禁止写入密钥与全文；师生对话数据拥有独立的保留周期（默认 90 天）与过期清理机制；学习分析仅消费结构化的 trace_id 投影信号，而非原始对话文本，从源头降低敏感信息留存与泄露风险。
- **访问控制（精细化与防重放）**：权限判定经由课程访问体系（Course Access）解析课程、学生、成员与能力视图，而非简单依赖用户角色标签；平台在接口层内置签名防重放中间件（MD5 签名 + 时间窗校验），对平台同步等内部接口叠加内网 IP 白名单，杜绝越权调用与重放攻击。
- **运行环境隔离（沙箱化执行）**：学生代码经独立的 Judge0 沙箱执行，永不进入主应用进程；沙箱以非特权方式运行（仅最小必要内核能力 + 禁止提权），并与 OCR 等重资源服务解耦为独立服务栈，配合 CPU、内存与进程数（pids）的硬性资源上限，确保单点任务越界不会拖垮主机。

## 二、功能可嵌入式：以标准契约灵活融入各类教学场景

平台的所有核心能力（智课生成、实时问答、进度适配等）均以 REST API 形态对外提供，遵循开放 API 规范的接口契约（如课件解析、问答交互、进度追踪等），天然适配泛雅 Web 端与学习通移动端。

在架构层面，平台通过 Port / Provider / Contracts 模式将各功能模块解耦——模块之间仅通过协议（Protocol）协作，不共享可变状态；前端通过统一的 API 客户端对接后端，权限消费能力视图模型而非全局状态。这种"契约先行、状态隔离"的设计，使任一功能模块都能作为独立服务被灵活嵌入备课、授课、自学、答疑等不同业务流，无需改动核心链路即可完成场景适配。

## 三、Graph RAG 与图检索：让知识关联与推理可解释、可追溯

区别于常规"向量检索 + 上下文拼接"的黑盒式 RAG，平台构建了面向教育领域的**知识图谱**作为检索增强的结构化底座：图谱内置 8 种教育关系类型、14× 节点类型校验矩阵与三色 DFS 先修环检测，并支持不可变快照与版本对比回滚。

在此之上，平台提供**基于图结构的检索增强生成（Graph RAG）**能力——问答不再局限于字面相似度匹配，而是沿"先修 / 包含 / 例证"等语义关系进行多跳推理，将零散知识点组织为可解释的知识网络。答案可溯源至具体的图谱边与学习证据（`evidence_refs` 强制挂载），使跨章节的知识关联与推理准确性显著提升，同时让"为什么这样讲、依据是什么"对用户透明可见。

## 四、平台可插拔性：按需装配，专业领域定制零侵入

平台采用 Port / Provider 装配与组件注册表机制，支持功能组件的**按需插拔**。以两类典型组件为代表：

- **代码沙箱（Judge0）**：作为独立可挂载的执行组件，为编程类课程提供安全代码评测能力；
- **算法可视化**：通过算法白名单注册表（内置 11 种算法）管理可插拔的可视化与计算模块。

面向特定专业领域（如理工科实验仿真、医学影像分析、艺术设计生成），扩展方式极为轻量——只需新增对应的算法 / 工具 / 可视化模块并完成注册，即可完成领域定制，核心链路与既有模块不受影响。这种"加模块即能力"的设计，使平台具备极强的可拓展性与跨学科通用性。

## 五、其他创新点与核心优势

除上述四大维度外，平台还在以下方向形成差异化竞争力：

- **多模态学习支持**：集成语音合成与语音识别，支持文字 / 语音双通道交互；数字人讲授形象实行授权与版本化管理（媒体资源以不可变版本访问），兼顾体验与合规。
- **个性化推荐与自适应节奏**：基于学习证据与结构化推理信号（如平均提问深度、薄弱点标记）驱动薄弱知识定位，并据此自动调整后续讲授节奏与重点强化，实现"因人而异"的学习路径。
- **低代码与配置化运营**：功能开关采用 fail-closed 灰度策略、课程能力开关与统一前端设计令牌体系，使新能力的试点、回滚与界面定制以配置方式完成，显著降低定制与运维成本。
- **跨平台与可交付性**：接口遵循开放标准（URL 版本化、JSON、HTTPS、统一签名），适配泛雅 Web 与学习通移动端；后端以声明式容器编排（Docker Compose）一键拉起全栈，配合资源硬隔离，便于在不同院校环境中快速交付与弹性部署。

综上，平台以"安全为底线、嵌入为形态、图谱为智能内核、插拔为扩展方式"，在合规、灵活、智能与通用四个层面形成闭环，能够为高校智慧教学提供一套既能深度融入现有教学平台、又可随学科发展持续演进的技术底座。
