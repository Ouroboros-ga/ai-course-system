## 一、当前项目分析

### 1.1 保留部分

| 模块 | 路径 | 保留理由 |
|------|------|---------|
| 前端框架 | `frontend/` | Vue 3 + Vite 架构成熟，保留基础框架 |
| 后端框架 | `backend/app/core/` | FastAPI 配置、安全模块可复用 |
| 数据库迁移 | `backend/app/models/database.py` | SQLModel 基础设施保留 |
| RAG基础 | `backend/app/common/RAG/` | TreeRAG、混合提取器可参考 |
| LLM客户端 | `backend/app/common/llm_client.py` | LLM调用逻辑可复用 |

### 1.2 重构部分

| 模块 | 问题 | 重构方向 |
|------|------|---------|
| API端点 | 20+端点扁平堆砌，职责混乱 | 按领域模块化重组 |
| 业务逻辑 | Service层耦合严重 | 按智能体能力拆分 |
| 前端组件 | 组件臃肿，缺乏状态管理 | 按功能域重组 + Pinia |
| 数据模型 | 为旧业务设计 | 新增认知状态、知识图谱模型 |

### 1.3 新增部分

| 模块 | 说明 |
|------|------|
| 认知追踪引擎 | 核心创新1：多维BKT + HMM思维路径推断 |
| 多智能体系统 | 核心创新2：竞争-协商-反思动态协同 |
| GraphRAG引擎 | 核心创新3：知识图谱多跳推理 |
| 可视化编辑器 | 载体层：数据结构交互编辑 + 认知信号采集 |
| 代码实训环境 | 载体层：Monaco Editor + Docker容器 |

│  └─ 推理路径生成（可解释）                                  │

│         ↓ 个性化教学内容                                    │
│  【用户层】学生界面                                          │
│  ├─ 认知仪表盘（实时状态）                                  │

## 四、技术栈

| 层 | 技术 | 用途 |
|----|------|------|
| 前端 | Vue 3 + TypeScript | UI框架 |
| 可视化 | D3.js + Canvas | 数据结构可视化 |

| 智能体 | LangGraph | 多智能体编排 |

| 大模型 | Qwen-14B API | LLM推理 |
| 容器 | Docker | 代码实训环境 |
| 部署 | Docker Compose | 本地开发 |
