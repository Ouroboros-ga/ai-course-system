# 联系我们

CodeNexus智码交响是开源项目，欢迎通过以下渠道反馈问题、提出建议或参与共建。

## 问题反馈

发现 Bug、功能异常或体验问题，请优先到 GitHub Issues 提交：

- 问题反馈入口：https://github.com/Ouroboros-ga/ai-course-system/issues
- 提交时请说明复现步骤、页面路径与期望行为，必要时附上截图或日志摘要。
