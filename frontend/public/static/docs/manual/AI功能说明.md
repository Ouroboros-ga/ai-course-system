# AI 功能说明

SmartCarb 通过四类智能体与受控能力层提供 AI 功能：备课、教学问答、代码诊断与科研检索。所有 AI 输出都遵循「有证据、可审核、失败明确」的原则，本节说明各能力的职责与边界。

## 一、四类智能体

| 智能体 | 核心职责 | 写入边界 |
| --- | --- | --- |
| 备课智能体（Prep Agent） | 初始备课与增量备课提案生成 | 经教师审核后写入课程草稿 |
| 教学智能体（TeachingAgent） | 课程内教学问答与受控教学动作 | 回答后写入对话记录；高风险动作需教师确认 |
| 代码教学智能体（CodingEduAgent） | 基于沙箱真实结果的代码诊断与教学 | 只读沙箱结果，评分由服务端写入证据 |
| 科研智能体（ResearchAgent） | 课程内学术资料检索与科研工作区 | 外部结果仅作补充参考，进正式课程需教师审核 |

四类智能体物理分离、状态独立，不共享跨课程可变状态，通过受控接口协作；协作媒介是课程发布、知识包、提案与证据记录，而不是自由的消息传递。

## 二、教学问答（TeachingAgent）

教学问答的工作流固定为：范围校验 → 学生状态读取 → 认知信号读取 → 可选工具调用 → 教师策略应用 → 回答生成。要点：

- 范围校验确认课程、学生、成员关系与调用能力，不通过即终止；
- 回答基于课程检索证据生成，引用（Citation）可回到材料原文位置；
- 教师策略层决定允许的教学动作；高风险动作（如外部研究、触发实验、更换话题）需教师确认后执行；
- 题目生成只产出草稿，教师批准后才进入正式题库。

## 三、课程检索与知识包

问答与推荐使用的检索基于课程知识图谱：节点是知识点，边是前置、从属、支撑、关联等类型化关系，每个节点锚定教师确认过的证据。正式检索链路包含 BM25 稀疏检索、本地语义向量、排名融合与图谱关系增强，结果再经过三重约束：

- 课程一致：只返回当前课程的候选；
- 版本一致：只返回当前激活知识包的候选；
- 引用可闭合：候选能够回到正式证据与材料原文。

任一约束不满足，候选不进入正式回答。检索依赖不可用时返回明确的不可用状态，不回退到跨课程或未经审核的内容。

## 四、代码诊断（CodingEduAgent）

编程类课程的实验代码提交到独立沙箱（Judge0）编译运行，与主应用物理隔离。智能体只读取沙箱返回的真实结果（通过、编译错误、运行错误、超时、资源限制）生成诊断与讲解：

- 不猜测程序运行结果，不伪造通过状态；
- 完整源码、隐藏用例与沙箱凭据不进入智能体状态、审计或对话记录；
- 最终评分由服务端确认后写入正式学习证据，权重高于普通题目作答。

## 五、六维认知与学情反馈

系统基于正式评分证据与学习交互，在课程与知识点范围内维护六维认知状态：表现、证据置信度、困惑风险、提问深度、提示依赖与解释需求。

每个维度有独立样本量门槛，证据不足时保持「未知」并记录原因码；低置信度判断进入「需要更多证据」路径，而不是直接断言薄弱。认知状态还叠加三类机制：

- 认知衰减：评分证据按遗忘曲线降低参考权重（半衰期默认 14 天），久未复习的知识点倾向保守判断；
- 学习轨迹：追加记录教学回答、作答、推荐与认知刷新等关键事件，不保存对话原文；
- 学习路径：基于图谱前置关系与认知状态推荐下一学习节点。

## 六、科研检索（ResearchAgent）

研究型课程的科研工作区支持围绕课程主题检索学术资料（当前基线为 arXiv 元数据与摘要）。工作区按课程与操作者隔离，外部论文标记为补充参考证据：

- 不自动写入课程图谱、掌握度或正式课程事实；
- 教师可把有价值的外部资料转化为待审核提案，审核通过后才能进入正式课程域；
- 趋势分析、自动综述、论文写作辅助与完整代码复现属于规划能力，当前界面明确标注边界。

## 七、AI 出题与备课

备课与出题遵循同一种治理模式：AI 输出先形成草稿或提案，经过证据校验与教师批准后才成为正式内容。

- 备课提案（PatchProposal）要求携带有效证据引用，只能修改未锁定节点，不能增删移动节点；
- 题目草稿经教师批准后进入正式题库，未批准题目学生不可见。

## 八、安全与失败关闭

AI 功能受到独立安全围栏约束：课程类型安全收敛、政治敏感两级审查、平台级屏蔽词配置、工具治理与数据域隔离。关键兜底行为：

- 命中屏蔽词的内容不进入正式回答；
- 权限、证据、沙箱或安全阀不可用时失败关闭，返回明确错误语义，不伪装成功；
- 智能体运行审计只保存结构化标识与结果码，不持久化完整提示词与模型输出。
