# 快速入门指南

CodeNexus智码交响是一套证据驱动的课程建设、互动学习与教学分析系统，核心思想是让课程回应学习。本文带你从注册登录开始，用最短路径完成第一门课程的建设与学习。

## 一、注册与登录

打开平台首页后，点击页面右上角的登录入口进入 `/profile` 登录页。

- 已有账号：输入用户名和密码登录。
- 新用户：切换到注册页签，填写用户名、密码，勾选《隐私政策》与《服务条款》后提交。注册成功后即可登录。

登录后系统默认停留在首页 `/app`。首页导航集中了四类入口：我的课程、平台实验室、资源库与任务中心，页脚提供文档中心与产品相关链接。

## 二、学生视角：加入一门课程并开始学习

1. 在首页进入「我的课程」→「课程大厅」，找到目标课程并加入；也可以直接通过教师分享的课程链接进入。
2. 在「我的课程」→「我学习的」列表中找到课程，点击进入课程空间，再打开「学习」页。
3. 学习页按统一时间轴同步呈现课件、讲解声音、字幕与知识点：播放器自动推进，知识点随页面切换更新，右侧可展开知识结构。
4. 学习过程中随时可以在问答区向课程智能体提问，回答会引用课程材料中的原文位置；需要回顾时，根据智能体提示选择「回顾」即可跳转到对应内容，回顾完成后再返回原位置。
5. 学习进度自动保存，下次进入课程从上次位置继续。

课程内出现的测验、练习与编程实验会在服务端完成评分，并作为正式学习证据进入你的学情分析，详情见《学生使用手册》。

## 三、教师视角：创建并发布第一门课程

1. 在首页进入「我的课程」→「我建设的」，点击「创建课程」，填写课程名称、简介并选择课程类型（专业通识 / 网络安全 / 思想政治）。
2. 课程创建后进入建设流程，按左侧步骤依次完成：上传材料 → 确认课程结构 → 生成与编辑讲授脚本 → 完成页面映射 → 生成媒体 → 质量校验 → 发布课程。
3. 上传 PPT、PDF 或 Word 材料后，系统会自动登记材料版本并启动解析任务；解析完成后进入「知识空间」确认证据片段与知识候选，只有教师确认过的证据才能成为正式课程依据。
4. 建设过程中的生成结果（讲稿、题目、媒体）都以草稿或提案形式呈现，教师批准后才进入正式内容；发布后的课程版本不可变，必要时可以回滚到历史版本。
5. 发布完成后，学生即可在「课程大厅」或课程链接中看到并学习该课程。

完整流程见《教师建设手册》。

## 四、常见问题

**解析任务一直显示「解析中」？** 解析任务在服务重启时会标记为「已中断」，回到建设页重新触发解析即可，系统不会自动伪造成功状态。

**提问没有得到回答？** 教学问答只在课程能力、成员身份与权限均满足时可用；知识检索或智能体依赖不可用时，系统会返回明确的不可用提示，而不是生成无依据的回答。

**找不到入口？** 平台实验室、资源库、任务中心、文档中心分别承担实验、素材、任务与文档职能，绝大多数功能入口都汇总在首页导航中。
