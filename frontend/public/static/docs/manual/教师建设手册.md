# 教师建设手册

本手册面向教师在 SmartCarb 上建设、审核与发布课程，覆盖从创建课程、材料解析、证据确认到发布回滚的完整流程。手册描述以当前代码实际工作流为准。

## 一、创建课程

在首页「我的课程」→「我建设的」点击「创建课程」，填写课程名称、简介并选择课程类型。课程类型影响安全策略适用范围：

- 专业通识（professional）：常规专业课程；
- 网络安全（cybersecurity）：网络安全与 CTF 类课程，安全教学内容按规则放行；
- 思想政治（ideological）：思政课程，政治类主题在合规语境下允许教学讨论。

课程创建后进入课程空间，建设功能集中在「建设」页。

## 二、建设流程概览

建设页按左侧步骤推进，当前包含八个子页面：

1. 材料（materials）：上传与管理课程材料；
2. 结构（structure）：确认课程大纲与知识点结构；
3. 脚本（scripts）：生成与编辑各知识点的讲授脚本；
4. 映射（mapping）：脚本内容与课件页面之间的映射；
5. 媒体（media）：生成讲解声音、字幕与课件播放清单；
6. 校验（validate）：发布前的质量门检查；
7. 发布（releases）：正式发布与历史版本管理；
8. 题目草稿（drafts）：审核智能体生成的题目草稿。

## 三、材料上传与解析

建设页「材料」中上传 PPT、PDF 或 Word 文件。系统按逻辑材料与材料版本分别登记：同一材料再次上传会形成新版本，旧文件不静默覆盖。

上传后系统自动启动解析任务，任务状态包括等待、运行、成功、失败、中断与部分成功。解析采用原生结构提取与 OCR 增强的组合方式：可直接提取的文本优先使用原生解析，扫描页或图像区域使用 OCR 补充识别，两源结果按置信度合并。解析质量不达标时，相关页面进入「待人工复核」状态，不会直接写入正式内容。

## 四、证据确认与知识审核

解析结果形成文档内容块与证据片段候选。进入「知识空间」可以完成三类工作：

- 图谱（graph）：查看课程知识节点与关系，确认智能体识别出的知识候选；
- 证据（evidence）：浏览证据片段候选，确认后成为正式课程证据；被拒绝的候选保留拒绝原因；
- 候选审核（reviews）：审核知识节点、关系与题目等候选批次；
- 快照（snapshots）：查看已发布的图谱快照版本记录。

证据确认是正式课程内容的必要前提：缺少有效证据的生成内容不能进入正式提案。

## 五、备课智能体

备课智能体（Prep Agent）负责把材料转化为课程草稿，并提供两种工作模式：

- 初始备课：根据材料与课程目标生成结构化草稿（课程结构、讲授脚本等）；
- 增量备课：选中某个知识节点，对脚本内容或表达风格提出修改建议。

增量备课以「修改提案（PatchProposal）」形式工作：智能体只能修改指定范围内未锁定节点的标题、脚本内容或风格，不能自行增删移动节点，也不能修改已发布或锁定内容。每个提案都要求携带可解析到当前课程有效证据的引用，教师审核通过后才写入课程草稿。

## 六、脚本、映射与媒体

「脚本」页按课程结构组织讲授脚本，可逐节点查看与编辑。「映射」页建立脚本内容与课件页面之间的对应关系，无 PPT 材料时该步骤保留入口但进入冻结状态。「媒体」页基于脚本生成可复用的讲解声音、字幕与播放清单；生成失败会保留阶段与错误码，媒体依赖不可用时课程回退为基础内容模式。

修改脚本或媒体形象后，需要生成新媒体版本，旧版本标记为失效而非静默替换。

## 七、发布与回滚

「校验」页在发布前执行质量门检查；「发布」页创建正式课程版本（CourseRelease）。发布要点：

- 发布版本不可变：学生只能看到激活的版本；
- 支持回滚：内容修订时创建新版本，需要恢复历史内容时回滚到既有版本，历史版本与制品继续保留；
- 发布时课程结构、知识图谱引用与知识包制品绑定到同一发布版本。

## 八、题目审核

教学智能体可基于当前知识节点与学情生成题目，但生成结果先进入「题目草稿」：教师在题目草稿页批准后，题目才进入正式题库；未批准的题目学生不可见，拒绝记录保留原因。

## 九、学情分析与设置

「分析」页提供课程级知识点掌握分布与学生级明细，只统计真实学生且未被排除的数据，教师预览行为不进入学生分析。

「设置」页包含课程资料、访问权限、智能体策略、安全策略、代码沙箱与外部集成六类配置，按需调整即可。

## 十、常用注意事项

- 材料更新后需重新解析并确认受影响的证据，旧证据会被标记为失效或孤立，不会自动删除；
- 发布与回滚均保留历史记录，操作可追溯；
- 课程建设中的 AI 生成内容始终以草稿/提案形式呈现，最终发布责任由教师承担。
